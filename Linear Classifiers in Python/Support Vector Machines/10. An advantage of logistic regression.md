## An advantage of logistic regression

### Concept: The Power of Probabilities
While SVMs win the battle of speed and complex curved boundaries, Logistic Regression has a massive advantage of its own.

Because Logistic Regression uses the smooth Logistic Loss (and the Sigmoid function), it never hits a hard zero penalty. It carefully calculates a mathematical score for every single point in the dataset.

---

### Instructions

**Question:** Which of the following is an advantage of logistic regression over SVMs?

**Possible Answers:**
* [x] (1) It naturally outputs meaningful probabilities.
* [ ] (2) It can be used with kernels.
* [ ] (3) It is computationally efficient with kernels.
* [ ] (4) It learns sigmoidal decision boundaries.

---

### Solution

**Correct Answer:** `(1)`

**Why this is correct:**
* **Option 1 is true:** Because Logistic Regression passes its raw output through the Sigmoid "squisher" function, it naturally translates its math into perfect 0.0 to 1.0 percentages. If you are predicting stock market crashes or cancer diagnoses, you usually want to know exactly *how confident* the model is, rather than just a hard Yes/No answer.
* Options 2 and 3 belong to SVMs.
* Option 4 is a trick: It uses the sigmoid function to calculate *probabilities*, but the actual decision boundary it draws is still just a straight, linear line!
