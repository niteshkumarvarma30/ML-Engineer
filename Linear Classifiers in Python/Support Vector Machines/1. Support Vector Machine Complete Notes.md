# 1. Introduction to Support Vector Machine (SVM)

Support Vector Machine (SVM) is a **supervised machine learning algorithm** primarily used for:

* Binary Classification
* Multi-class Classification (using extensions)
* Regression (Support Vector Regression - SVR)

Unlike many classifiers, SVM does not simply find a separating boundary. Instead, it finds the **best possible separating boundary**.

Its goal is to maximize the distance between the two classes.

---

# 2. Why SVM?

Suppose we have two classes.

```text
× × × ×

----------------

○ ○ ○ ○
```

Many lines can separate these classes.

SVM asks:

> **Which separating line is the best?**

Answer:

The line having the **largest margin**.

A larger margin generally leads to better generalization on unseen data.

---

# 3. Types of SVM

## Linear SVM

Used when data is linearly separable.

```text
× × ×

------------

○ ○ ○
```

A straight line separates both classes.

---

## Non-Linear SVM

Sometimes the data looks like

```text
      ○ ○ ○

   ○ × × ○

      ○ ○ ○
```

A straight line cannot separate these classes.

In such cases SVM uses the **Kernel Trick**.

---

# 4. Hyperplane

A Hyperplane is simply the decision boundary.

Depending on dimensions

| Number of Features | Decision Boundary |
| ------------------ | ----------------- |
| 1                  | Point             |
| 2                  | Line              |
| 3                  | Plane             |
| n                  | Hyperplane        |

---

# 5. Hyperplane Equation

General equation

```text
ax + by + c = 0
```

For multiple features

```text
w₁x₁ + w₂x₂ + ... + wₙxₙ + b = 0
```

Matrix notation

```text
wᵀx + b = 0
```

where

* w = Weight Vector
* x = Feature Vector
* b = Bias

---

# 6. Weight Vector (w)

The weight vector is always **perpendicular** to the hyperplane.

Therefore it is called the **Normal Vector**.

```text
----------------------- Hyperplane

        ↑
        │
        │  w
        │
```

The shortest distance from any point to the hyperplane is measured along this vector.

---

# 7. Role of Bias (b)

Without bias

```text
wᵀx = 0
```

the hyperplane passes through the origin.

Adding bias

```text
wᵀx + b = 0
```

shifts the hyperplane without changing its orientation.

---

# 8. Decision Rule

For any point

Compute

```text
wᵀx + b
```

### Case 1

```text
wᵀx+b > 0
```

Predict

```text
+1
```

---

### Case 2

```text
wᵀx+b < 0
```

Predict

```text
-1
```

---

### Case 3

```text
wᵀx+b = 0
```

The point lies exactly on the hyperplane.

---

# 9. Why Does the Sign Work?

The sign tells us which side of the hyperplane the point lies on.

Positive

```text
wᵀx+b > 0
```

Positive Class

Negative

```text
wᵀx+b < 0
```

Negative Class

---

# 10. Support Vectors

Support Vectors are the training samples closest to the decision boundary.

These points completely determine the position of the hyperplane.

Removing non-support vectors usually has little effect.

Moving a support vector changes the hyperplane.

---

# 11. Margin

Margin is the distance between

```text
Positive Margin

and

Negative Margin
```

Visual

```text
Positive

×

-----------------

wᵀx+b=1

-----------------

wᵀx+b=0

-----------------

wᵀx+b=-1

○

Negative
```

SVM maximizes this distance.

---

# 12. Why +1 and -1?

The equations

```text
wᵀx+b=1

wᵀx+b=-1
```

are chosen only for mathematical convenience.

Any scaled values would represent the same hyperplanes.

---

# 13. Constraints

For Positive Class

```text
wᵀx+b ≥ 1
```

For Negative Class

```text
wᵀx+b ≤ -1
```

Both combine into

```text
yᵢ(wᵀxᵢ+b) ≥ 1
```

This single equation works because labels are

```text
+1

-1
```

---

# 14. Support Vector Condition

Support Vectors satisfy

```text
yᵢ(wᵀxᵢ+b)=1
```

Correctly classified points satisfy

```text
yᵢ(wᵀxᵢ+b)>1
```

---

# 15. Margin Distance

Distance between both margin lines is

```text
Margin = 2 / ||w||
```

where

```text
||w||
```

is the magnitude of the weight vector.

---

# 16. Why Maximize Margin?

Suppose

```text
Margin = 2 / ||w||
```

Larger Margin

↓

Smaller

```text
||w||
```

Therefore

Maximizing Margin

is equivalent to

Minimizing

```text
||w||
```

---

# 17. Optimization Problem

Instead of minimizing

```text
||w||
```

we minimize

```text
½||w||²
```

The square simplifies differentiation.

The factor

```text
½
```

eliminates the constant 2 during differentiation.

Final optimization

```text
Minimize

½||w||²

Subject To

yᵢ(wᵀxᵢ+b)≥1
```

This is called **Hard Margin SVM**.

---

# 18. Hard Margin SVM

Assumptions

* Perfectly separable data
* No noise
* No overlap
* No misclassified samples

Works well only on ideal datasets.

---

# 19. Problem with Hard Margin

Real-world data contains

* Noise
* Incorrect labels
* Outliers
* Overlapping classes

Hard Margin fails because it insists on perfectly classifying every point.

---

# 20. Soft Margin SVM

Soft Margin allows some classification errors.

Instead of forcing

```text
Every point must be correctly classified.
```

it says

```text
A few mistakes are acceptable.
```

This improves generalization.

---

# 21. Slack Variable (ξ)

Slack Variable

```text
ξ
```

measures how much a point violates the margin.

---

## Case 1

```text
ξ = 0
```

Perfectly classified.

Outside the margin.

---

## Case 2

```text
0 < ξ < 1
```

Correctly classified

but inside the margin.

---

## Case 3

```text
ξ > 1
```

Misclassified.

---

# 22. New Constraint

Soft Margin modifies the constraint to

```text
yᵢ(wᵀxᵢ+b)

≥

1−ξᵢ
```

---

# 23. New Optimization Function

Soft Margin minimizes

```text
½||w||²

+

CΣξᵢ
```

subject to

```text
yᵢ(wᵀxᵢ+b)

≥

1−ξᵢ
```

---

# 24. Meaning of C

C controls the balance between

* Large Margin
* Classification Error

---

## Large C

Large penalty for errors.

Small Margin.

Less tolerance for mistakes.

Can overfit.

---

## Small C

Allows more mistakes.

Larger Margin.

Better generalization.

---

# 25. Linear SVM vs Soft Margin

| Hard Margin           | Soft Margin         |
| --------------------- | ------------------- |
| No errors allowed     | Errors allowed      |
| Perfect data only     | Works on noisy data |
| Sensitive to outliers | Robust              |
| Rarely used           | Used in practice    |

# 28. Kernel Trick

Instead of explicitly transforming data into high dimensions,

SVM computes similarities directly.

This shortcut is called the

```text
Kernel Trick
```

It makes computations efficient.

---

# 29. Kernel Function

General form

```text
K(xᵢ,xⱼ)
```

It computes similarity between two points.

---

# 30. Types of Kernels

## Linear Kernel

```text
K(x,y)=xᵀy
```

Used for linearly separable data.

---

## Polynomial Kernel

```text
K(x,y)

=

(xᵀy+c)^d
```

Useful for polynomial decision boundaries.

---

## Gaussian (RBF) Kernel

```text
K(x,y)

=

exp(-γ||x-y||²)
```

Most widely used.

Handles complex non-linear data.

---

## Sigmoid Kernel

```text
K(x,y)

=

tanh(axᵀy+c)
```

Similar to neural network activation functions.

Rarely used.

---

# 31. Choosing the Right Kernel

| Kernel         | Use Case                      |
| -------------- | ----------------------------- |
| Linear         | Linearly separable data       |
| Polynomial     | Polynomial boundaries         |
| Gaussian (RBF) | Unknown or complex boundaries |
| Sigmoid        | Rare applications             |

# 33. Frequently Asked Questions

### Why is SVM called Maximum Margin Classifier?

Because it selects the hyperplane having the maximum distance between the two classes.

---

### Why are Support Vectors important?

Only the nearest points determine the hyperplane.

---

### Why do we maximize the margin?

A larger margin generally improves generalization and reduces overfitting.

---

### Why do we use Soft Margin?

Real-world data contains noise and overlap.

Soft Margin allows controlled violations.

---

### What does C control?

It balances

* Margin Size
* Classification Errors

---

### Why do we need Kernels?

Because many real-world datasets are not linearly separable.

Kernels allow SVM to create non-linear decision boundaries efficiently.

# Final One-Line Summary

> **Support Vector Machine (SVM) is a supervised learning algorithm that finds the optimal hyperplane with the maximum margin between classes. It uses support vectors to define the boundary, Soft Margin to handle noisy data, and the Kernel Trick to solve non-linear classification problems efficiently.**

# Understanding SVM Variables (w, x, y) and Support Vector Regression (SVR)

---

# Part 1: What are x and w in SVM?

The most common confusion in SVM is understanding the meaning of **x**, **w**, and **y**.

Let's understand them using a real dataset.

---

## Example Dataset

Suppose we want to predict whether a student will **Pass** or **Fail**.

| Hours Studied | Attendance | Result |
|---------------|------------|--------|
| 2 | 60 | Fail |
| 4 | 70 | Fail |
| 6 | 85 | Pass |
| 8 | 90 | Pass |

Here,

- **Hours Studied**
- **Attendance**

are the **input features (X)**.

The last column

- Pass / Fail

is the **output (y)**.

---

# Part 2: What is x?

Each row of the dataset becomes one **feature vector**.

Student 1

```
x₁ = [2, 60]
```

Student 2

```
x₂ = [4, 70]
```

Student 3

```
x₃ = [6, 85]
```

Student 4

```
x₄ = [8, 90]
```

Each **x** represents one training example.

---

# Part 3: What is w?

The model creates one weight for every feature.

Suppose

```
Hours Weight = 3

Attendance Weight = 0.5
```

Then

```
w = [3, 0.5]
```

Notice

Number of Weights = Number of Features

If there are

- 2 features → 2 weights
- 5 features → 5 weights
- 100 features → 100 weights

---

# Part 4: What do Weights Represent?

Weights represent the **importance** of each feature.

Example

```
Hours Weight = 5

Attendance Weight = 0.2
```

This means

Hours Studied is much more important.

Another example

```
Hours Weight = 0.1

Attendance Weight = 4
```

Now Attendance becomes much more important.

During training,

SVM automatically learns these weights.

---

```
]
```

```

```

Notice

- X contains the input variables.
- y contains the output labels.

# Part 12: How Does SVR Work?

Instead of finding the widest margin between classes,

SVR finds the best regression line while allowing a small prediction error.

This small error is controlled by

```
ε (epsilon)
```

called the **epsilon-insensitive tube**.

---

# What is the Error in SVR?

Linear Regression penalizes **every prediction error**.

Suppose

| Actual | Predicted |
|----------|-----------|
|50|49|

Error

```
|50−49|=1
```

Linear Regression penalizes this error.

---

SVR thinks differently.

Suppose

```
ε = 2
```

SVR says

> Any prediction within ±2 units is acceptable.

No penalty.

---

# Example 1

Actual

```
50
```

Prediction

```
49
```

Error

```
|50−49|=1
```

Since

```
1 < ε
```

Loss

```
0
```

No penalty.

---

# Example 2

Actual

```
50
```

Prediction

```
48
```

Error

```
2
```

Since

```
2 = ε
```

Loss

```
0
```

Still no penalty.

---

# Example 3

Actual

```
50
```

Prediction

```
47
```

Error

```
3
```

Now

```
3 > ε
```

Penalty

```
3−2

=1
```

Only the part outside the epsilon tube is penalized.

---

# ε-Insensitive Loss

SVR uses

```
Loss = 0

if

|Actual − Predicted| ≤ ε
```

Otherwise

```
Loss

=

|Actual−Predicted|

−

ε
```

---

# Example Table

Suppose

```
ε = 2
```

| Actual | Predicted | Error | Loss |
|----------|-----------|-------|------|
|50|49|1|0|
|50|48|2|0|
|50|47|3|1|
|50|44|6|4|

Notice

The first two units of error are ignored.

Only the extra error is penalized.

---

# Why Ignore Small Errors?

Suppose

Actual House Price

```
₹50,00,000
```

Prediction

```
₹49,90,000
```

Difference

```
₹10,000
```

For a ₹50 lakh house,

₹10,000 is a very small error.

SVR says

> "I won't change the entire model just to reduce such a tiny difference."

This makes SVR less sensitive to noise.

# Key Takeaways

- **x** = One input sample (feature vector).
- **w** = Learned weights representing feature importance.
- **b** = Bias that shifts the decision boundary.
- **y** = Actual output used only during training.
- **Classification SVM** predicts classes (+1 or -1).
- **Support Vector Regression (SVR)** predicts continuous values.
- **SVR ignores small errors inside the ε-tube and penalizes only errors outside it.**
