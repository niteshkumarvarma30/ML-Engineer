## An advantage of SVMs

### Concept: The Power of Support Vectors
In the ultimate showdown between Logistic Regression and Support Vector Machines, each model has a distinct superpower.

Because an SVM minimizes the Hinge Loss, it creates a massive "Zero Loss" zone. Any data point that is correctly classified and safely away from the boundary line receives a penalty of zero, causing the SVM to completely delete that point from its memory. It only calculates the math for the "Support Vectors" (the tricky points near the boundary).

---

### Instructions

**Question:** Which of the following is an advantage of SVMs over logistic regression?

**Possible Answers:**
* [ ] (1) They naturally output meaningful probabilities.
* [ ] (2) They can be used with kernels.
* [x] (3) They are computationally efficient with kernels.
* [ ] (4) They learn sigmoidal decision boundaries.

---

### Solution

**Correct Answer:** `(3)`

**Why this is correct:**
* Option 1 is false: This is the superpower of Logistic Regression, not SVMs.
* Option 2 is a trick: Technically, *any* machine learning model can be used with a kernel if you manually transform the data yourself before training. 
* **Option 3 is true:** Because SVMs delete 90% of the dataset (the non-support vectors), they are incredibly fast. This computational efficiency is what actually allows the math-heavy Kernel Trick to be run on normal computers without crashing!
* Option 4 is false: Neither model learns a sigmoidal boundary. They both learn straight linear boundaries in their given feature space.
