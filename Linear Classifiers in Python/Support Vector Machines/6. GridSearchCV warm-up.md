## GridSearchCV warm-up

### Concept: How GridSearchCV is used in SVMs
Support Vector Machines (especially Non-Linear ones using the RBF kernel) are notoriously sensitive to their hyperparameters. If you just use the default settings, an SVM can easily fail completely or massively overfit.

To make an SVM work well, you usually have to tune two main dials:
1. **C (Regularization):** Controls how strict the margin is (how much it cares about misclassified points).
2. **gamma (Smoothness):** Controls how tight and jagged the decision boundary curves are.

Because you don't know the perfect combination of `C` and `gamma` in advance, you use `GridSearchCV`. You give it a list of `C` values and a list of `gamma` values, and it exhaustively tests every single combination using cross-validation to find the absolute best setup for your specific dataset.

### Solution

```python
from sklearn.svm import SVC
from sklearn.model_selection import GridSearchCV

# Instantiate an RBF SVM
svm = SVC()

# Instantiate the GridSearchCV object and run the search
parameters = {'gamma':[0.00001, 0.0001, 0.001, 0.01, 0.1]}

# 1. You have to hand GridSearchCV two things: the model (svm) and the menu (param_grid)
searcher = GridSearchCV(svm, param_grid=parameters)

# 2. You have to call .fit() on the searcher object, and pass in your features (X) and target (y)
searcher.fit(X, y)

# Report the best parameters
print("Best CV params", searcher.best_params_)
```

**Takeaway:** Behind the scenes, this single `.fit()` line is going to build 5 different SVM models (one for each gamma value in your list), test them all using cross-validation, and then automatically save the best one so you can print it out on line 10!
