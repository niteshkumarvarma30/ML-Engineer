## Minimizing a loss function

### Concept: Finding the Best Coefficients
In the previous concepts, we learned that a linear model makes predictions using a dot product: `y_pred = Coefficients @ Features`. But how does the model find the best coefficients (`w`) in the first place? 

It uses a **Loss Function** and an **Optimizer**.
* The **Loss Function** (like Squared Error) calculates how bad the current coefficients are. 
* The **Optimizer** (`scipy.optimize.minimize`) tries hundreds of different coefficient combinations until it finds the ones that produce the lowest possible loss.

In this exercise, you'll implement linear regression "from scratch" using `scipy.optimize.minimize`. We'll train a model on a housing price data set, which is already loaded into the variables `X` and `y`. For simplicity, we won't include an intercept in our regression model.

### Solution

```python
from scipy.optimize import minimize
from sklearn.linear_model import LinearRegression

# The squared error, summed over training examples
def my_loss(w):
    s = 0
    for i in range(y.size):
        # Get the true and predicted target values for example 'i'
        y_i_true = y[i]
        y_i_pred = w@X[i]
        # The loss is the difference between the true and predicted values, squared!
        s = s + (y_i_true - y_i_pred)**2
    return s

# Returns the w that makes my_loss(w) smallest
w_fit = minimize(my_loss, X[0]).x
print(w_fit)

# Compare with scikit-learn's LinearRegression coefficients
lr = LinearRegression(fit_intercept=False).fit(X,y)
print(lr.coef_)
```

**Takeaway:** The custom `my_loss` function we built using the squared error formula will produce the exact same coefficients as scikit-learn's built-in `LinearRegression` model! Scikit-learn is just doing this optimization process for you behind the scenes.
