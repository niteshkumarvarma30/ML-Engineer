## Comparing the logistic and hinge losses

### Concept: The Mathematical Equations
We know that Logistic Regression and Linear SVMs use different loss functions during training. But what do the actual mathematical equations for these penalties look like?

* **Logistic Loss (Logistic Regression):** Uses a smooth logarithmic curve.
* **Hinge Loss (SVM):** Uses a sharp angle (like a hinge) that flattens out at exactly 0.

### Solution

```python
import numpy as np
import matplotlib.pyplot as plt

# Mathematical functions for logistic and hinge losses
def log_loss(raw_model_output):
   return np.log(1+np.exp(-raw_model_output))
   
def hinge_loss(raw_model_output):
   return np.maximum(0, 1-raw_model_output)

# Create a grid of values and plot
grid = np.linspace(-2,2,1000)

# Pass the grid array directly into our custom loss functions!
plt.plot(grid, log_loss(grid), label='logistic')
plt.plot(grid, hinge_loss(grid), label='hinge')
plt.legend()
plt.show()
```

**Takeaway:** When plotted, you can clearly see the difference. The **Hinge Loss** is a straight diagonal line that sharply hits 0 and stays flat (like a hinge). The **Logistic Loss** is a smooth, continuous curve that gradually approaches 0. Because Logistic Loss is smooth, it is easier to calculate probabilities from it!
