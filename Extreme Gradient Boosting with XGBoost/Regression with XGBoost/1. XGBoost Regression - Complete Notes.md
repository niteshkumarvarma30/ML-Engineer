# 1. Why XGBoost?

Before learning XGBoost, we should ask:

> If Decision Trees already work well, why was XGBoost invented?

A single Decision Tree has several limitations.

## Problem 1: High Variance

A small change in the training data can produce a completely different tree.

```
Small Change in Data

↓

Completely Different Tree
```

---

## Problem 2: Overfitting

A deep tree memorizes the training data.

```
Training Accuracy = 100%

↓

Poor Test Accuracy
```

---

## Problem 3: One Tree Cannot Learn Everything

A single regression tree predicts piecewise constant values.

```
Real Function

      Smooth Curve

Decision Tree

Step-like Approximation
```

Prediction errors still remain.

---

# 2. Solution - Boosting

Instead of building

```
One Large Tree
```

XGBoost builds

```
Many Small Trees
```

Each new tree learns only the mistakes made by previous trees.

```
Tree 1

↓

Residuals

↓

Tree 2

↓

Residuals

↓

Tree 3

↓

Residuals

↓

Final Prediction
```

# 4. Stage 1 - Initial Prediction

Initially,

there is no tree.

No split.

No model.

Question

What should XGBoost predict?

---

Suppose prediction is

```
Prediction = C
```

for every sample.

The loss is

```
Loss

=

Σ(yi−C)²
```

Differentiate

```
dLoss/dC = 0
```

Result

```
C

=

Σyi / n
```

Therefore,

the best constant prediction is

```
Mean(Target Values)
```

---

```
6

8
```

```
(4.5+11+6+8)/4

=7.375

≈7.3
```

Initial Prediction

```
Everyone

↓

7.3
```

This is called the **Base Prediction**.

# 6. Residuals

Residual means

```
Residual

-

```


Interpretation

```

```

```

↓

```

```

↓

```

# 8. Similarity Score

To measure how good a node is,

XGBoost uses

```
                (Σ Residuals)²
SS = -------------------------------
          n + λ
```

where

- Σ Residuals = Sum of residuals in the node
- n = Number of samples
- λ = Regularization parameter

---

## Why Square the Sum?

Suppose

```
Residuals

3

4

5
```

Sum

```
12
```

All residuals point in the same direction.

Good node.

Suppose

```
3

-3

4

-4
```

Sum

```
0
```

Residuals cancel each other.

Bad node.

Squaring makes

```
(-10)²

=

(+10)²
```

Both are treated equally.

---

## Why Divide by n?

Without dividing,

large nodes automatically get larger scores.

Dividing by n normalizes the score.

---

## Why Add λ?

Suppose only one sample reaches a node.

Without λ

```
100² / 1

=10000
```

Huge score.

The tree will overfit.

Adding λ reduces this score.

---

# Example

Residuals

```
0.7

-2.8

-1.3

3.7
```

Sum

```
0.3
```

Square

```
0.09
```

Samples

```
4
```

Assume λ = 0

```
SS

=

0.09 / 4

=

0.0225

≈0.02
```

# 9. Gain

Every possible split is evaluated using

```
Gain

=

SS(left)

+

SS(right)

-

SS(parent)
```

Meaning

```
Improvement

After Splitting
```

---

## Example

Suppose

```
CGPA < 8.25
```

Left SS

```
3.85
```

Right SS

```
13.69
```

Parent SS

```
0.02
```

Gain

```
3.85

+

13.69

-

0.02

=

17.52
```

Large Gain means

```
Excellent Split
```

Instead of adding the full correction,

XGBoost uses

```
New Prediction

=

Old Prediction

+

η(Tree Output)
```

where

```
0 < η ≤ 1
```

Common values

```
0.3

0.1

0.05

0.01
```

---

## Example

```

```

```

```

```
0.3
```

```

=

```

The model makes a small correction instead of a large jump.

# 16. Why is it Called Gradient Boosting?

So far,

we used

```
Residual

=

Actual

-

Prediction
```

For Mean Squared Error

```
Loss

=

½(y−ŷ)²
```

Differentiate

```
dLoss/dŷ

=

-(y−ŷ)
```

Therefore

```
Negative Gradient

=

-(dLoss/dŷ)

=

(y−ŷ)

=

Residual
```

Thus,

Residuals are actually

```
Negative Gradients
```

Therefore

XGBoost trains trees on

```
Negative Gradient

instead of

Target Values
```

This is why the algorithm is called

```
Gradient Boosting
```

# 18. Complete Mathematical Flow

```
Dataset
        │
        ▼
Initial Prediction

ŷ₀ = Mean(Target)
        │
        ▼
Residual

ri = yi − ŷ
        │
        ▼
Build Regression Tree
        │
        ▼
Similarity Score

SS = (Σri)² / (n + λ)
        │
        ▼
Gain

Gain = SS(left)

     + SS(right)

     − SS(parent)
        │
        ▼
Best Split
        │
        ▼
Leaf Output

Output = Σri / (n + λ)
        │
        ▼
Prediction Update

ŷnew = ŷold + η(Output)
        │
        ▼
New Residuals
        │
        ▼
Repeat
        │
        ▼
Residuals ≈ 0
        │
        ▼
Final Prediction
```

# Key Takeaways

- XGBoost is an **ensemble of many small regression trees**.
- The first prediction is the **mean of the target values**, because it minimizes the squared error for a constant predictor.
- The difference between the actual value and the prediction is called the **residual**.
- Each new tree is trained to predict these **residuals (negative gradients)** rather than the original target values.
- XGBoost evaluates candidate splits using the **Similarity Score** and **Gain**, not Gini or Entropy.
- Each leaf predicts a **correction**, not the final target value.
- Predictions are updated gradually using the **learning rate (η)**.
- After every update, new residuals are computed and another tree is trained.
- This iterative correction process continues until the residuals become very small, producing the final XGBoost regression model.
