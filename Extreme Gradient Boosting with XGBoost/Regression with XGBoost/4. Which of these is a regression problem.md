# Exercise

## Which of these is a regression problem?

### Concept: Identifying the Task
Here are 4 potential machine learning problems you might encounter in the wild. Pick the one that is a clear example of a regression problem.

Remember the rule from our previous notes: Regression is the branch of machine learning where you try to predict a **continuous, real number** (like price, weight, or temperature) rather than a category.

### Possible Answers

1. Recommending a restaurant to a user given their past history of restaurant visits and reviews for a dining aggregator app.
2. Predicting which of several thousand diseases a given person is most likely to have given their symptoms.
3. Tagging an email as spam/not spam based on its content and metadata (sender, time sent, etc.).
4. Predicting the expected payout of an auto insurance claim given claim properties (car, accident type, driver prior history, etc.).

---

### Solution

**Correct Answer:** 4

**Explanation:**
* **Option 1 (Incorrect):** This is a Recommendation System problem, which typically uses collaborative filtering or matrix factorization, not standard regression.
* **Option 2 (Incorrect):** This is a Multi-class Classification problem. The model is predicting a distinct category (a specific disease out of thousands) rather than a continuous number.
* **Option 3 (Incorrect):** This is a Binary Classification problem (Spam vs. Not Spam).
* **Option 4 (Correct):** This is exactly a Regression problem! The expected payout of an insurance claim is a continuous real number (e.g., $1,245.50 or $8,000.00). Because there are infinite possible numerical answers on a sliding scale, this requires regression.
