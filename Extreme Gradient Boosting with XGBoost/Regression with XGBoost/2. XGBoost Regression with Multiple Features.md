# 9. Computing Gain

For every threshold,

XGBoost computes

```
Similarity Score (Left)

+

Similarity Score (Right)

-

Similarity Score (Parent)
```

```

=

SS(Left)

+

SS(Right)

-

SS(Parent)
```

Exactly the same mathematics

we studied earlier.

Nothing changes.

# Key Takeaways

- The mathematics of XGBoost does **not change** when multiple features are present.
- The initial prediction is still the **mean of the target values**.
- Residuals are computed in the same way for every training sample.
- At each node, XGBoost evaluates **every feature** independently.
- For each feature, it tests **every possible threshold**.
- For every candidate split, it computes the **Similarity Score** and **Gain**.
- The feature and threshold with the **maximum Gain** become the split for that node.
- After splitting, **all features become available again** for every child node.
- Different levels of the tree may use **different features**, depending on which one provides the highest Gain.
- This process repeats recursively for every tree in the ensemble until the training process is complete.
