# Concept

## Tuning XGBoost Inside a Pipeline

Up to this point, we have done two things separately:
1. We put an XGBoost model inside a Pipeline to automatically scale our data and prevent data leakage.
2. We used `RandomizedSearchCV` to magically test hundreds of hyperparameter combinations to find the best model.

Now, we are going to combine them. We are going to pass the *entire pipeline* into the Randomized Search!

---

### 1. The Problem: The Lost Delivery Driver

Imagine your Pipeline is a giant assembly line inside a factory.
* **Machine 1** is the `StandardScaler`.
* **Machine 2** is the `XGBRegressor`.

`RandomizedSearchCV` is like a delivery driver trying to drop off new, upgraded parts (hyperparameters like `max_depth` and `learning_rate`).

If you just hand the driver a box labeled `max_depth: 5` and say "deliver this to the factory," the driver will get confused. They will look at the assembly line and say, *"Wait, do I plug this into the Scaler machine, or the XGBoost machine? I don't know where this belongs!"* The code will crash.

---

### 2. The Solution: The Double Underscore Trick (`__`)

To fix this, you must write a highly specific "shipping address" on the box of hyperparameters. You do this using a **Double Underscore** (`__`).

When you build your pipeline, you name your steps:
`Pipeline([ ("st_scaler", StandardScaler()), ("xgb_model", xgb.XGBRegressor()) ])`

When you build your hyperparameter grid, you combine the **Step Name** + `__` + **Hyperparameter Name**.

* **Wrong:** `{'max_depth': [3, 5, 7]}` *(The driver is lost).*
* **Right:** `{'xgb_model__max_depth': [3, 5, 7]}` *(The driver knows exactly where to go!)*

**Translation:** *"Hey Searcher, walk into the factory, find the machine named `xgb_model`, look inside it, and change its `max_depth` setting."*

---

### 3. The Ultimate Machine Learning Code

Here is the exact code from your screenshots, combining everything we have learned into one seamless, professional workflow.

```python
import pandas as pd
import numpy as np
import xgboost as xgb
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.model_selection import RandomizedSearchCV

# 1. Load the Data
names = ["crime", "zone", "industry", "charles", "no", "rooms", 
         "age", "distance", "radial", "tax", "pupil", "aam", "lower", "med_price"]
data = pd.read_csv("boston_housing.csv", names=names)

X, y = data.iloc[:, :-1], data.iloc[:, -1]

# ==========================================
# 2. BUILD THE PIPELINE
# ==========================================
# Step 1: Scale the data. Step 2: XGBoost.
xgb_pipeline = Pipeline([
    ("st_scaler", StandardScaler()), 
    ("xgb_model", xgb.XGBRegressor())
])

# ==========================================
# 3. CREATE THE PARAMETER GRID (The Menu)
# ==========================================
# NOTICE THE DOUBLE UNDERSCORES! We are routing these settings directly to "xgb_model"
gbm_param_grid = {
    'xgb_model__subsample': np.arange(.05, 1, .05),
    'xgb_model__max_depth': np.arange(3, 20, 1),
    'xgb_model__colsample_bytree': np.arange(.1, 1.05, .05)
}

# ==========================================
# 4. RUN THE RANDOMIZED SEARCH
# ==========================================
# We pass the ENTIRE pipeline in as the estimator!
randomized_neg_mse = RandomizedSearchCV(estimator=xgb_pipeline,
                                        param_distributions=gbm_param_grid, 
                                        n_iter=10, # Test 10 random combinations
                                        scoring='neg_mean_squared_error', 
                                        cv=4)

# Fit it to the raw data (The pipeline will handle the scaling internally for every fold!)
randomized_neg_mse.fit(X, y)

# ==========================================
# 5. EXTRACT THE WINNERS
# ==========================================
# Calculate the final RMSE score (flip the negative sign and take the square root)
best_rmse = np.sqrt(np.abs(randomized_neg_mse.best_score_))
print(f"Best rmse: {best_rmse}")

# Print the absolute best pipeline configuration it found!
print("Best model: ", randomized_neg_mse.best_estimator_)
```

#### Why this is the "Holy Grail" of ML Code:

With this one block of code, you have built a system that automatically slices the data into cross-validation folds, perfectly scales the data without any leakage, and intelligently searches through thousands of hyperparameters to find the optimal XGBoost model. 

This is exactly how professional data scientists write production-ready code!
