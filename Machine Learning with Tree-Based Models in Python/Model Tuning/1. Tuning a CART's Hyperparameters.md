# Concept

## Tuning a CART's Hyperparameters

We know that a Decision Tree (CART) plays a game of "20 Questions" to classify data. But how do we ensure it plays the best possible game? We have to tune its settings!

To understand this, we must first understand the difference between the two types of settings in machine learning.

---

### 1. Parameters vs. Hyperparameters

**Parameters (Learned by the Model):** These are the things the model figures out on its own during training by looking at the data.
* **Example in a CART:** The exact feature to split on (e.g., "Weight") and the exact split-point (e.g., "> 20 lbs").

**Hyperparameters (Set by the Human):** These are the strict rules you must set *before* the training even begins. The model cannot learn these; you have to guess them.
* **Example in a CART:** The maximum depth of the tree (`max_depth`), or the minimum number of samples allowed in a leaf (`min_samples_leaf`).

**Why tune them?** Scikit-learn provides default hyperparameters (like letting the tree grow infinitely deep), but these defaults are rarely optimal for your specific dataset. If you leave them on default, you will likely overfit.

---

### 2. Grid Search Cross-Validation (The Brute Force Method)

Because we don't know the perfect hyperparameters in advance, we use Grid Search Cross-Validation (`GridSearchCV`).

Imagine you are at a restaurant and you want the perfect meal, but you don't know what to order.

* **The Grid (The Menu):** You create a menu of options you want to test. (e.g., Test `max_depth` of 2, 4, and 6. Test `min_samples_leaf` of 0.1 and 0.2).
* **The Exhaustive Search:** The computer orders every single combination on the menu. (Depth 2 + Leaf 0.1, Depth 2 + Leaf 0.2, Depth 4 + Leaf 0.1, etc.).
* **Cross-Validation:** It tastes every meal using K-Fold Cross Validation to get a highly accurate score.
* **The Winner:** It looks at all the scores and tells you exactly which combination tasted the best!

> [!WARNING]
> **The Danger: "The Curse of Dimensionality"**
> Grid search is exhaustive. If you put 10 options for parameter A, 10 for parameter B, and 10 for parameter C, the computer has to test 1,000 combinations. If you use 10-Fold CV, it has to train the model 10,000 times. The bigger your grid (more dimensions), the longer your computer will take to run.

---

### 3. Extracting the Best Model

When GridSearchCV is finished, it saves the winning results inside special attributes (variables that end with an underscore `_`):

* `best_params_`: Prints out the exact winning combination (e.g., `{'max_depth': 4, 'min_samples_leaf': 0.1}`).
* `best_score_`: Prints out the Cross-Validation accuracy that the winning combination achieved.
* `best_estimator_`: This is the ultimate prize. By default, once GridSearchCV finds the best hyperparameters, it automatically builds a brand new model using those settings and trains it on your entire training dataset.

---

### 4. Cheat Sheet: Python Code

Here is how you tune a Decision Tree in scikit-learn!

```python
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import GridSearchCV, train_test_split
from sklearn.metrics import accuracy_score

# 1. Split the data
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, stratify=y, random_state=1)

# 2. Instantiate a blank model
dt = DecisionTreeClassifier(random_state=1)

# (Optional) You can check all available hyperparameters by calling:
# print(dt.get_params())

# 3. Create the hyperparameter grid (The Menu)
params_dt = {
    'max_depth': [2, 3, 4],
    'min_samples_leaf': [0.12, 0.14, 0.16, 0.18]
}

# 4. Instantiate the Grid Search
# cv=10 means 10-Fold Cross-Validation
grid_dt = GridSearchCV(estimator=dt, param_grid=params_dt, scoring='accuracy', cv=10, n_jobs=-1)

# 5. Fit the Grid Search to the training data (The Exhaustive Search begins!)
grid_dt.fit(X_train, y_train)

# 6. Extract the best results
print("Best Hyperparameters:", grid_dt.best_params_)
print("Best CV Score:", grid_dt.best_score_)

# 7. Extract the ultimate optimized model and test it on the unseen vault data!
best_model = grid_dt.best_estimator_
test_accuracy = best_model.score(X_test, y_test)

print("Final Test Set Accuracy:", test_accuracy)
```
