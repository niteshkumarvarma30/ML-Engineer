## Random forests hyperparameters

### Concept: Checking the Hyperparameters
Before tuning a Random Forest Regressor, we need to know what settings we are allowed to change. Because a Random Forest is an *ensemble* of Decision Trees, it has all the standard tree hyperparameters (like `max_depth`), plus extra ensemble hyperparameters (like `n_estimators`). 

However, it does *not* have boosting hyperparameters, because it is a bagging ensemble!

### Instructions
In the following exercises, you'll be revisiting the **Bike Sharing Demand** dataset that was introduced in a previous chapter. Recall that your task is to predict the bike rental demand using historical weather data from the Capital Bikeshare program in Washington, D.C.. For this purpose, you'll be tuning the hyperparameters of a Random Forests regressor.

We have instantiated a `RandomForestRegressor` called `rf` using `sklearn`'s default hyperparameters. You can inspect the hyperparameters of `rf` in your console.

Which of the following is not a hyperparameter of `rf`?

### Possible Answers
* `min_weight_fraction_leaf`
* `criterion`
* **`learning_rate`** (Correct Answer)
* `warm_start`

### Solution
The correct answer is `learning_rate`. Random Forests do not use a learning rate; that hyperparameter belongs exclusively to Boosting ensembles like AdaBoost and Gradient Boosting!
