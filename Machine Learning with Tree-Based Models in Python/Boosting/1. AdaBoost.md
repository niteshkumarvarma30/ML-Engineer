# Concept

## AdaBoost

In our previous guides on Bagging and Random Forests, we learned how to build an army of hundreds of Decision Trees *at the same time* and let them vote.

**Boosting** is a completely different type of ensemble. Instead of building the trees at the same time, you build them **sequentially** (one after the other). Tree #2 is specifically built to fix the mistakes made by Tree #1!

The most famous boosting algorithm is AdaBoost (Adaptive Boosting).

---

### 1. Weak Learners vs. Strong Learners

In a Random Forest, we let our trees grow relatively deep. We wanted them to be smart.
In Boosting, we deliberately use **Weak Learners**.

**What is a Weak Learner?** A model that does just slightly better than random guessing.

**The Decision Stump:** In AdaBoost, we almost always use a "Decision Stump". This is a Decision Tree with a `max_depth` of exactly 1. It is only allowed to ask *one single question* before making a guess.

**The Magic:** How can an army of 100 dumb stumps beat an army of 100 smart trees? By learning from each other's mistakes!

---

### 2. How AdaBoost Works (The Red Highlighter)

Imagine a classroom where 100 students (our decision stumps) take turns taking a test.

1. **Student 1 (Tree 1):** Takes the test and gets 70% right, but misses 30% of the questions.
2. **The Adjustment (Weights):** The teacher (AdaBoost) takes a bright red highlighter and highlights all the questions Student 1 got wrong. It assigns a **higher weight** to those specific data points.
3. **Student 2 (Tree 2):** Takes the test next. Because the teacher highlighted those specific questions in red, Student 2 is mathematically forced to pay extra attention to them. Student 2 gets those red questions right, but misses some different ones.
4. **Repeat:** The teacher highlights the new mistakes in red, and Student 3 takes the test.

This happens 100 times in a row. Every single tree is laser-focused on fixing the blind spots of the tree that came right before it!

---

### 3. Alpha ($\alpha$) and The Final Vote

When all 100 trees are finished, how do they make a final prediction? They use a **Weighted Majority Vote**.

Not all trees get an equal vote. AdaBoost calculates a score for each tree called **Alpha ($\alpha$)**.

* If a tree had a very low error rate, it gets a **High Alpha**. Its vote counts heavily in the final election.
* If a tree did poorly, it gets a **Low Alpha**. Its vote barely counts.

---

### 4. The Learning Rate ($\eta$)

There is one major hyperparameter you can tune in AdaBoost: **The Learning Rate** (Eta, or $\eta$).

The Learning Rate is a number between 0 and 1 that shrinks the Alpha scores. It basically tells the model: *"Don't trust any single tree too much. Slow down and learn gradually."*

**The Trade-off:** If you make the Learning Rate very small (e.g., 0.1), the model learns very slowly. To compensate for this slow learning, you must give it more trees by increasing the `n_estimators` (e.g., 500 trees instead of 100).

---

### 5. Cheat Sheet: Python Code

Here is how you build an AdaBoost classifier in scikit-learn. Notice that we have to instantiate a Decision Stump *first*, and then hand it to the AdaBoost engine!

> [!NOTE]
> We are using the ROC-AUC Score to evaluate it, which means we MUST use `.predict_proba()` instead of `.predict()`!

```python
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import AdaBoostClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import roc_auc_score

# 1. Split the data
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=1)

# 2. Instantiate the Weak Learner (The Decision Stump)
# max_depth=1 forces it to only ask one question!
dt = DecisionTreeClassifier(max_depth=1, random_state=1)

# 3. Instantiate the AdaBoost Classifier
# We hand it the stump, and tell it to build a sequential army of 100 stumps.
adb_clf = AdaBoostClassifier(base_estimator=dt, n_estimators=100, random_state=1)

# 4. Fit the model to the training data
# (Behind the scenes, it is constantly updating the weights of the missed questions!)
adb_clf.fit(X_train, y_train)

# 5. Predict PROBABILITIES for the Test Set
# We need probabilities to calculate the ROC-AUC score. We slice [:, 1] to get the Positive class.
y_pred_proba = adb_clf.predict_proba(X_test)[:, 1]

# 6. Evaluate using ROC-AUC
auc_score = roc_auc_score(y_test, y_pred_proba)
print(f"AdaBoost ROC-AUC Score: {auc_score:.2f}")
```
