## Define the GB regressor

### Concept: The Sequential Regressor
Unlike AdaBoost which we used for Classification (predicting if someone has liver disease), we are going to use Gradient Boosting for Regression (predicting a continuous number). We will revisit the Capital Bikeshare dataset from the Random Forests chapter to see if Gradient Boosting can beat our old RMSE score!

Notice that unlike AdaBoost, we do **not** need to instantiate a separate Decision Tree first! The `GradientBoostingRegressor` automatically assumes you want to use Decision Trees, so you can pass the tree's hyperparameters (like `max_depth`) directly into the ensemble itself.

### Instructions
You'll now revisit the **Bike Sharing Demand** dataset that was introduced in the previous chapter. Recall that your task is to predict the bike rental demand using historical weather data from the Capital Bikeshare program in Washington, D.C.. For this purpose, you'll be using a gradient boosting regressor.

As a first step, you'll start by instantiating a gradient boosting regressor which you will train in the next exercise.

* Import `GradientBoostingRegressor` from `sklearn.ensemble`.
* Instantiate a gradient boosting regressor by setting the parameters:
  * `max_depth` to 4
  * `n_estimators` to 200

### Solution

```python
# Import GradientBoostingRegressor
from sklearn.ensemble import GradientBoostingRegressor

# Instantiate gb
gb = GradientBoostingRegressor(max_depth=4, 
            n_estimators=200,
            random_state=2)
```
