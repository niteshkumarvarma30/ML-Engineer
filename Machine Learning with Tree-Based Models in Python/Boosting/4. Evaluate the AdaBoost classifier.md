## Evaluate the AdaBoost classifier

### Concept: The ROC-AUC Score
Now that we have successfully extracted the predicted probabilities for the positive class (`y_pred_proba`), we can pass them into the `roc_auc_score` function along with the true labels (`y_test`).

The ROC-AUC score is a brilliant metric for imbalanced datasets because it measures the model's ability to successfully rank positive instances higher than negative instances, regardless of the strict 50% cutoff threshold used by standard accuracy. 

A score of 0.5 is no better than random guessing, while a score of 1.0 is absolute perfection!

### Instructions
Now that you're done training `ada` and predicting the probabilities of obtaining the positive class in the test set, it's time to evaluate `ada`'s ROC AUC score. Recall that the ROC AUC score of a binary classifier can be determined using the `roc_auc_score()` function from `sklearn.metrics`.

The arrays `y_test` and `y_pred_proba` that you computed in the previous exercise are available in your workspace.

* Import `roc_auc_score` from `sklearn.metrics`.
* Compute `ada`'s test set ROC AUC score, assign it to `ada_roc_auc`, and print it out.

### Solution

```python
# Import roc_auc_score
from sklearn.metrics import roc_auc_score

# Evaluate test-set roc_auc_score
ada_roc_auc = roc_auc_score(y_test, y_pred_proba)

# Print roc_auc_score
print('ROC AUC score: {:.2f}'.format(ada_roc_auc))
```
