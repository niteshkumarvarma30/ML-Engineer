## Train the AdaBoost classifier

### Concept: Probabilities vs. Hard Predictions
When we call `.fit()`, AdaBoost runs through its 180 trees sequentially, constantly updating the weights (the "Red Highlighter") to force the next tree to focus on the previous tree's mistakes.

Once training is complete, we need to evaluate it. Because the Indian Liver Patient dataset is highly imbalanced, standard Accuracy is a terrible metric. We need to use the ROC-AUC score.

To calculate the ROC-AUC score, we cannot use `.predict()` (which outputs hard labels like 0 or 1). We MUST use `.predict_proba()` to get the raw percentage probabilities (e.g., "I am 85% sure this patient has liver disease"). 

`predict_proba()` returns a 2D array with two columns:
* Column 0: Probability of the Negative Class (0)
* Column 1: Probability of the Positive Class (1)

We slice `[:, 1]` to grab only the positive probabilities!

### Instructions
