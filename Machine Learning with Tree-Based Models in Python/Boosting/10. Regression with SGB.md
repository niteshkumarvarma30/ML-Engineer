## Regression with SGB

### Concept: Adding the Stochastic Blindfolds
Because Scikit-Learn is so brilliant, we don't have to import a totally different model to use Stochastic Gradient Boosting. We just use the standard `GradientBoostingRegressor` and explicitly turn on the random blindfolds during instantiation!

By setting `subsample=0.9`, we are forcing every single tree to randomly drop 10% of the training rows. 
By setting `max_features=0.75`, we are forcing every single tree to randomly ignore 25% of the columns when looking for the best split!

This simple change forces the 200 trees to learn vastly different patterns, destroying the "exhaustive copycat" problem of standard Gradient Boosting.

### Instructions
As in the exercises from the previous lesson, you'll be working with the **Bike Sharing Demand** dataset. In the following set of exercises, you'll solve this bike count regression problem using stochastic gradient boosting.

* Instantiate a Stochastic Gradient Boosting Regressor (SGBR) and set:
  * `max_depth` to 4 and `n_estimators` to 200,
  * `subsample` to 0.9, and
  * `max_features` to 0.75.

### Solution

```python
# Import GradientBoostingRegressor
from sklearn.ensemble import GradientBoostingRegressor

# Instantiate sgbr
sgbr = GradientBoostingRegressor(max_depth=4, 
            subsample=0.9,
            max_features=0.75,
            n_estimators=200,
            random_state=2)
```
