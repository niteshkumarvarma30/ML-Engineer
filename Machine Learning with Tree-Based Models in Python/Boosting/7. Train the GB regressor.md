## Train the GB regressor

### Concept: Predicting the Mistakes
When we call `.fit()`, an incredible mathematical relay race begins behind the scenes. 

The first tree takes a swing at predicting the bike rentals. It inevitably makes mistakes. The Gradient Boosting engine calculates the exact Residual Errors (the distance between the prediction and the actual truth), and hands those errors to the second tree. 

Tree 2 completely ignores the actual bike rentals, and trains itself *only* to predict Tree 1's mistakes! It then passes its own mistakes to Tree 3, and so on for 200 trees. 

Finally, when we call `.predict(X_test)`, the engine passes the new data through all 200 trees, adds up all their tiny adjustments (shrunk by the Learning Rate), and spits out the final `y_pred`.

* Fit `gb` to the training set.
