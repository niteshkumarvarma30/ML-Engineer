## Logistic regression vs classification tree

### Concept: Comparing Decision Boundaries
A classification tree divides the feature space into **rectangular regions**. This is because at every split, the tree asks a question about a single feature (e.g., "Is X > 5?"), which draws perfectly straight horizontal or vertical lines on a graph.

In contrast, a linear model such as **Logistic Regression** produces only a single linear decision boundary, drawing one straight diagonal line that divides the feature space into two regions.
