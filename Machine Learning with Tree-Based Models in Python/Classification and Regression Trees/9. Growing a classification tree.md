## Growing a classification tree

### Concept: Maximizing Information Gain
When building a classification tree, the algorithm tests every possible feature and every possible split-point to find the question that best separates the data into pure classes. The mathematical measure of this improvement is called **Information Gain**.

Because we want the resulting child nodes to be as pure as possible, the algorithm always selects the split that **maximizes** Information Gain. It does not minimize it!

### Question
In the video, you saw that the growth of an unconstrained classification tree followed a few simple rules. Which of the following is **not** one of these rules?

**Possible Answers:**
1. The existence of a node depends on the state of its predecessors.
2. The impurity of a node can be determined using different criteria such as entropy and the gini-index.
3. When the information gain resulting from splitting a node is null, the node is declared as a leaf.
4. When an internal node is split, the split is performed in such a way so that information gain is minimized.

### Solution

**Correct Answer: 4**

*When an internal node is split, the split is performed in such a way so that information gain is minimized.*

**Explanation:**
This statement is false. The goal of a decision tree split is to increase purity as much as possible, which means the split must be performed in such a way that Information Gain is **maximized**, not minimized!
