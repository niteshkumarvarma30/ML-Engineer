## Evaluate the classification tree

### Concept: Evaluating Model Performance
Now that you've fit your first classification tree, it's time to evaluate its performance on the test set. For classification tasks, the most common metric is **Accuracy**, which corresponds to the fraction of correct predictions made on the test set.

We can compute this using `accuracy_score` from `sklearn.metrics`. It compares the true labels (`y_test`) against the predicted labels (`y_pred`).

### Instructions
* Import the function `accuracy_score` from `sklearn.metrics`.
* Predict the test set labels and assign the obtained array to `y_pred`.
* Evaluate the test set accuracy score of `dt` by calling `accuracy_score()` and assign the value to `acc`.

### Solution

```python
# Import accuracy_score
from sklearn.metrics import accuracy_score

# Predict test set labels
y_pred = dt.predict(X_test)

# Compute test set accuracy
acc = accuracy_score(y_test, y_pred)
print("Test set accuracy: {:.2f}".format(acc))
```
