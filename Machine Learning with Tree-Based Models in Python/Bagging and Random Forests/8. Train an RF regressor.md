## Train an RF regressor

### Concept: Blindfolding the Trees
Because we are predicting Bike Rentals (a continuous number), we will use the `RandomForestRegressor` instead of the Classifier.

When we instantiate this model and set `n_estimators=25`, we are telling the computer to build a Jury of 25 trees. However, unlike standard Bagging, these 25 trees will automatically have **Feature Sampling** turned on. At every single split, Scikit-Learn will randomly blindfold the tree to a large portion of the features, forcing the trees to look at different clues and mathematically guaranteeing a highly diverse Jury!

### Instructions
In the following exercises you'll predict bike rental demand in the Capital Bikeshare program in Washington, D.C using historical weather data from the **Bike Sharing Demand** dataset available through Kaggle. For this purpose, you will be using the random forests algorithm. As a first step, you'll define a random forests regressor and fit it to the training set.

The dataset is processed for you and split into 80% train and 20% test. The features matrix `X_train` and the array `y_train` are available in your workspace.

* Import `RandomForestRegressor` from `sklearn.ensemble`.
* Instantiate a `RandomForestRegressor` called `rf` consisting of 25 trees.
* Fit `rf` to the training set.

### Solution

```python
# Import RandomForestRegressor
from sklearn.ensemble import RandomForestRegressor

# Instantiate rf
rf = RandomForestRegressor(n_estimators=25,
            random_state=2)
            
# Fit rf to the training set    
rf.fit(X_train, y_train) 
```
