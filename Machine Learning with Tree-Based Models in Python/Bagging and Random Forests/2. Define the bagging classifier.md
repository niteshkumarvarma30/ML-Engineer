## Define the bagging classifier

### Concept: Building the Magic Hat
In our concept guide, we learned that Bagging requires two things: a Base Estimator (the model we are going to copy), and the number of copies we want to make.

In this exercise, we will use a simple, unconstrained Decision Tree as our Base Estimator. Then, we will tell the `BaggingClassifier` to create 50 slightly different copies of it (50 `n_estimators`). Behind the scenes, the `BaggingClassifier` will automatically handle all of the Bootstrapping (Sampling with Replacement) to create 50 slightly different training datasets for our 50 trees!

### Instructions
In the following exercises you'll work with the **Indian Liver Patient** dataset from the UCI machine learning repository. Your task is to predict whether a patient suffers from a liver disease using 10 features including Albumin, age and gender. You'll do so using a Bagging Classifier.

* Import `DecisionTreeClassifier` from `sklearn.tree` and `BaggingClassifier` from `sklearn.ensemble`.
* Instantiate a `DecisionTreeClassifier` called `dt`.
* Instantiate a `BaggingClassifier` called `bc` consisting of 50 trees.

### Solution

```python
# Import DecisionTreeClassifier
from sklearn.tree import DecisionTreeClassifier

# Import BaggingClassifier
from sklearn.ensemble import BaggingClassifier

# Instantiate dt
dt = DecisionTreeClassifier(random_state=1)

# Instantiate bc
bc = BaggingClassifier(base_estimator=dt, n_estimators=50, random_state=1)
```
