## Better performance with a Voting Classifier

### Concept: The Power of Hard Voting
Now it is time to build the Meta-Model! 

We will pass our list of 3 classifiers directly into `VotingClassifier`. When we ask the Voting Classifier to predict the test data, it secretly runs the data through all 3 individual models behind the scenes. 

If Logistic Regression and the Decision Tree both vote "1" (Malignant), but KNN votes "0" (Benign), the Voting Classifier takes a majority vote and outputs "1". By covering each other's blind spots, the ensemble almost always achieves a higher accuracy than any of the individual models could on their own!

### Instructions
Finally, you'll evaluate the performance of a voting classifier that takes the outputs of the models defined in the list `classifiers` and assigns labels by majority voting.

`X_train`, `X_test`, `y_train`, `y_test`, the list `classifiers` defined in a previous exercise, as well as the function `accuracy_score` from `sklearn.metrics` are available in your workspace.

* Import `VotingClassifier` from `sklearn.ensemble`.
* Instantiate a `VotingClassifier` by setting the parameter `estimators` to `classifiers` and assign it to `vc`.
* Fit `vc` to the training set.
* Evaluate `vc`'s test set accuracy using the test set predictions `y_pred`.

### Solution

```python
# Import VotingClassifier from sklearn.ensemble
from sklearn.ensemble import VotingClassifier

# Instantiate a VotingClassifier vc
vc = VotingClassifier(estimators=classifiers)     

# Fit vc to the training set
vc.fit(X_train, y_train)   

# Evaluate the test set predictions
y_pred = vc.predict(X_test)

# Calculate accuracy score
accuracy = accuracy_score(y_test, y_pred)
print('Voting Classifier: {:.3f}'.format(accuracy))
```
