# Exercise

## How many clusters in comic con data?

### Concept: Reading the Dendrogram
Given the dendrogram from the last exercise, how many clusters can you see in the data?

A dendrogram is stored in the variable `dn`. Use `plt.show()` to display the dendrogram.

### Instructions

**Possible answers:**
* `2 clusters`
* `3 clusters`
* `4 clusters`

### Solution

**Answer:** `2 clusters`

*(By drawing a horizontal line across the tallest vertical lines in the dendrogram, it will intersect exactly 2 lines, indicating 2 natural clusters).*
