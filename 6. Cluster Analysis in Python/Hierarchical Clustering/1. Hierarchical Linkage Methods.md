# Concept

## Hierarchical Linkage Methods

When we do Hierarchical Clustering, the algorithm starts with every data point as its own cluster, and slowly merges them together.

But how does it decide which two groups should merge next? It relies on a "Distance Matrix" generated by the `linkage()` function.

---

### 1. The Engine: `linkage()`

In SciPy, the `linkage()` function is the mathematical engine of hierarchical clustering. It calculates the distances and builds the entire family tree (from $N$ individual points all the way up to 1 giant universal cluster).

When you use `linkage()`, you have to set a parameter called `method`. This is a crucial dial that tells the algorithm exactly *how* to define the distance between two clusters.

---

### 2. The 3 Main Linkage Methods

Imagine you have two separate groups of people at a party, and you want to measure the distance between the two groups to see if they should merge. How do you measure it?

#### A. The `single` Method (The "Closest Friend" Rule)
* **How it works:** It measures the distance between the two *closest individuals* across the two groups. As long as one person in Group A is standing close to one person in Group B, the algorithm considers the entire groups to be close, and merges them.
* **The Result:** Because it only takes one "bridge" point to merge massive groups together, the `single` method often creates very long, stringy, dispersed, and loose clusters.

#### B. The `complete` Method (The "Farthest Friend" Rule)
* **How it works:** It measures the distance between the two *farthest individuals* across the two groups. It says: *"I will only merge these two groups if the two people standing the absolute furthest apart are still relatively close to each other."*
* **The Result:** This ensures that when groups merge, everyone in the new group is close to everyone else. It creates much tighter, more compact clusters than the `single` method.

#### C. The `ward` Method (The "Dense Center" Rule)
* **How it works:** Instead of looking at individual people on the edges, Ward's method uses variance math (Sum of Squares). It calculates where the new center of the merged group would be, and checks if merging them would make the group too messy.
* **The Result:** It heavily favors creating clusters that are highly dense and concentrated right around their centers. This is usually the default and most popular method to use!

*(Note: There are other methods like `average`, `centroid`, and `median`, which simply measure the distance between the mathematical middle-points of the groups!)*

---

### 3. The Label Maker: `fcluster()`

The `linkage()` function builds the tree, but it doesn't actually assign your data points into final teams (like Cluster 1, Cluster 2, etc.).

To get those final labels, you pass your completed linkage math into the `fcluster()` function.
`fcluster` basically takes a pair of scissors and "cuts" the family tree to create a specific number of groups.

You use the `criterion='maxclust'` argument to tell it exactly how many clusters you want!

---

### 4. Cheat Sheet: Python Code

Here is the exact two-step process for performing Hierarchical Clustering in Python using SciPy:

```python
import pandas as pd
from scipy.cluster.hierarchy import linkage, fcluster
import matplotlib.pyplot as plt
import seaborn as sns

# 1. THE MATH (Build the Tree)
# We pass our raw data into linkage() and choose our method.
# Let's use 'ward' to get nice, dense clusters!
distance_matrix = linkage(my_data, method='ward')

# 2. THE LABELS (Cut the Tree)
# We pass our distance_matrix into fcluster().
# We tell it we want exactly 3 clusters, using the 'maxclust' criterion.
cluster_labels = fcluster(distance_matrix, 3, criterion='maxclust')

# 3. VISUALIZING IT
# We can attach those labels to our dataframe and plot them using Seaborn!
my_data['Cluster_ID'] = cluster_labels

# Plot X vs Y, and color the dots using the 'Cluster_ID'
sns.scatterplot(x='X_Coordinate', y='Y_Coordinate', hue='Cluster_ID', data=my_data)
plt.title("Hierarchical Clustering (Ward Method)")
plt.show()
```

---

### Which method is the "Best"?

As the transcript notes at the end: **There is no one "right" method.**
If your data naturally forms long, stringy shapes (like a crescent moon), the `single` method might actually be the best! If your data forms tight, circular groupings, `ward` or `complete` will win. You always have to test them and visualize the results to see what fits your specific data best.
