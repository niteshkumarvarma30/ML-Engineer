# Concept

## Document Clustering

We just learned how to use K-Means to cluster the pixels in an image. Now, we are going to use it to cluster text!

If you go to Google News, the algorithm automatically groups dozens of articles about the "Indian Cricket Team" together. It doesn't do this by having a human read them; it uses Document Clustering and Natural Language Processing (NLP).

Because algorithms can only do math, we have to translate paragraphs of text into a grid of numbers. Here is the step-by-step process.

---

### 1. Clean and Tokenize (Prepping the Text)

Before we do any math, we have to clean the garbage out of the text.

*   **Remove Noise:** We delete punctuation, hyperlinks, and emoticons because they don't help us figure out the topic of an article.
*   **Remove Stop Words:** Words like "the", "is", and "are" appear in every single English sentence. They give us zero clues about the specific topic, so we delete them completely.
*   **Tokenization:** We take a full sentence and chop it up into individual words (called tokens).
*   *(Advanced Tip: Normalization):* We often group similar words together. For example, "run", "ran", and "running" are all converted into the single base word "run".

---

### 2. TF-IDF (Scoring the Words)

Now that we have clean words, we need to score them. To do this, we use a scikit-learn tool called `TfidfVectorizer`.

**TF-IDF** stands for **Term Frequency - Inverse Document Frequency**.
It is a brilliant scoring system that asks two questions:

1.  **Term Frequency (TF):** Does this word appear a lot in this specific article? *(If yes, score goes up).*
2.  **Inverse Document Frequency (IDF):** Does this word appear in every single article on the internet? *(If yes, the word is probably generic and useless, so the score goes down).*

**Example:** If the word "Cricket" appears 20 times in one article, but almost never in the other articles, it gets a massive TF-IDF score. The algorithm realizes: *"This specific word is highly unique and important to this specific document!"*

---

### 3. The Sparse Matrix (Saving Memory)

Once we score the words, we build a giant spreadsheet.

*   **Rows:** Every single article.
*   **Columns:** Every single unique word across the entire dataset (the Vocabulary).

If we have 1,000 articles and a vocabulary of 50,000 words, that is a grid of 50 million cells!
Because most articles only use a few hundred words, 99% of this spreadsheet will be filled with zeros.

To stop your computer from crashing, Python saves this as a **Sparse Matrix**. It is a special data format that only memorizes the cells with *actual* numbers in them, and completely ignores all the zeros, saving a massive amount of RAM.

---

### 4. Clustering & The SciPy Catch

Now we can finally run K-Means to cluster the articles!

**The SciPy Catch:**
The `kmeans` function in the `scipy` library *hates* sparse matrices. It literally cannot read them.
Before you run scipy K-Means, you must use the `.todense()` method. This forces the computer to unpack the matrix and put all the millions of zeros back in.
*(Warning: On a huge dataset, `.todense()` will crash your computer. For massive NLP datasets, data scientists abandon SciPy and use Scikit-Learn's K-Means instead, because it natively supports Sparse Matrices!)*

**Why no Elbow Plot?**
Because this dataset has thousands of variables (columns), the math gets incredibly messy. An Elbow Plot will look completely erratic, so we usually just have to guess our K (number of clusters) or base it on business logic.

---

### 5. Finding the Top Terms (Reading the Algorithm's Mind)

Once K-Means clusters the articles, how do we know what the clusters are about? (Remember, the computer just names them *Cluster 0* and *Cluster 1*).

We look at the **Cluster Centers (Centroids)**.
Because the Centroid is the mathematical "average" of the cluster, we can look at which words have the highest TF-IDF weights at that center.

*   If Cluster 0's top terms are: *"room, hotel, staff"*, we know it's a cluster of Hotel Reviews.
*   If Cluster 1's top terms are: *"bad, location, breakfast"*, we know it's a cluster of Complaints.

*(In Python, we use the `zip()` function to glue the list of vocabulary words to the list of Centroid weights, and sort them highest-to-lowest to see these top words!)*
