# Exercise

## Clustering with many features

### Concept: The Curse of Dimensionality
What should you do if you have too many features for clustering?

### Possible Answers

*   Visualize all the features
*   **Reduce features using a technique like Factor Analysis** *(Correct)*
*   Perform hierarchical clustering

### Explanation
When you have too many features (dimensions), the math behind distance calculations (like K-Means) starts to break down. This is known as the *Curse of Dimensionality*. Furthermore, you cannot physically visualize anything above 3 dimensions!

To solve this, advanced Data Scientists use dimensionality reduction techniques—such as Factor Analysis or PCA (Principal Component Analysis)—to compress hundreds of features down into 2 or 3 highly important features before running the clustering algorithm.
