# Intro to Data Preprocessing

Building a machine learning model is exactly like cooking a meal.

*   **Exploration & Cleaning:** Looking in the fridge to see what ingredients you have and washing the dirt off the vegetables.
*   **Preprocessing:** Chopping the vegetables into exact, uniform sizes so they actually fit into the cooking pot.
*   **Modeling:** Putting everything in the pot and cooking it.

Data Preprocessing is the crucial bridge between exploring your data and actually training your model.

## 1. Why do we Preprocess?

Machine learning algorithms are basically just giant calculators. Because they are calculators, they only understand numbers.

If you try to feed a text column (like "Color": Red, Blue, Green) into a machine learning model, the computer will instantly crash. You have to preprocess that data by translating the words into numbers.

Proper preprocessing ensures your models don't crash, run faster, and produce much more accurate, reliable results!

## 3. Removing Missing Data (The NaN Problem)

In the real world, data is messy. People forget to fill out forms, or sensors break. Pandas shows these empty cells as `NaN` (Not a Number).

Machine learning models hate missing data. One of your first preprocessing jobs is to get rid of it. Here are the 4 ways to do it:

### A. The "Nuke" Method (Drop all rows with missing data)

If you have 10,000 rows of data, and only 5 rows are missing information, the easiest thing to do is just delete those 5 rows entirely.

**The Code:** `df.dropna()`

**What it does:** If a row has even one single blank cell anywhere, the entire row is thrown in the trash.

```python
print(df)
```
| | A | B | C |
|---|---|---|---|
| 0 | 1.0 | NaN | 2.0 |
| 1 | 4.0 | 7.0 | 3.0 |
| 2 | 7.0 | NaN | NaN |
| 3 | NaN | 7.0 | NaN |
| 4 | 5.0 | 9.0 | 7.0 |

```python
print(df.dropna())
```
| | A | B | C |
|---|---|---|---|
| 1 | 4.0 | 7.0 | 3.0 |
| 4 | 5.0 | 9.0 | 7.0 |


### B. The "Trash the Column" Method

What if you have a column called "Secondary Email Address," and 99% of the cells are blank? You shouldn't delete 99% of your rows! You should just throw away the useless column.

**The Code:** `df.drop("Secondary Email", axis=1)`

**What it does:** The `axis=1` tells Pandas to look horizontally for a column with that name and completely delete it.

*(Note: We can also drop specific rows if we know their indices!)*

```python
print(df.drop([1, 2, 3]))
```
| | A | B | C |
|---|---|---|---|
| 0 | 1.0 | NaN | 2.0 |
| 4 | 5.0 | 9.0 | 7.0 |

### C. The "Targeted" Method (subset)

Usually, you only care about specific columns. Imagine a housing dataset. If a house is missing its "Roof Color," that's fine. But if it is missing its "Price," the row is completely useless to us.

**The Code:** `df.dropna(subset=["Price"])`

**What it does:** It tells Pandas: "Look at the data. If a row is missing the Roof Color, keep it. But if it is missing the Price, throw the row away."

### D. The "Minimum Requirement" Method (thresh)

Sometimes you just want to make sure a row has enough good data to be useful.

**The Code:** `df.dropna(thresh=10)`

**What it does:** It tells Pandas: "Only keep this row if it has at least 10 perfectly good, non-missing values. If it has 9 or fewer, delete it."
