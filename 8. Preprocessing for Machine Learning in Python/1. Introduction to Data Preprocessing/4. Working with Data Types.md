# Working with Data Types

Before we can do any advanced machine learning, we have to make sure our data is actually in the correct format. As we learned earlier, machine learning models are essentially giant calculators—they can only do math on numbers.

If a column looks like a number to you, but the computer thinks it's a word, the model will crash. Here is how we check and fix our data types!

## 1. The "Big 4" Pandas Data Types

When you load a spreadsheet into Pandas, the computer assigns a specific "Data Type" (or dtype) to every single column.

Here are the four most common types you will encounter:

*   **`int64` (Integers):** Whole numbers without a decimal point. (e.g., 5, 42, -10).
*   **`float64` (Floats):** Numbers that have a decimal point. (e.g., 3.14, 5.0, -0.99).
*   **`object` (Strings/Text):** This is what Pandas calls text or words. If a column has a mix of numbers and letters, Pandas will default to calling it an object. (e.g., "Apple", "User_123").
*   **`datetime64`:** A special format specifically for Dates and Times. (e.g., 2023-10-31 14:30:00). This format unlocks special features, like allowing you to easily extract just the "Month" or "Year".

*(Note: Don't let the "64" confuse you! It just means "64-bit", which is the amount of computer memory allocated to store the number. You can just think of them as normal Integers and Floats).*

## 3. The Problem: When Pandas Guesses Wrong

Sometimes, when you import a CSV file, Pandas makes a mistake.

We have a DataFrame with Column C. To our human eyes, Column C contains numbers: 1.0, 2.0, 3.0.

```python
print(df)
```
| | A | B | C |
|---|---|---|---|
| 0 | 1 | string | 1.0 |
| 1 | 2 | string2 | 2.0 |
| 2 | 3 | string3 | 3.0 |

However, because of a formatting quirk in the original file, Pandas accidentally imported them as text strings (like the word "1.0" instead of the math number 1.0).

If we check the types, Pandas says Column C is an `object`. If we try to feed this into a machine learning model, the model will crash because it cannot do math on words!

## 4. The Fix: Converting Types (`.astype()`)

To fix this, we use the `.astype()` method. It forces Pandas to translate the column into the specific type we tell it to.

Here is the code to fix Column C:

```python
# Force Column C to become a float (decimal number)
# CRUCIAL: You must re-assign the column back to itself to permanently save the change!
df["C"] = df["C"].astype("float")

# Verify the fix worked
print(df.dtypes)
```

The Output:

```text
A     int64
B    object
C   float64
dtype: object
```

Success! Column C is now a `float64`. The computer finally recognizes the numbers as actual math numbers, and the data is officially ready to be preprocessed for machine learning!

> [!WARNING]
> Before you use `.astype()`, make sure every single cell in that column can actually be converted. If you try to run `.astype("float")` on a column that contains the word "Apple", Python will throw a massive error because it doesn't know how to turn an Apple into a number!
