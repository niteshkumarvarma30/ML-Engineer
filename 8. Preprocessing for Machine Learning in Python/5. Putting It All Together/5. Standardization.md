# Standardization

In addition to transforming categorical variables, we need to standardize numeric columns that have high variance, like the `seconds` column in our UFO dataset. 

Recall that we can check the variance of a column with the `.var()` method. 

```python
# Check the variance of the seconds column
print(ufo["seconds"].var())
```

If the variance is extremely high, it can throw off the machine learning model. After we've checked the variance, we can log normalize the column using NumPy's `log` function. This drastically reduces the variance while maintaining the relationships between the numbers.

```python
import numpy as np

# Log normalize the seconds column
ufo["seconds_log"] = np.log(ufo["seconds"])
```
