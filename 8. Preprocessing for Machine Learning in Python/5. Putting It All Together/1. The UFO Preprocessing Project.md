# The UFO Preprocessing Project

You have learned a lot of different data preprocessing techniques. Now it's time to put them all together into a single workflow!

In this final exercise, you are handed a messy, real-world dataset of UFO Sightings.
It contains columns like the location of the UFO, the shape/type of the UFO, how many seconds it hovered in the sky, a text description, and the date it was recorded.

Before you can run this through a machine learning model, you have to clean it up. Here is your ultimate preprocessing checklist based on the concepts we've covered!

## 1. The Missing Data Check

Real-world data is rarely complete. Did a witness forget to write down the shape of the UFO?

*   **The Tools:** Use `df.isna().sum()` to count how many blank cells exist in every column.
*   **The Fix:** If there are rows with missing crucial information, use `df.dropna()` to throw those incomplete rows in the trash so they don't crash your model.

## 2. The Data Type Check

Remember, machine learning models are just calculators. They only understand math.

*   **The Problem:** What if the column for "Seconds Lasted" was accidentally imported by Pandas as text words (an object) instead of math numbers?
*   **The Fix:** You must force the computer to recognize them as numbers using the `.astype()` method. (e.g., `df["Seconds"] = df["Seconds"].astype("float")`).

## 3. The Train/Test Split Check

Before you do any advanced scaling or modeling, you must lock a portion of your data away in a vault so the model can take a "Final Exam" on unseen data.

*   **The Tool:** `train_test_split()`
*   **The Imbalance Problem:** Some UFO shapes are probably very common (like "Disk"), but some are extremely rare (like "Cigar"). If you randomly shuffle the data, all the rare "Cigar" UFOs might accidentally end up in the test vault, meaning your model will never see one during training!
*   **The Fix:** Use the `stratify=y` parameter. This guarantees that the exact ratio of common and rare UFOs is perfectly balanced between your training group and your test group.

## 4. (Bonus) Feature Engineering

Though not explicitly mentioned in the checklist, keep an eye out for other tricks you've learned!

*   **Dates:** A computer doesn't understand "July 4, 1999". You might need to use `pd.to_datetime()` and extract just the Month (`.dt.month`) to see if UFOs appear more often in the summer!
*   **Categories:** If you have a column of UFO types ("Disk", "Light", "Triangle"), you'll need to use `pd.get_dummies()` or a LabelEncoder to turn those text words into binary 1s and 0s!

Good luck with your final practice exercise!
