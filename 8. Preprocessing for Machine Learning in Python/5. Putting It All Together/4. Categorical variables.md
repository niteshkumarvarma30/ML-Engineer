# Categorical variables

Recall that there are a number of categorical variables in the UFO dataset, including location data (like `state` and `country`) and the `type` of the encounter. 

The following exercises will be about dealing with these categorical variables. There are a number of categorical variables that need to be one-hot encoded so that a machine learning model can understand them.

Remember that we can one-hot encode variables using pandas' `get_dummies()` function:

```python
import pandas as pd

# Example of one-hot encoding
ufo_encoded = pd.get_dummies(ufo, columns=["type", "country", "state"])
```
