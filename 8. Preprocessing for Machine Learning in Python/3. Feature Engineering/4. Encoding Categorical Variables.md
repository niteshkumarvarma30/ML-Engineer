# Encoding Categorical Variables

Machine learning models only understand math. If your dataset contains text words (Categorical Variables) like "Yes", "No", "Blue", or "Green", you have to translate them into numbers before you can train your model.

This process is called **Encoding**. How we encode the text depends on how many unique options there are in the column.

## 1. Binary Encoding (Only 2 Options)

If a column only has two possible answers (like a `subscribed` column with "y" for Yes and "n" for No), we use **Binary Encoding**. We just translate them into 1s and 0s.

There are two ways to do this: The Pandas way, and the Scikit-Learn way.

### Method A: The Pandas Way (Quick & Manual)

If you are just exploring your data and want to make a quick change, you can use Pandas' `.apply()` method combined with a `lambda` function.

```python
print(users["subscribed"])
```

```text
0    y
1    n
2    n
3    y
Name: subscribed, dtype: object
```

```python
# Tell Pandas: "If the value is 'y', make it a 1. Otherwise, make it a 0."
users["sub_enc"] = users["subscribed"].apply(lambda val: 1 if val == "y" else 0)

print(users[["subscribed", "sub_enc"]])
```

```text
   subscribed  sub_enc
0           y        1
1           n        0
2           n        0
3           y        1
```

This physically replaces the "y" and "n" characters with 1s and 0s right in your spreadsheet.

### Method B: The Scikit-Learn Way (LabelEncoder)

If you are building a proper machine learning pipeline, it is much safer to use Scikit-Learn's `LabelEncoder`.

```python
from sklearn.preprocessing import LabelEncoder

# 1. Instantiate the tool
le = LabelEncoder()

# 2. Fit and Transform the column
users["sub_enc_le"] = le.fit_transform(users["subscribed"])

print(users[["subscribed", "sub_enc_le"]])
```

```text
   subscribed  sub_enc_le
0           y           1
1           n           0
2           n           0
3           y           1
```

**Why is this better?** Because the `LabelEncoder` memorizes that "y" = 1 and "n" = 0. Later, when you bring in brand new Test Data, you can just use `.transform()` and it will automatically apply the exact same rules!

## 2. One-Hot Encoding (3 or More Options)

What if your column has more than two options? Let's say you have a `fav_color` column with "blue", "green", and "orange".

You might think: *"I'll just make blue=1, green=2, and orange=3!"*
**The Danger:** If you do that, the math model will think that Orange (3) is mathematically "larger" or "greater" than Blue (1). That makes no sense for colors!

### The Fix: One-Hot Encoding (Dummy Variables)

Instead of assigning a single number, we split the column into multiple Yes/No Checkboxes.

*   **Blue** becomes `[1, 0, 0]` *(Yes Blue, No Green, No Orange)*
*   **Green** becomes `[0, 1, 0]` *(No Blue, Yes Green, No Orange)*
*   **Orange** becomes `[0, 0, 1]` *(No Blue, No Green, Yes Orange)*

### How to do it in Pandas (`get_dummies`)

Pandas has an amazing built-in function called `get_dummies()` that does all of this math for you instantly.

```python
print(users["fav_color"])
```

```text
0      blue
1     green
2    orange
3     green
Name: fav_color, dtype: object
```

```python
import pandas as pd

# Automatically converts the text column into multiple binary columns!
encoded_colors = pd.get_dummies(users["fav_color"])
print(encoded_colors)
```

```text
   blue  green  orange
0     1      0       0
1     0      1       0
2     0      0       1
3     0      1       0
```

**The Output:**
Instead of one column with words, you now have three separate columns named `blue`, `green`, and `orange` filled entirely with 1s and 0s. Your data is now perfectly formatted for a machine learning model!
