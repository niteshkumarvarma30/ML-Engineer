# Text Feature Engineering

Machine learning algorithms are just giant calculators—they can only understand numbers. So, what do you do when your dataset is full of text, like emails, user reviews, or messy string descriptions?

You have to use Text Feature Engineering to translate that text into math. Here are the two main ways to do it, and the best model to use afterward!

## 1. Extraction (Using Regular Expressions)

Sometimes, you don't care about the whole sentence; you just want to extract a specific piece of information hiding inside the text.

**The Raw Data:** `my_string = "temperature:75.6 F"`

**The Problem:** You can't do math on that string. We need to extract just the `75.6` and turn it into a float.

**The Solution: Regular Expressions (Regex)**
Regex is a special "search code" that looks for patterns in text. We use Python's built-in `re` module for this.

Let's break down the search code used in the lesson: `"\d+\.\d+"`

*   `\d+`: The `\d` means "find a digit (0-9)". The `+` means "grab as many digits as you can find next to each other" (so it grabs the 75).
*   `\.`: The `\` tells the computer we are looking for a literal decimal point (`.`).
*   `\d+`: Grab all the digits after the decimal point (the 6).

**The Python Code:**

```python
import re

my_string = "temperature:75.6 F"
# Search the string for our exact pattern
temp = re.search("\d+\.\d+", my_string)

# temp.group(0) extracts the matched text ("75.6")
# float() wraps it to officially turn the text into a math number!
print(float(temp.group(0))) 
```

```text
75.6
```

## 2. Vectorizing Text (TF-IDF)

What if you care about the entire sentence? For example, you want to read a whole email and predict if it is Spam or Not Spam. You have to turn every single word into a number. We call this **Vectorizing**.

**The Tool: TfidfVectorizer**
TF-IDF stands for **Term Frequency - Inverse Document Frequency**. It doesn't just count the words; it scores how important they are!

*   **Term Frequency (TF):** How many times does the word appear in this specific sentence? *(More times = Higher score)*.
*   **Inverse Document Frequency (IDF):** Does this word appear in every single sentence in the whole dataset? If a word like "the" or "and" is used everywhere, it isn't special. *(Highly common words = Score gets crushed to near zero)*.

**The Result:** Rare, highly specific words (like "Oxfam" or "Afghan" in the data below) get massive scores. Generic words get ignored.

## 3. Text Classification (Naive Bayes)

Once you use TF-IDF to turn thousands of emails into a giant grid of numbers, you need a machine learning model to classify them (e.g., Spam vs. Inbox).

Because text datasets have massive dimensionality (a vocabulary of 10,000 unique words means 10,000 columns!), heavy models like Random Forests can get bogged down.

The absolute best, fastest algorithm for this is the **Naive Bayes Classifier**. 

It is based on Bayes' Theorem:

$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$

**How it works (ELI5):**
It calculates conditional probability. It basically asks: *"Given that the word 'Viagra' and 'Free' are in this email, what is the mathematical probability that this email belongs in the Spam folder?"*

**Why is it called "Naive"?**
The model makes a very "naive" (silly/simple) assumption: It assumes every single word in the sentence is completely independent and has nothing to do with the words next to it. 

Even though this violates the rules of real human grammar, it simplifies the math so much that the model runs lightning fast and performs amazingly well on text classification!
