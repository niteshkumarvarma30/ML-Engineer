# Exercise

## Identifying areas for feature engineering

Take an exploratory look at the `volunteer` dataset.

Which of the following columns would you want to perform a feature engineering task on?

**Possible Answers:**
*   `vol_requests`
*   `title`
*   `created_date`
*   `category_desc`
*   2, 3, and 4

**Solution:**

**2, 3, and 4** is the correct answer.

To find this out yourself, you would run exploratory commands like `.head()` or `.info()` in your IPython Shell to look at the data types and contents.

*   `title` is raw text (needs NLP).
*   `created_date` is a timestamp (needs to be broken down into parts).
*   `category_desc` is categorical text (needs to be encoded into numbers).

All three of these columns require feature engineering before a model can use them!
