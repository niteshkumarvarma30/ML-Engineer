# Exercise

## Feature engineering knowledge test

Now that you've learned about feature engineering, which of the following examples are good candidates for creating new features?

**Possible Answers:**
*   A column of timestamps
*   A column of newspaper headlines
*   A column of weight measurements
*   1 and 2
*   None of the above

**Solution:**

**1 and 2** is the correct answer. 

Timestamps can be broken down into useful numeric components (like month, day, or year), and newspaper headlines (text) must be processed using NLP techniques to convert the words into numbers. A column of weight measurements is already numerical and continuous, so it does not require feature engineering (though it might require scaling!).
