# The Standardized Modeling Workflow

We know that models like K-Nearest Neighbors (KNN) require our data to be scaled (Standardized) so that big numbers don't bulldoze small numbers.

We also know that we have to split our data into a Training Set and a Test Set.

But which one do we do first? You must **ALWAYS** split your data before you scale it. Here is why.

## 1. The Danger of "Data Leakage"

Imagine you are a teacher giving your students a practice test so they can study for a final exam.

*   **The Wrong Way:** You calculate the "average score" using both the practice tests AND the final exams, and you tell the students that average while they are studying. You just cheated! You let information from the final exam "leak" into the study session.

**Data Leakage:** In machine learning, if you run a `StandardScaler` on your *entire dataset* before you split it, the scaler calculates the mean and variance using the Test Data. Your model has officially peeked into the future. It will score an artificially high grade on the test, but fail in the real world.

## 2. The Golden Workflow (Step-by-Step)

To prevent data leakage, we have to strictly follow this workflow.

### Step 1: Split First!

We immediately lock 25% of our data in a vault so the computer cannot see it.

```python
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler

# Lock the test data away!
X_train, X_test, y_train, y_test = train_test_split(X, y, stratify=y, random_state=42)
```

### Step 2: Set up the Tools

We grab our blank KNN model and our blank Scaler tool.

```python
knn = KNeighborsClassifier()
scaler = StandardScaler()
```

### Step 3: Fit & Transform the Training Data

We point the Scaler at the training data. We use `.fit_transform()`.
This tells the Scaler: *"Look at the training data, calculate the average (fit), and immediately scale the numbers (transform)."*

```python
X_train_scaled = scaler.fit_transform(X_train)
```

### Step 4: ONLY Transform the Test Data!

This is the most crucial step. We point the Scaler at the test data, but we ONLY use `.transform()`.
This tells the Scaler: *"Do NOT calculate the average of the test data. I want you to scale this test data using the exact same math rules you memorized from the training data!"*

```python
X_test_scaled = scaler.transform(X_test)
```

### Step 5: Train and Grade

Now that everything is perfectly and fairly scaled, we train the model on the scaled training data, and grade it on the perfectly hidden, scaled test data!

```python
# Train the model
knn.fit(X_train_scaled, y_train)

# Grade the final exam!
knn.score(X_test_scaled, y_test)
```

## Summary

Never use `.fit()` or `.fit_transform()` on your Test Data. You should only ever use `.transform()` on Test Data to ensure it remains completely unseen and pure!
