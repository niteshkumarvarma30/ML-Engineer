## When to standardize

Now that you've learned when it is appropriate to standardize your data, which of these scenarios is NOT a reason to standardize?

**Possible Answers:**
*   A column you want to use for modeling has extremely high variance.
*   You have a dataset with several continuous columns on different scales, and you'd like to use a linear model to train the data.
*   The models you're working with use some sort of distance metric in a linear space.
*   Your dataset is comprised of categorical data.

**Solution:**

**Your dataset is comprised of categorical data.** 

*Why?* Recall the "Golden Rule" from the previous concept guide: Standardization is *only* applied to continuous, numerical data. You never standardize categorical text data (like "Red", "Blue", or Zip Codes). The other three options are the exact three scenarios (High Variance, Different Scales, Linear Distance Models) where you absolutely *must* standardize!
