# Unsupervised Learning: Discovering Hidden Patterns

## 1. The Big Shift: No More "Answer Keys"

In the previous modules, you used Supervised Learning (like Logistic Regression and KNN). You always had a target variable `y`—an "answer key" that told the computer exactly what it was trying to predict (like if a song was "Rock" or "Jazz").

In Unsupervised Learning, there is no answer key. There is no `y` column. You simply hand the computer a massive spreadsheet of raw data (`X`) and say: *"I don't know what I'm looking for. Please organize this and tell me if you find any hidden patterns."*

## 2. What is Clustering?

Clustering is the most common unsupervised learning task. It is the act of grouping similar data points together.

**Real-world example:** Netflix uses clustering. They don't have a pre-defined label for every single user. Instead, they feed everyone's watch history into an algorithm, and the algorithm automatically groups users into "clusters" of people who have similar tastes, allowing Netflix to recommend movies.

## 3. The Algorithm: K-Means Clustering

K-Means is an incredibly popular clustering algorithm. The "`k`" simply stands for the number of groups you want to find. (If you want 3 groups, `k=3`).

Here is exactly how it works conceptually:

* **The Guess:** You tell the computer to find 3 clusters. The computer randomly drops 3 pins onto your data map. These pins are called **Centroids** (the center of a cluster).
* **The Grouping:** Every single data point looks at the 3 pins and walks over to whichever pin is closest to it. (This is where *Distance* comes in).
* **The Adjustment:** The pin looks at its new group of data points, calculates their exact average location, and moves itself to be perfectly in the middle of them. (This is where the *Average* comes in).

**A Concrete Example:** Imagine you are mapping coffee shops on a 2D city grid. You have two coffee shops in Cluster 1: Shop A is at coordinates `(1, 1)` and Shop B is at `(3, 3)`.
* **The Average:** To find the centroid, the computer averages the X and Y coordinates: `x = (1+3)/2 = 2` and `y = (1+3)/2 = 2`. The Centroid pin moves to exactly `(2, 2)`.
* **The Distance:** When a brand new customer appears on the map at `(1, 2)`, the computer calculates the literal physical distance between the customer and that Centroid pin at `(2, 2)` to see if they belong to Cluster 1 or a different cluster!
* **Repeat:** The data points look at the pins again, rearrange themselves based on the pins' new locations, and the pins move again. This repeats until the pins stop moving. The clusters are now locked in!

## 4. The Scikit-Learn Workflow

The good news is that the Python code looks exactly like the Supervised Learning code you already know.

### Step A: Fit the Model and Find Clusters

Notice we only pass a single array of samples (our `X`). There is no `y`!

```python
from sklearn.cluster import KMeans

# 1. Instantiate the model, telling it to find 3 clusters
model = KMeans(n_clusters=3)

# 2. Fit the model to the data (the pins find their final resting places)
model.fit(samples)

# 3. Predict the labels for the data you just fed it
labels = model.predict(samples)
print(labels)
# Output: [0 0 1 1 0 1 2 1 0 1 ...]
```
*(The output is an array of cluster numbers: 0, 1, or 2, telling you which group each row belongs to).*

### Step B: Assign New Samples

If brand new data comes in, the model doesn't need to recalculate the pins. It simply measures the distance from the new points to the existing centroids and assigns them a label!

```python
new_labels = model.predict(new_samples)
print(new_labels)
# Output: [0 2 1]
```

## 5. Visualizing the Clusters

Because we are finding geometric groups, the absolute best way to evaluate our results is to plot them on a graph using Matplotlib.

In Python, we use NumPy array slicing to isolate the columns we want for our X and Y axes.

```python
import matplotlib.pyplot as plt

# Grab all rows (:), but only the 0th column (sepal length)
xs = samples[:, 0]

# Grab all rows (:), but only the 2nd column (petal length)
ys = samples[:, 2]

# Create a scatter plot, and color the dots based on the cluster groups!
plt.scatter(xs, ys, c=labels)
plt.show()
```

By adding `c=labels`, Matplotlib automatically assigns a unique color to each cluster (e.g., all 0s are purple, 1s are green, 2s are yellow). You can instantly see how well the model separated the data!
