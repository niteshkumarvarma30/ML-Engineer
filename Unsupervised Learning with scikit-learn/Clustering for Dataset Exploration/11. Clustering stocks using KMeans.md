# StandardScaler vs Normalizer

## Overview

Both **StandardScaler** and **Normalizer** are preprocessing techniques used before applying machine learning algorithms.

However, they serve **different purposes**.

| StandardScaler | Normalizer |
|----------------|------------|
| Scales **columns (features)** | Scales **rows (samples)** |
| Standardizes each feature independently | Normalizes each sample independently |
| Makes all features have comparable scales | Makes all samples have the same vector length |
| Mean = 0, Standard Deviation = 1 | Vector Length (L2 Norm) = 1 |
| Used when feature scales differ | Used when the direction or pattern of samples matters |

---

# 1. StandardScaler

## What does it do?

StandardScaler standardizes each **feature (column)** by:

1. Subtracting the mean
2. Dividing by the standard deviation

Every feature becomes

- Mean = 0
- Standard Deviation = 1

---

## Formula

\[
z=\frac{x-\mu}{\sigma}
\]

where

- \(x\) = Original value
- \(\mu\) = Mean of the feature
- \(\sigma\) = Standard deviation of the feature

---

## Example

Original Dataset

| Student | Height (cm) | Weight (kg) |
|----------|------------:|------------:|
| A | 150 | 50 |
| B | 160 | 60 |
| C | 170 | 70 |

Height column

```
150
160
170
```

Mean

```
160
```

After StandardScaler

```
-1.22
0
1.22
```

Similarly,

Weight column is scaled independently.

Final Dataset

| Height | Weight |
|---------|---------|
| -1.22 | -1.22 |
| 0 | 0 |
| 1.22 | 1.22 |

---

## When to Use StandardScaler?

Use StandardScaler when

- Features have different units
- Features have different scales
- Algorithms depend on distance

Examples

- K-Means
- KNN
- PCA
- Logistic Regression
- SVM

# 2. Normalizer

## What does it do?

Normalizer rescales **each sample (row)** independently.

Instead of changing columns,

it changes the entire row so that

```
Vector Length = 1
```

The relative proportions remain the same.

---

## Formula (L2 Normalization)

For a sample

\[
x=(x_1,x_2,\ldots,x_n)
\]

L2 norm

\[
||x||
=
\sqrt{x_1^2+x_2^2+\cdots+x_n^2}
\]

Normalized sample

\[
x'=\frac{x}{||x||}
\]

---

## Example

Suppose we have stock prices.

| Company | Jan | Feb | Mar |
|----------|----:|----:|----:|
| A | 100 | 200 | 300 |
| B | 1000 | 2000 | 3000 |

Company A

```
100
200
300
```

Vector Length

```
√(100²+200²+300²)

=

374.17
```

Normalized

```
100/374.17 = 0.267

200/374.17 = 0.535

300/374.17 = 0.802
```

Company B

```
1000
2000
3000
```

Vector Length

```
3741.7
```

Normalized

```
0.267

0.535

0.802
```

Notice

Both companies become identical after normalization because they have the same **trend**, even though their prices differ.

---

## Visual Representation

```
Company A

100   200   300

↓

0.267 0.535 0.802


Company B

1000 2000 3000

↓

0.267 0.535 0.802
```

Normalizer removes the effect of magnitude while preserving direction.

---

## Why is Normalizer Useful?

Suppose

Company A

```
100 → 200 → 300
```

Company B

```
1000 → 2000 → 3000
```

Without normalization

- Euclidean distance is large.
- K-Means thinks they are different.

After normalization

Both vectors become identical.

K-Means now groups them together because they follow the same pattern.

---

## When to Use Normalizer?

Use Normalizer when

- Comparing patterns instead of magnitudes
- Text classification (TF-IDF vectors)
- Document clustering
- Stock trend clustering
- Cosine similarity
- Recommendation systems

# StandardScaler vs Normalizer

| Property | StandardScaler | Normalizer |
|------------|---------------|------------|
| Works On | Columns | Rows |
| Scales | Features | Samples |
| Formula | (x−μ)/σ | x/‖x‖ |
| Mean | 0 | Not changed |
| Standard Deviation | 1 | Not applicable |
| Vector Length | Changes | Becomes 1 |
| Preserves | Feature distribution | Direction of sample |
| Removes | Scale differences between features | Magnitude differences between samples |
| Common Applications | K-Means, PCA, SVM, Logistic Regression | Text Mining, TF-IDF, Stock Trends, Cosine Similarity |

# Rule of Thumb

### Use StandardScaler when

- Feature scales are different.
- Every feature should contribute equally.
- Distance-based algorithms are used.

Examples

- K-Means
- KNN
- PCA
- SVM
- Logistic Regression

---

### Use Normalizer when

- The **direction or pattern** of each sample matters.
- Magnitude should be ignored.

Examples

- Document Clustering
- TF-IDF
- Recommendation Systems
- Stock Price Trend Analysis
- Cosine Similarity

---

# Key Takeaways

- **StandardScaler** scales **columns (features)** so each feature has mean **0** and standard deviation **1**.
- **Normalizer** scales **rows (samples)** so each sample has a vector length of **1**.
- StandardScaler is used when **feature scales differ**.
- Normalizer is used when **pattern or direction matters more than magnitude**.
- K-Means often uses **StandardScaler** for general numerical datasets and **Normalizer** for data where the **shape of each sample** (e.g., stock trends or TF-IDF vectors) is more important than its absolute size.
