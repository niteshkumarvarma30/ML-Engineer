# Concept

## NMF learns interpretable parts

NMF (Non-Negative Matrix Factorization) is a dimension reduction tool, just like PCA. It takes a massive dataset with hundreds of columns and squishes it down into just a few important columns. However, NMF is special because it learns interpretable parts—meaning it finds patterns that frequently occur in your data, like distinct topics in a stack of documents or repeating shapes in a collection of images.

NMF has one massive advantage over PCA: **It is interpretable.** (Meaning humans can actually understand what the new columns mean).

Here is a breakdown of how it works.

---

### 1. The Golden Rule of NMF

NMF has one strict mathematical rule: **Absolutely no negative numbers allowed.** You can only use NMF on datasets where every single number is $0$ or higher.

* **Good for NMF:** Word counts in an email (you can't have negative words), pixel brightness in an image, or purchase histories (you can't buy -3 pairs of shoes).
* **Bad for NMF:** A dataset containing negative temperatures or negative bank account balances.

---

### 2. The Lego Analogy (Sums of its Parts)

Because NMF cannot use negative numbers, it is forced to do something special: it can only add things together. It can never subtract.

Think of NMF as a master Lego builder.
If you hand NMF a dataset of 1,000 different Lego houses, it will break them down and say: *"I found the basic parts! Every house is just a combination of these 3 base pieces: A Roof piece, a Door piece, and a Wall piece."*

* **The Components:** The base Lego pieces it discovered (Roof, Door, Wall).
* **The Features:** The instructions for a specific house (e.g., *"Use 1 Roof, 0 Doors, and 4 Walls"*).

By simply multiplying the components by the features and adding them together, you can reconstruct the original house!

---

### 3. Example 1: Text Documents & Topics

When you apply NMF to documents, the components it finds correspond to topics.

Imagine you have a Word-Frequency Array of 20,000 scientific articles (the rows) and a vocabulary of 800 words (the columns).

If you ask NMF to find 10 components (`n_components=10`), it will create 10 new rows that live in that 800-dimensional word space. Because NMF is interpretable, you can align these components with the vocabulary to see what they mean!

If you look at one component, the words with the highest values might be: *"species, plant, plants, genetic, evolution, life."*

You can instantly see the theme: **Biology/Botany!** NMF successfully grouped these words into an interpretable topic.

---

### 4. Example 2: Images & Visual Patterns

NMF isn't just for text; it can also learn the repeating physical parts of an image (like individual cells on an LCD screen).

However, dealing with images requires a specific setup:

* **Grayscale Math:** A grayscale image is just a grid of pixels. We can measure the brightness of each pixel on a scale from $0$ (totally black) to $1$ (totally white).
* **Flattening the Array:** Normally, an image is a 2D array (a square grid of pixels). But NMF needs the data in a flat row. To fix this, we flatten the image by reading the pixels row-by-row, from left-to-right and top-to-bottom, until it forms one single, long 1D array of non-negative numbers.
* **The Dataset:** In our final dataset, every row is a single flattened image, and every column is a single pixel.

#### Visualizing the Image Again
Once NMF is done analyzing the flattened pixels, it is incredibly difficult for human eyes to understand a 1D flat array. To actually look at the picture again, you must reverse the flattening process:

1. **Reshape:** Use the `.reshape()` method to turn that flat row back into a 2D grid (by specifying the original dimensions).
2. **Display:** Pass that newly shaped 2D array into matplotlib's `plt.imshow()` function to render the actual picture on your screen!

---

### 5. Reconstruction Error

To understand **Reconstruction Error**, let's go back to the Lego analogy we used for NMF.

When you use NMF, you are doing two things:
1. **Deconstructing:** You take a massive, detailed dataset (like a giant Lego castle) and break it down into a few basic pieces (the Components/Topics).
2. **Reconstructing:** If you take those basic pieces and multiply them by their instructions (the Features), you can rebuild the castle.

#### The "Blurry" Copy
Because you compressed the data (for example, squishing 800 words down into just 10 topics), you threw away some of the minor, highly specific details.

When you rebuild the dataset using only those 10 topics, the rebuilt version will not be a 100% perfect match to the original. It will be an approximation—like a slightly blurry photocopy.

**Reconstruction Error** is simply the mathematical measurement of how different your rebuilt copy is from the original data.

#### How to use it
In scikit-learn, after you fit your NMF model, you can instantly check this error score by calling `model.reconstruction_err_`.

It is a balancing act when choosing your `n_components`:

* **Too few components (e.g., 2):** Your error will be high. The rebuilt data is way too blurry because you don't have enough Lego pieces to capture the real patterns.
* **Too many components (e.g., 500):** Your error will be near zero. You can rebuild the data perfectly! But... you completely failed at dimension reduction. Having 500 topics is just as confusing for a human to read as the original data.

The goal is to find the "sweet spot" where the error is relatively low, but the number of components is still small enough for a human to easily interpret!

---

### 6. Cheat Sheet: Python Code

The code for NMF looks almost exactly like PCA, with one exception: **You MUST tell it how many components you want** (it won't guess for you).

```python
# 1. Import NMF
from sklearn.decomposition import NMF
import matplotlib.pyplot as plt

# 2. Create the model and explicitly set the number of components
model = NMF(n_components=10)

# 3. Fit the model to your data (finds the Lego pieces / topics / patterns)
model.fit(samples)

# 4. Transform the data (gets the instructions for each sample)
nmf_features = model.transform(samples)

# --- BONUS: Viewing an Image ---
# If your sample was a flattened image, reshape it back to 2D
# (Assuming the original image was 50x50 pixels)
restored_image = sample.reshape((50, 50))
plt.imshow(restored_image, cmap='gray')
plt.show()
```

*(Bonus: Just like TruncatedSVD, NMF is perfectly happy working with Sparse Arrays / `csr_matrix` full of zeros!)*
