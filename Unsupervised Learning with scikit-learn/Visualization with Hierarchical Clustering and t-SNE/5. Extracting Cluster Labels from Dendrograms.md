# Extracting Cluster Labels from Dendrograms

Hierarchical clustering is more than just a visualization tool; it allows us to extract usable cluster groups for further data analysis. We do this by looking at "intermediate stages" of the clustering process.

Instead of letting the algorithm merge everything into one giant cluster, we can stop the process early by choosing a specific **height** on the dendrogram. Because the y-axis (height) encodes the exact distance between merging clusters, picking a height sets a rule: stop merging when the clusters are at least this far apart.

## 1. The Meaning of Height (Distance)

An intermediate stage in the hierarchical clustering is specified by choosing a height on the dendrogram. For example, choosing a height of `15` defines a clustering in which Bulgaria, Cyprus, and Greece are in one cluster, Russia and Moldova are in another, and Armenia is in a cluster on its own.

But what is the meaning of the height?

The y-axis of the dendrogram encodes the **distance** between merging clusters. For example:
* The distance between the cluster containing Cyprus and the cluster containing Greece was approximately `6` when they were merged into a single cluster.
* When this new cluster was merged with the cluster containing Bulgaria, the distance between them was `12`.

So the height that specifies an intermediate clustering corresponds to a distance. This specifies that the hierarchical clustering should stop merging clusters when all clusters are at least this far apart.

## 2. Linkage Methods

The distance between two clusters is measured using a "linkage method". In our example, we used **complete linkage**, where the distance between two clusters is the *maximum* of the distances between their samples. This was specified via the `method='complete'` parameter. 

There are many other linkage methods (like 'single' or 'ward'), and different linkage methods give different hierarchical clusterings!

## 3. Extracting Cluster Labels (fcluster)

The cluster labels for any intermediate stage of the hierarchical clustering can be extracted using the `fcluster` function from `scipy.cluster.hierarchy`. 

Let's try it out, specifying the height of `15`.

```python
from scipy.cluster.hierarchy import linkage, fcluster

# 1. Calculate the linkage
mergings = linkage(samples, method='complete')

# 2. Extract the labels using a height of 15
labels = fcluster(mergings, 15, criterion='distance')

print(labels)
```

**Output:**
```text
[ 9  8 11 20  2  1 17 14 ... ]
```
*(Note: SciPy cluster labels start at 1, not at 0 like they do in scikit-learn!)*

## 4. Aligning Labels with Data

To inspect cluster labels, let's use a Pandas DataFrame to align the labels with the country names, just like we did with K-Means.

```python
import pandas as pd

# Create the DataFrame
pairs = pd.DataFrame({'labels': labels, 'countries': country_names})

# Sort by cluster label and print
print(pairs.sort_values('labels'))
```

**Output:**
```text
    countries  labels
5     Belarus       1
40    Ukraine       1
...
36      Spain       5
8    Bulgaria       6
19     Greece       6
10     Cyprus       6
28    Moldova       7
```
As expected, the cluster labels successfully group Bulgaria, Greece, and Cyprus in the same cluster! The labels can now be used in further computations, such as cross-tabulations.

## Why is Clustering Unsupervised Learning?

The distinction between supervised and unsupervised learning comes down to whether or not you have an "answer key" for your data.

* **Supervised Learning:** You train the model using data that already has labels or target outcomes. (e.g., predicting house prices using a dataset where final prices are known).
* **Unsupervised Learning:** You do not have an answer key. You are handing the algorithm raw, unlabeled data.

This is exactly why clustering is an unsupervised learning technique. Its main purpose is **pure discovery 🕵️**. Since you don't have predefined labels to train on, you use clustering to automatically group similar data points together. The algorithm figures out the natural structures, hidden patterns, or segments within the data entirely on its own—just like finding geographical voting blocks in the Eurovision dataset without being told which countries are political allies.

**Example Application:** Imagine you are a bank with a massive dataset of credit card transactions. You want an algorithm to group these transactions based on spending habits to see if any strange, isolated groups form that might indicate a new, unknown type of fraud (Anomaly Detection).
