# Exercise

## How many merges?

### Question

If there are 5 data samples, how many merge operations will occur in a hierarchical clustering? (To help answer this question, think back to the video, in which Ben walked through an example of hierarchical clustering using 6 countries.)

### Possible Answers

* **4 merges.**
* 3 merges.
* This can't be known in advance.

---

### Solution

**Answer:** 4 merges.

### Concept Explanation

In agglomerative (bottom-up) hierarchical clustering, the algorithm starts by treating every single data sample as its own individual cluster. 

* If you have **$N$** samples, you start with **$N$** clusters.
* Every time a merge operation happens, two clusters are joined together into one. This means every merge reduces the total number of clusters by exactly $1$.
* The algorithm stops when all samples have been merged into one single, giant root cluster at the top of the dendrogram.

Therefore, to go from $N$ clusters down to $1$ cluster, it will always take exactly **$N - 1$** merge operations. 

For 5 data samples, it takes $5 - 1 = 4$ merges!
