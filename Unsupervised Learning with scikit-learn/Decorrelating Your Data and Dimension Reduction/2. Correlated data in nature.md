## Correlated data in nature

### Concept: Identifying Correlation Before PCA

Before we use PCA to *de-correlate* our data, we first need to prove that our data is correlated in the first place! 

In nature, features are often highly correlated. For example, if a grain of wheat is very long, it is usually very wide as well. You are given an array `grains` giving the width and length of samples of grain. You suspect that width and length will be correlated. 

To confirm this, you will visually inspect the relationship using a scatter plot and then mathematically measure it using the **Pearson correlation** coefficient from the `scipy.stats` module.

*(Note: The code uses `plt.axis('equal')`. This forces the X and Y axes to have the exact same scale, which is crucial for accurately visualizing the true physical spread and correlation of the data without the graph skewing it).*

### Instructions

* Import `matplotlib.pyplot` as `plt` and `pearsonr` from `scipy.stats`.
* Assign column `0` of `grains` to `width` and column `1` of `grains` to `length`.
* Make a scatter plot with `width` on the x-axis and `length` on the y-axis.
* Use the `pearsonr()` function to calculate the Pearson correlation of `width` and `length`.

### Solution

```python
# Perform the necessary imports
import matplotlib.pyplot as plt
from scipy.stats import pearsonr

# Assign the 0th column of grains: width
width = grains[:, 0]

# Assign the 1st column of grains: length
length = grains[:, 1]

# Scatter plot width vs length
plt.scatter(width, length)
plt.axis('equal')
plt.show()

# Calculate the Pearson correlation
correlation, pvalue = pearsonr(width, length)

# Display the correlation
print(correlation)
```
