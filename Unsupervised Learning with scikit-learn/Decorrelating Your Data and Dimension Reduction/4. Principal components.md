# Exercise

## Principal components

### Concept: Visualizing Principal Components

This exercise tests your visual intuition of what "Principal Components" actually are. 

Recall from the guide that principal components are simply the **directions along which the data varies the most**. If you have a cloud of data points shaped like a cigar, the first principal component is the line running straight down the long center of that cigar. The second principal component will be perfectly perpendicular (orthogonal) to the first one.

Because an axis is just a line, a principal component vector can point in either direction along that line (e.g., "up and to the right" or "down and to the left"). Both are mathematically valid principal components representing the exact same axis of variance.

### Instructions

Three scatter plots of the same point cloud are shown. Each scatter plot shows a different set of axes (in red). In which of the plots could the axes represent the principal components of the point cloud?

*Recall that the principal components are the directions along which the data varies.*

**Possible answers:**
1. None of them.
2. Both plot 1 and plot 3.
3. Plot 2.

---

### Solution

**Correct Answer: 2. Both plot 1 and plot 3.**

**Explanation:**
* **Plot 2** shows standard horizontal and vertical axes (like a regular X/Y graph). Because the data cloud is slanted diagonally, these standard axes do NOT align with the direction the data is spreading. Therefore, they are not the principal components.
* **Plot 1 and Plot 3** both show red axes that perfectly align with the diagonal spread (variance) of the data cloud. One red line goes right through the longest part of the cluster, and the other line is perfectly perpendicular to it. The fact that the arrows might point in opposite directions between Plot 1 and Plot 3 doesn't matter; they still define the exact same axis of variance. Therefore, both represent the principal components of this point cloud!
