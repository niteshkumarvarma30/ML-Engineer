# Counting Words (CountVectorizer)

We know that machine learning models only understand math. If we want a computer to read a President's inaugural address, we have to translate the text into numbers.

The easiest and most common way to do this is called **Bag of Words** (or Word Counting).

## 1. The "Text to Columns" Concept

Look at the illustration below. It perfectly illustrates how we turn a sentence into a math grid.

![Bag of Words Concept](../../images/Screenshot%202026-07-20%20113934.png)

**The Sentence:**
"NLP is the best. I love NLP."

**The Translation:**
We take every single unique word in that sentence and make it its own column. Then, we simply tally up how many times each word was used!

*   NLP: 2
*   I: 1
*   love: 1
*   best: 1
*   is: 1
*   the: 1

Instead of reading the English sentence, the computer now just reads a row of numbers: `[2, 1, 1, 1, 1, 1]`.

**How the Numbers Line Up:**
That entire array of numbers represents exactly one single row in our new mathematical spreadsheet.

Here is how the grid is organized:
*   **Every Row** represents one specific document or sentence (e.g., Row 1 is Sentence 1, Row 2 is Sentence 2).
*   **Every Column** represents a unique word from the dictionary, usually sorted in alphabetical order.

For the sentences we analyzed in the second screenshot below, the computer fills in the numbers across the columns like this:

![Text to Grid Example](../../images/Screenshot%202026-07-20%20114037.png)

| Sentence | I | love | NLP | Machine | Learning |
| :--- | :--- | :--- | :--- | :--- | :--- |
| I love NLP | 1 | 1 | 1 | 0 | 0 |
| I love machine learning | 1 | 1 | 0 | 1 | 1 |

## 2. Scikit-Learn's Automatic Counter

You don't have to write a custom loop to count millions of words. Scikit-Learn has a built-in tool for this called `CountVectorizer`.

### Step A: Fit and Transform

First, you clean your text. Then, you can use the `.fit()` and `.transform()` methods, or the pro-shortcut to do it all at once using `.fit_transform()`.

![CountVectorizer Example 1](../../images/Screenshot%202026-07-20%20114150.png)
![CountVectorizer Example 2](../../images/Screenshot%202026-07-20%20114230.png)
![CountVectorizer Output](../../images/Screenshot%202026-07-20%20114319.png)

```python
from sklearn.feature_extraction.text import CountVectorizer

vectorizer = CountVectorizer()

# The tool memorizes the vocabulary and counts the words all at once!
X = vectorizer.fit_transform(cleaned_reviews)
```

**The Sparse Matrix Catch:** If you look at the output in the screenshot, it doesn't look like a normal array. It says `<Compressed Sparse Row sparse matrix of dtype 'int64' with 16 stored elements and shape (3, 9)>`.
Because 99% of the word counts for any given speech will be 0, Python compresses the grid to save memory. To turn it back into a normal grid of numbers, you must use `.toarray()`.

```python
print(X.toarray())
```

### Step B: Get the Feature Names

Right now, `X.toarray()` is just a giant grid of numbers. We don't know which column belongs to which word! We extract the column headers using `.get_feature_names_out()`.

![Get Feature Names](../../images/Screenshot%202026-07-20%20114350.png)

```python
# Returns a list like: ['amazing', 'boring', 'hated', ...]
print(vectorizer.get_feature_names_out())
```

## 3. The Sanity Check (Finding Common Words)

Whenever you generate new text features, you should do a quick sanity check to make sure the computer isn't extracting garbage. A great way to do this is to add up the columns and plot the most popular words!

Look at the code and Word frequencies plot below:

![Word frequencies](../../images/Screenshot%202026-07-20%20114414.png)

```python
import numpy as np
import matplotlib.pyplot as plt

# 1. Add up all the columns vertically (axis=0) to get a total count for every single word!
word_counts = np.sum(X.toarray(), axis=0)

# 2. Grab the vocabulary list to use as labels for our X-axis
words = vectorizer.get_feature_names_out()

# 3. Create a bar chart!
plt.bar(words, word_counts)
plt.title("Word Frequencies in Movie Reviews")
plt.xlabel("Words")
plt.ylabel("Frequency")
plt.show()
```

**The Verdict:** We are analyzing a dataset of movie reviews. Looking at this output graph, it makes perfect sense that the most commonly spoken words are stop words like "was", "the", and "it". Because we didn't remove stop words during preprocessing, they dominated the chart! To capture better context, we need a more advanced approach.
