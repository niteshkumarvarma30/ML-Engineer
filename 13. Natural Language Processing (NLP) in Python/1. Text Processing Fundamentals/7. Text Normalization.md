# Text Normalization

In our previous guides, we learned how to chop sentences into tokens and throw away useless garbage (like stop words and punctuation).

Now we face a new problem: Language is incredibly flexible, but computers hate flexibility.
A human knows that the words "run", "running", and "ran" basically mean the exact same thing. But to a computer, those are three completely unique, unrelated tokens.

Text Normalization is the process of forcing all these variations into one single, standard format. Here are the three main ways we do it!

## 1. Lowercasing

*(Reference: image_a3c8bf.png and image_a3c91d.png)*

If a user types "DATA", "Data", and "data", a computer will treat them as three totally different words just because of the capital letters. If you don't fix this, your vocabulary size will artificially explode, slowing down your machine learning model!

**The Fix:** We use Python's built in `.lower()` string method to force every single letter to become lowercase. Now, all three variations perfectly match as "data".

*   **When to use it:** Almost always! It is fantastic for tasks like Sentiment Analysis or finding keywords in a search engine.
*   **When NOT to use it:** You skip lowercasing if capitalization completely changes the meaning of the word. For example, the lowercase word "us" (me and you) is completely different from the uppercase word "US" (the United States).

## 2. Stemming (The "Chainsaw" Method)

*(Reference: image_a3cc29.png and image_a3cc4b.png)*

Stemming is a brute-force method to find the "root" of a word. It literally acts like a pair of scissors, blindly chopping off common suffixes (like `-ing`, `-ed`, or `-s`) from the end of your tokens.

*   "running" becomes "run"
*   "reading" becomes "read"

**The Problem:** Because Stemming is blind and doesn't know actual English grammar, it often chops too much off and creates fake, non-dictionary words. For example, it might chop "organization" down to "organizat".

**The Python Code for Stemming**

We use the `PorterStemmer` tool from the NLTK library to do the chopping.

```python
from nltk.stem import PorterStemmer

# 1. Instantiate the tool
stemmer = PorterStemmer()

tokens = ['running', 'bats', 'organizations', 'reading']

# 2. Chop off the ends using a list comprehension!
stemmed = [stemmer.stem(word) for word in tokens]

print(stemmed)
# Output: ['run', 'bat', 'organizat', 'read']
```

## 3. Lemmatization (The "Careful Trimmer" Method)

*(Reference: image_a3cce2.png and image_a3cd1b.png)*

Lemmatization has the exact same goal as Stemming (finding the base root of a word), but it is much smarter. Instead of blindly chopping off suffixes, it actually looks up the word in a massive English dictionary and applies proper grammar rules.

Because it actually understands grammar, it knows that "organizations" should safely reduce to the valid word "organization".

**The Python Code for Lemmatization**

We use the `WordNetLemmatizer` from NLTK. (WordNet is the massive internal dictionary it uses to check the grammar!).

```python
from nltk.stem import WordNetLemmatizer
import nltk

# Download the dictionary database
# nltk.download('wordnet')

# 1. Instantiate the tool
lemmatizer = WordNetLemmatizer()

tokens = ['running', 'bats', 'organizations', 'reading']

# 2. Trim the words properly!
lemmatized = [lemmatizer.lemmatize(word) for word in tokens]

print(lemmatized)
# Output: ['running', 'bat', 'organization', 'reading']
```

*(Notice how it was smart enough to leave "running" and "reading" alone if it recognized them as valid nouns/gerunds in the dictionary context!)*

## 4. The Ultimate Showdown: Stemming vs. Lemmatization

*(Reference: image_a3cfe8.jpg)*

Which one should you use? Look at the fantastic illustration comparing the two!

*   **Stemming is a Chainsaw:** It is incredibly fast and lightweight. It gets the job done, but it is messy and leaves behind weird, non-dictionary words. You should use this when **Speed** is your top priority (like indexing millions of documents for a Search Engine).
*   **Lemmatization is a pair of Garden Shears:** It takes its time. It carefully prunes the word using a dictionary to ensure the final result is a beautiful, valid English word. It is much slower than Stemming. You should use this when **Grammar and accuracy** matter (like training an AI Chatbot or a translation app).
