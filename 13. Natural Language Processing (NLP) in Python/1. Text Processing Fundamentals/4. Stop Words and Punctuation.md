# Stop Words and Punctuation

After you have chopped your text into tokens, the next step in the NLP pipeline is cleaning up the garbage. We do this by handling Stop Words and Punctuation.

## 1. Stop Words

![Stop Words 1](../../images/Screenshot%202026-07-19%20202007.png)
![Stop Words 2](../../images/Screenshot%202026-07-19%20202039.png)

Not all words in a sentence are actually useful. Words like "the", "and", "is", and "at" are just grammatical glue holding the sentence together. They don't actually tell you what the sentence is about. These are called Stop Words.

*   **When to remove them:** If you are trying to figure out the topic of a customer review, words like "great" and "terrible" matter. "The" does not. By removing them, you reduce noise and help the machine focus only on the important, content-rich words.
*   **When to keep them:** If you are building an AI to translate French to English, you need to keep every single word so the grammar translates correctly!

**The Python Code for Stop Words**

NLTK has a built-in dictionary of these useless words based on linguistic research. We use a list comprehension to check our tokens and keep them ONLY if they don't appear in the stop words list.

```python
from nltk.corpus import stopwords
from nltk.tokenize import word_tokenize

# Download and load the official NLTK English stop words list
# nltk.download('stopwords')
stop_words = stopwords.words('english')

text = "This is an example to demonstrate removing stop words."
tokens = word_tokenize(text)

# Filter them out! (We use .lower() to catch both "The" and "the")
filtered_tokens = [word for word in tokens if word.lower() not in stop_words]

print(filtered_tokens)
# Output: ['example', 'demonstrate', 'removing', 'stop', 'words', '.']
# Notice that "This", "is", "an", and "to" have been completely deleted!
```

## 2. Punctuation

![Punctuation 1](../../images/Screenshot%202026-07-19%20202216.png)
![Punctuation 2](../../images/Screenshot%202026-07-19%20202248.png)

We still have one more piece of noise to throw away: Punctuation marks (like `!`, `?`, `,`, and `.`).

*   **When to remove them:** If you want to find the most common words in a document, punctuation gets in the way. To a computer, the word `hello` and the word `hello!` look like two completely different things because of the exclamation point attached to the end.
*   **When to keep them:** Just like stop words, we keep punctuation if we are doing a task where sentence structure matters, like having an AI write a summary. Without periods or commas, the AI would generate one massive, unreadable run-on sentence.

**The Python Code for Punctuation**

Python has a built-in list of all punctuation marks in its standard string module. We run our tokens through one more list comprehension filter to wipe them out!

```python
import string

# Python's built in string.punctuation looks like this:
# !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~

# Take the filtered_tokens from the previous step, and filter them AGAIN!
clean_tokens = [word for word in filtered_tokens if word not in string.punctuation]

print(clean_tokens)
# Output: ['example', 'demonstrate', 'removing', 'stop', 'words']
# The period (.) at the end has finally been deleted!
```

Your text is now completely clean, stripped of noise, and ready to be turned into math!
