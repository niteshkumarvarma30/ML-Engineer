# Zero-Shot Classification & QNLI

In our previous lesson, we used a Hugging Face pipeline for Sentiment Analysis. We used a model that was specifically trained to look for "Positive" and "Negative" emotions.

But what if you want to categorize text into custom labels that the model has never seen before? Or what if you want a model to act like a search engine?

Here are two incredibly powerful, versatile text classification techniques that can do exactly that!

## 1. Zero-Shot Classification

*(Reference: image_1f5b3b.png)*

Standard machine learning models have a massive flaw: they only know the categories they were explicitly trained on. If you train a model to recognize "Cats" and "Dogs," and you show it a picture of a "Bird," it will be completely confused.

Zero-Shot Classification fixes this. It allows a model to accurately categorize text into brand new, custom labels that it has never seen before!

### How does it work?

Instead of looking for specific keywords, it uses Natural Language Prediction. It essentially asks itself a logical question: "Does this sentence imply this label?"

*   **The Sentence:** "The national football team won the cup yesterday."
*   **The Labels:** `[Sports, Technology, Health]`

The model reads the sentence, looks at the labels, and logically deduces that the sentence implies the "Sports" label, even if it was never explicitly trained on a "Sports" category!

**Why is this useful?** It is perfect for content tagging, filtering news, or organizing customer support tickets into flexible, on-the-fly categories without having to train an entirely new model from scratch.

### The Python Code

*(Reference: image_1f5e40.png)*

To use this, we simply instantiate the pipeline and pass it our text along with our custom `candidate_labels`.

```python
from transformers import pipeline

# 1. Define the Zero-Shot Pipeline
zero_shot_classifier = pipeline(
    task="zero-shot-classification",
    model="MoritzLaurer/DeBERTa-v3-base-mnli-fever-anli"
)

# 2. Define the Text and the Custom Labels
text = "The national football team won the cup yesterday."
candidate_labels = ["sports", "technology", "health"]

# 3. Make the Prediction!
result = zero_shot_classifier(text, candidate_labels)
print(result)

# Output: 
# {'sequence': 'The national football team won the cup yesterday.', 
#  'labels': ['sports', 'technology', 'health'], 
#  'scores': [0.9948, 0.0029, 0.0021]}
```

**Understanding the Output:**
The model correctly ranked the labels, showing a massive 99.48% confidence score that the sentence is about "sports".

## 2. QNLI (Question Natural Language Inference)

*(Reference: image_1f5e83.png)*

QNLI is a specific type of classification that acts like a highly intelligent search engine.

You hand the model two things:
*   **A Passage:** A paragraph of text.
*   **A Question:** Something you want to know.

The model acts as a detective. It reads the passage and determines whether or not the passage contains the answer to your question. It then outputs a confidence score.

**Why is this useful?** If you have a massive company database of 10,000 PDF documents, you can use QNLI to build a custom Chatbot. When a user asks a question, the algorithm quickly scans every document to see which one actually contains the answer!

### The Python Code (A Successful Match)

*(Reference: image_1f5ea4.png)*

```python
from transformers import pipeline

# 1. Define the QNLI Pipeline
qnli_pipeline = pipeline(
    task="text-classification",
    model="cross-encoder/qnli-electra-base"
)

# 2. Define the Passage and the Question
passage = "Penguins are found primarily in the Southern Hemisphere."
question = "Where do penguins live?"

# 3. Ask the Model! (Note: The keys 'text' and 'text_pair' might change depending on the model!)
result = qnli_pipeline({"text": question, "text_pair": passage})
print(result)

# Output: {'label': 'LABEL_0', 'score': 0.9951}
```

**Understanding the Output:** The model returned a massive 99.5% confidence score, confirming that the passage successfully answers the question.

### The Python Code (A Failed Match)

*(Reference: image_1f5edc.png)*

What happens if we ask a completely unrelated question? Let's use the exact same code, but change the question to: "What is the capital of Paris?"

```python
passage = "Penguins are found primarily in the Southern Hemisphere."
question = "What is the capital of Paris?"

result = qnli_pipeline({"text": question, "text_pair": passage})
print(result)

# Output: {'label': 'LABEL_0', 'score': 0.0089}
```

**Understanding the Output:** The model read the passage about penguins, realized it had absolutely nothing to do with Paris, and dropped its confidence score down to a tiny 0.8%. The detective correctly realized the answer was missing!
