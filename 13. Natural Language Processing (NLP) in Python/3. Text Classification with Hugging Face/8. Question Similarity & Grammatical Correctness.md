# Question Similarity & Grammatical Correctness

We've already seen that Hugging Face text classification pipelines can be used for Sentiment Analysis and Zero-Shot categorization. But the power of text classification doesn't stop there!

Here are two more incredible ways we can use text classification to solve real-world language problems.

## 1. Question Similarity (QQP)

*(Reference: image_1f71bf.png)*

Imagine you are building a Chatbot or an FAQ page for a website. Users are constantly asking questions, but humans are messy—we ask the exact same question in dozens of different ways!

*   "How do I reset my password?"
*   "I forgot my password, what do I do?"
*   "Where is the password reset button?"

To a computer, those look like three completely different sentences. Question Similarity fixes this. It compares two sentences and determines if they are actually paraphrases (meaning the exact same thing).

**Why is this useful?** It is perfect for deduplicating forum posts, clustering similar questions together, or helping a search engine realize that a user's weirdly-phrased question perfectly matches an existing FAQ answer!

### The QQP Dataset

To do this, we use models that were trained on the QQP (Quora Question Pairs) dataset. Quora had millions of users asking duplicate questions, so they built a massive database of question pairs labeled as "Matches" or "Does Not Match."

### The Python Code

*(Reference: image_1f71e1.png and image_1f748a.png)*

```python
from transformers import pipeline

# 1. Define the QQP Pipeline
qqp_pipeline = pipeline(
    task="text-classification",
    model="textattack/bert-base-uncased-QQP"
)

# 2. Define our Questions
question1 = "How can I learn Python?"
question2 = "What is the best way to study Python?"

# 3. Ask the Model!
result = qqp_pipeline({"text": question1, "text_pair": question2})
print(result)

# Output: {'label': 'LABEL_1', 'score': 0.6853}
```

**Understanding the Output:**
For QQP models, `LABEL_1` means "Yes, these are similar," and `LABEL_0` means "No, they are different."
The model gave us `LABEL_1` with a 68.5% confidence score, correctly realizing that learning Python and studying Python mean the same thing!

If we changed `question2` to "What is the capital of France?", the model would immediately spit out `LABEL_0` with 99.9% confidence, realizing the topics are completely unrelated.

## 2. Assessing Grammatical Correctness (CoLA)

*(Reference: image_1f74c8.png)*

What if you want to build the next Grammarly, or a tool to grade a student's essay? You need an AI that knows the rules of English.

We can use text classification to assess Grammatical Acceptability.

### The CoLA Dataset

To achieve this, we use models trained on the CoLA (Corpus of Linguistic Acceptability) dataset. This dataset is basically a giant list of English sentences that linguistic experts have manually graded as either grammatically correct or grammatically broken.

### The Python Code (A Good Sentence)

*(Reference: image_1f74ea.png)*

```python
from transformers import pipeline

# 1. Define the CoLA Pipeline
cola_classifier = pipeline(
    task="text-classification",
    model="textattack/distilbert-base-uncased-CoLA"
)

# 2. Test a good sentence!
result = cola_classifier("The cat sat on the mat.")
print(result)

# Output: [{'label': 'LABEL_1', 'score': 0.9918}]
```

**Understanding the Output:**
For CoLA models, `LABEL_1` means "Grammatically Correct" and `LABEL_0` means "Unacceptable." The model gave us `LABEL_1` with a massive 99.18% confidence, giving the sentence a perfect grade.

### The Python Code (A Bad Sentence)

*(Reference: image_1f750a.png)*

Let's see what happens if we scramble the grammar completely and feed it nonsense.

```python
result = cola_classifier("The cat on sat mat the.")
print(result)

# Output: [{'label': 'LABEL_0', 'score': 0.9628}]
```

**Understanding the Output:**
The model instantly recognized that the sentence structure was completely broken. It output `LABEL_0` (Unacceptable) with a 96.2% confidence score!
