# Question Answering (Extractive vs. Abstractive)

One of the most impressive feats of Natural Language Processing is Question Answering (QA). This is where you give a machine learning model a large passage of text to "read," and then you ask it a question about what it just read.

There are two completely different ways an AI can answer a question: Extractive and Abstractive. Here is how they work.

## 1. Extractive QA (The "Copy and Paste" Method)

![Extractive QA](images/Screenshot%202026-07-20%20152806.png)

Extractive QA acts like a student taking an open-book test with a highlighter. It reads the passage, finds the exact location of the answer, and literally "extracts" (copies and pastes) that specific chunk of text.

### The Scenario:
*   **Context:** "The library closes at 6 PM on weekdays."
*   **Question:** "When does the library close on weekdays?"
*   **The Extractive Answer:** "6 PM"

**Why use it?**
Because the model is just pointing to text that already exists, it is highly accurate and less prone to errors or hallucinations. It is the absolute best choice for Search Engines, Document Retrieval (e.g., searching legal contracts), and Reading Comprehension apps where you need raw, factual precision.

### Extractive QA in Python

![Extractive QA in Python](images/Screenshot%202026-07-20%20152838.png)

To do this in Scikit-Learn/Hugging Face, we use a standard "question-answering" pipeline. Notice how we pass the question and context as two separate pieces of information!

```python
from transformers import pipeline

# 1. Define the Extractive Pipeline
qa_pipeline = pipeline(
    task="question-answering",
    model="distilbert/distilbert-base-cased-distilled-squad"
)

# 2. Provide the Reading Material and the Question
context = "The Amazon rainforest is the largest tropical rainforest in the world, covering parts of Brazil, Peru, and Colombia."
question = "Which countries does the Amazon rainforest cover?"

# 3. Ask the Model!
qa_answer = qa_pipeline(question=question, context=context)
print(qa_answer)

# Output: {'score': 0.9242, 'start': 90, 'end': 116, 'answer': 'Brazil, Peru, and Colombia'}
```

**Understanding the Output:** The model tells you the exact character positions (start: 90, end: 116) where it found the answer, and hands you the extracted string!

## 2. Abstractive QA (The "In Your Own Words" Method)

![Abstractive QA](images/Screenshot%202026-07-20%20152910.png)

Abstractive QA acts like a conversational human. It reads the passage, digests the information, and then generates a brand new, natural-sounding sentence from scratch. It paraphrases!

### The Scenario:
*   **Context:** "The library closes at 6 PM on weekdays."
*   **Question:** "When does the library close on weekdays?"
*   **The Abstractive Answer:** "Closure is at 6 PM." (Notice how it created a full sentence using words that weren't in the original text!)

**Why use it?**
Because it generates fluent, conversational sentences, it is perfect for Chatbots, Virtual Assistants (like Siri or Alexa), and Customer Support bots.
**The Danger:** Because it generates new text, it can sometimes introduce errors or hallucinate facts, especially when reading massive documents.

### Abstractive QA in Python

![Abstractive QA in Python](images/Screenshot%202026-07-20%20152926.png)

Because Abstractive QA is generating new text, we must change our pipeline task to "text2text-generation".

**The Formatting Catch:** Text-generation models usually expect one single string of text as input. We have to use a Python f-string to glue the question and the context together before feeding it to the model!

```python
from transformers import pipeline

# 1. Define the Abstractive Pipeline (Notice the task change!)
qa_pipeline = pipeline(
    task="text2text-generation",
    model="fangyuan/hotpotqa_abstractive"
)

context = "The Amazon rainforest is the largest tropical rainforest in the world, covering parts of Brazil, Peru, and Colombia."
question = "Which countries does the Amazon rainforest cover?"

# 2. THE CATCH: Glue the question and context into a single string!
input_text = f"question: {question} context: {context}"

# 3. Ask the Model!
result = qa_pipeline(input_text)
print(result)

# Output: [{'generated_text': 'The Amazon rainforest covers parts of Brazil, Peru, and Colombia.'}]
```

**Understanding the Output:** Instead of giving you character positions, the model simply hands you a beautifully generated, complete sentence!
