# Token Classification (NER & PoS)

![Token Classification](images/Screenshot%202026-07-20%20151612.png)

We have already learned how to use pipelines to classify entire sentences (like assigning a "Positive" or "Negative" sentiment to a movie review).

But what if we don't want to classify the whole sentence? What if we want to zoom in and classify the individual words inside the sentence? This is called **Token Classification**.

Here are the two most powerful ways we use Token Classification in the real world.

## 1. Named Entity Recognition (NER)

![Named Entity Recognition](images/Screenshot%202026-07-20%20151734.png)

NER (Named Entity Recognition) acts as an incredibly smart highlighter. It reads a sentence and automatically highlights specific "Entities" (things that exist in the real world).

For example, look at the sentence:
*"Apple opened a new office in Toronto in March 2023"*

The NER model acts as a detective and classifies the tokens into distinct categories:
*   "Apple" $\rightarrow$ Highlighted as an **Organization**.
*   "Toronto" $\rightarrow$ Highlighted as a **Location**.
*   "March 2023" $\rightarrow$ Highlighted as a **Date**.

**Why is this useful?**
If you have a massive folder of 10,000 PDF financial reports, you don't have time to read them. You can use NER to instantly scan all 10,000 documents and extract a master list of every single Company (Organization) and Dollar Amount (Money) mentioned!

### NER in Python

![NER in Python](images/Screenshot%202026-07-20%20151818.png)

```python
from transformers import pipeline

# 1. Define the NER Pipeline
# We set `grouped_entities=True` so it knows that "New York" is one single location, 
# rather than splitting it into "New" and "York"!
ner_pipeline = pipeline(
    task="ner",
    model="dslim/bert-base-NER",
    grouped_entities=True
)

# 2. Ask the model to extract the entities!
ner_results = ner_pipeline("Zara Venn established NovaCore Dynamics in London.")
print(ner_results)

# The Output will show:
# 'Zara Venn' -> 'PER' (Person)
# 'NovaCore Dynamics' -> 'ORG' (Organization)
# 'London' -> 'LOC' (Location)
```

## 2. Part of Speech (PoS) Tagging

![PoS Tagging](images/Screenshot%202026-07-20%20151846.png)

While NER looks for real-world things (like cities and companies), PoS (Part of Speech) Tagging looks at grammar. It acts like a strict English teacher, grading every single word in a sentence.

For example, look at the sentence:
*"The quick fox jumps over the lazy dog"*

The PoS model looks at the grammatical role of every word:
*   "fox" $\rightarrow$ Tagged as a **Noun**.
*   "jumps" $\rightarrow$ Tagged as a **Verb**.
*   "quick" $\rightarrow$ Tagged as an **Adjective**.

**Why is this useful?**
This is the foundational technology behind tools like Grammarly. If you want an AI to correct your grammar or translate English to Spanish perfectly, it must understand which word is the noun and which word is the verb!

### PoS Tagging in Python

![PoS Tagging in Python](images/Screenshot%202026-07-20%20151906.png)

```python
from transformers import pipeline

# 1. Define the PoS Pipeline
pos_pipeline = pipeline(
    task="token-classification",
    model="vblagoje/bert-english-uncased-finetuned-pos",
    grouped_entities=True
)

# 2. Ask the model to grade the grammar!
pos_results = pos_pipeline("Zara Venn established NovaCore Dynamics in London.")
print(pos_results)

# The Output will show:
# 'zara venn' -> 'PROPN' (Proper Noun)
# 'established' -> 'VERB' (Verb)
# 'in' -> 'ADP' (Preposition)
```
