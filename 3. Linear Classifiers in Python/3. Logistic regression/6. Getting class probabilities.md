## Getting class probabilities

### Concept: The Sigmoid Transformation
When you run `.predict_proba()` on a logistic regression model, it first calculates a raw mathematical score (`w@X + b`). This raw score can be absolutely any number, from negative infinity to positive infinity. 

To convert this raw score into a clean probability percentage between 0% (0.0) and 100% (1.0), the model must pass the raw score through a mathematical transformation. 

---

### Instructions

**Question:** Look at the four transformation graphs provided in the image. Which of the following transformations would make sense for transforming the raw model output of a linear classifier into a class probability?

* **Graph (1):** A straight diagonal line going from negative to positive infinity.
* **Graph (2):** A squiggly sine wave bouncing up and down between 0 and 1.
* **Graph (3):** A smooth S-curve starting at 0, hitting 0.5 in the middle, and maxing out at 1.0.
* **Graph (4):** A cubic curve that rockets downward to negative infinity and upward to positive infinity.

**Possible Answers:**
* [ ] (1)
* [ ] (2)
* [x] (3)
* [ ] (4)

---

### Solution

**Correct Answer:** `(3)`

**Why this is correct:**
* Graph `(3)` is the **Sigmoid Function**. It is the only function that perfectly "squishes" any number (no matter how big or small) into a strict range between `0.0` and `1.0`. 
* Because it crosses the Y-axis at exactly `0.5`, a raw model output of `0` means the model is exactly 50% confident, making it the perfect mathematical tool for calculating probabilities!
