## Fitting multi-class logistic regression

### Concept: OvR vs. Softmax
In this exercise, you'll fit the two types of multi-class logistic regression—**one-vs-rest** (the "separate judges" trick) and **softmax/multinomial** (the "master judge" trick)—on the handwritten digits data set and compare the results.

The handwritten digits dataset is already loaded and split into `X_train`, `y_train`, `X_test`, and `y_test`.

---

### Instructions

1. Fit a one-vs-rest logistic regression classifier by setting the `multi_class` parameter and report the results.
2. Fit a multinomial logistic regression classifier by setting the `multi_class` parameter and report the results.

---

---

### Solution

```python
from sklearn.linear_model import LogisticRegression

# Fit one-vs-rest logistic regression classifier
lr_ovr = LogisticRegression(multi_class='ovr')
lr_ovr.fit(X_train, y_train)

print("OVR training accuracy:", lr_ovr.score(X_train, y_train))
print("OVR test accuracy    :", lr_ovr.score(X_test, y_test))

# Fit softmax classifier
lr_mn = LogisticRegression(multi_class='multinomial')
lr_mn.fit(X_train, y_train)

print("Softmax training accuracy:", lr_mn.score(X_train, y_train))
print("Softmax test accuracy    :", lr_mn.score(X_test, y_test))
```

**Takeaway:** When you run this, you will usually find that the **Softmax/Multinomial** model achieves slightly higher accuracy on the test set! Because it optimizes all the classes simultaneously using the Cross-Entropy loss function, it creates a better holistic model than three separate judges working independently.
