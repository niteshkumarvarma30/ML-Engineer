# Exercise

## Counting the coefficients

### Concept: Multi-Class Grid Math
Remember from the previous concept guide: a multi-class logistic regression model creates a grid of coefficients. It essentially draws a completely separate "line in the sand" for *every single class*. 

Because it's drawing a separate line for each class, it needs a full set of feature weights PLUS an intercept for every single class!

---

### Instructions

**Question:** If you fit a logistic regression model on a classification problem with 3 classes and 100 features, how many coefficients would you have, including intercepts?

**Possible Answers:**
* [ ] (1) 101
* [ ] (2) 103
* [ ] (3) 301
* [x] (4) 303

---

### Solution

**Correct Answer:** `(4)`

**Why this is correct:**
* We have 100 features, and we need a weight for each feature for all 3 classes (100 * 3 = 300 weights).
* Every class line also gets its own intercept (3 classes = 3 intercepts).
* 300 feature weights + 3 intercepts = **303 total coefficients!** 

*(If you were using scikit-learn, `lr.coef_` would have a shape of `(3, 100)` and `lr.intercept_` would have a shape of `(3,)`)*
