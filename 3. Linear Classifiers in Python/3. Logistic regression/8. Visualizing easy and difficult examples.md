## Visualizing easy and difficult examples

### Concept: Finding ambiguity in the data
In this exercise, you'll visualize the examples that the logistic regression model is most and least confident about by looking at the largest and smallest predicted probabilities.

If a model's maximum probability for a digit is `0.99`, it is extremely confident (it's an "easy" example).
If a model's maximum probability for a digit is `0.51`, it is barely guessing (it's a "difficult" or "ambiguous" example).

The handwritten digits dataset is already loaded into the variables `X` and `y`. The `show_digit` function takes in an integer index and plots the corresponding image, with some extra information displayed above the image.

### Solution

```python
from sklearn.linear_model import LogisticRegression
import numpy as np

lr = LogisticRegression()
lr.fit(X,y)

# Get predicted probabilities
proba = lr.predict_proba(X)

# Sort the example indices by their maximum probability
# np.argsort sorts from smallest (least confident) to largest (most confident)
proba_inds = np.argsort(np.max(proba,axis=1))

# Show the most confident (least ambiguous) digit
# Grab the very LAST item in the sorted array
show_digit(proba_inds[-1], lr)

# Show the least confident (most ambiguous) digit
# Grab the very FIRST item in the sorted array
show_digit(proba_inds[0], lr)
```

**Takeaway:** By analyzing `predict_proba()`, you can isolate the exact data points that are confusing your model. If you notice a pattern in the "ambiguous" examples, you can clean your dataset or engineer new features to help the model figure them out!
