### Solution

```python
from sklearn.linear_model import LogisticRegression

# Print training accuracies
print("Softmax     training accuracy:", lr_mn.score(X_train, y_train))
print("One-vs-rest training accuracy:", lr_ovr.score(X_train, y_train))

# Create the binary classifier (class 1 vs. rest)
lr_class_1 = LogisticRegression(C=100)
# Passing y_train==1 turns the targets into booleans (True if Class 1, False if anything else)
lr_class_1.fit(X_train, y_train==1)

# Plot the binary classifier (class 1 vs. rest)
plot_classifier(X_train, y_train==1, lr_class_1)
```

**Takeaway:** This exercise proves exactly how One-vs-Rest (OvR) works! By manually passing `y_train==1`, we forced a standard Logistic Regression model to act exactly like "Judge 1" from our concept guide. It drew a single line separating Class 1 from *everything else*. The `lr_ovr` model literally just runs this exact code three separate times under the hood!
