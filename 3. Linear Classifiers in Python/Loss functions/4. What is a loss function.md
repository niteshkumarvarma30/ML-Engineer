# Concept

## What is a Loss Function?

Up until now, we know that calling `.fit(X, y)` makes the model "learn" from the data. But how exactly does it learn?

It uses a **Loss Function**.

---

### 1. What is a Loss Function?

A Loss Function is a penalty score. It tells the model exactly how poorly it is doing.

In machine learning, Loss is like Golf: **you want your score to be as close to zero as possible.**

When you call `.fit()`, the model is basically just playing a massive game of "Guess and Check." It guesses the coefficients, checks its penalty score (the Loss), tweaks the coefficients slightly, and checks again, trying to make the penalty score as small as possible.

**Loss vs. Score**
* **The Loss Function:** Used *during* training to help the model learn.
* **The Score Function:** Used *after* training to evaluate how well the model does (like Accuracy or R-Squared). 
*(They are often related, but they are not the same thing!)*

---

### 2. Regression: The Squared Loss

For Linear Regression (predicting continuous numbers like house prices), we use the **Squared Loss** (or Least Squares).

* **How it works:** The model guesses a house costs \$300,000. The true price is \$350,000. The error is \$50,000. The model squares that number, does the same for every house in the dataset, and adds them all up.
* **The Goal:** The model jiggles its coefficient lines up and down until that massive sum of squared errors reaches the lowest possible number.

---

### 3. Classification: The 0-1 Loss

If we are predicting categories (like "Cat" or "Dog"), we can't use Squared Loss. You can't mathematically subtract "Cat" from "Dog."

Instead, we think about the simplest possible penalty for classification: **The 0-1 Loss**.
* If the model guesses correctly, the penalty is **0**.
* If the model guesses wrong, the penalty is **1**.

If you add up all the 1s, the total Loss is just the total number of mistakes the model made.

**The Catch: Why we don't actually use it**
While the 0-1 Loss makes perfect logical sense to a human, computers hate it. Because it is a hard step (it jumps instantly from 0 to 1 without any smooth curve in between), it is mathematically a nightmare for the computer to minimize.

Because of this, real algorithms like Logistic Regression and SVMs do not use the 0-1 Loss. They use special, smoother loss functions that are easier for the computer's math engine to slide down!

---

### 4. How the Computer Minimizes Loss (SciPy)

In Python, the engine that actually does the heavy lifting of minimizing these penalties is often a tool like `scipy.optimize.minimize`.

If you give this tool an equation (like $y = x^2$) and an initial random guess, it will automatically test different numbers until it finds the exact input that results in the lowest possible output.

When you type `model.fit()` in scikit-learn, the model is secretly handing its Loss Function to an optimizer just like this one, asking it: *"Please find the exact coefficients and intercepts that make my penalty score as close to zero as possible!"*
