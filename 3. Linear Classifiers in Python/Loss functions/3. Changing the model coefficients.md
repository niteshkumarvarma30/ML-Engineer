## Changing the model coefficients

### Concept: Steering the Decision Boundary
When you call `.fit()` with scikit-learn, the model automatically learns the best coefficients and intercept from your dataset. However, you can actually set these manually! 

Remember the geometry of linear classifiers:
* **Intercept (`model.intercept_`):** Moves the boundary line up, down, left, or right.
* **Coefficients (`model.coef_`):** Rotates the angle of the boundary line.

In this exercise, you will manually tweak these numbers to try and perfectly separate a 2D dataset.

---

### Instructions

1. Set the two coefficients and the intercept to various values and observe the resulting decision boundaries.
2. Try to build up a sense of how the coefficients relate to the decision boundary.
3. Set the coefficients and intercept such that the model makes no errors on the given training data.

### Solution

```python
import numpy as np

# Set the coefficients (Example values that solve the dataset)
# Changing the coefficients from [0,1] to [-1, 1] rotates the line diagonally.
model.coef_ = np.array([[-1,1]])

# Changing the intercept from [0] to [-3] shifts the line to the perfect position.
model.intercept_ = np.array([-3])

# Plot the data and decision boundary
plot_classifier(X,y,model)

# Print the number of errors
num_err = np.sum(y != model.predict(X))
print("Number of errors:", num_err)
```

**Takeaway:** By manually tweaking `model.coef_` and `model.intercept_`, you can visually see how the weights rotate the line and the bias shifts it. The `.fit()` function is simply an automated way of finding these exact "perfect" numbers!
