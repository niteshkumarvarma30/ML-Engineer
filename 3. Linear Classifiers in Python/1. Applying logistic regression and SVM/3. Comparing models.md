# Exercise

## Comparing models

### Concept: Evaluating Hyperparameters
Compare k nearest neighbors classifiers with `k=1` and `k=5` on the handwritten digits data set, which is already loaded into the variables `X_train`, `y_train`, `X_test`, and `y_test`. 

You can set `k` with the `n_neighbors` parameter when creating the `KNeighborsClassifier` object, which is also already imported into the environment.

**Which model has a higher test accuracy?**

---

### Instructions

**Possible answers:**
* [ ] `k=1`
* [ ] `k=5`

---

### Solution

To solve this, you would run the following code in the IPython Shell to compare the scores:

```python
# Test accuracy with k=1
knn_1 = KNeighborsClassifier(n_neighbors=1)
knn_1.fit(X_train, y_train)
print("k=1 Test Accuracy:", knn_1.score(X_test, y_test))

# Test accuracy with k=5
knn_5 = KNeighborsClassifier(n_neighbors=5)
knn_5.fit(X_train, y_train)
print("k=5 Test Accuracy:", knn_5.score(X_test, y_test))
```

If you run that code on the handwritten digits dataset, you will find that `k=5` generalizes better to the unseen test data. 

**Correct Answer:** `k=5`
