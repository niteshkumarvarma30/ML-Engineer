# Exercise

## Overfitting

### Concept: The Danger of Memorization
As we learned in the *Scikit-Learn Workflow* concept guide, a model that simply memorizes the answers to the practice test (the Training Set) without actually learning the underlying patterns will fail miserably on the final exam (the Testing Set).

This phenomenon is called **Overfitting**. 

* **Underfitting:** The model is too simple and performs poorly on both the training and testing sets (e.g., Training: 50%, Testing: 50%).
* **Well-fit (Generalization):** The model learns the true patterns and performs well on both sets (e.g., Training: 95%, Testing: 95%).
* **Overfitting:** The model memorizes the training data perfectly, but completely falls apart when shown brand new data (e.g., Training: 95%, Testing: 50%).

---

### Instructions

**Question:** Which of the following situations looks like an example of overfitting?

**Possible answers:**
* [ ] Training accuracy 50%, testing accuracy 50%.
* [ ] Training accuracy 95%, testing accuracy 95%.
* [ ] Training accuracy 95%, testing accuracy 50%.
* [ ] Training accuracy 50%, testing accuracy 95%.

---

### Solution

**Correct Answer:** `Training accuracy 95%, testing accuracy 50%.`

**Why this is correct:**
Overfitting refers to a model doing significantly better on the training set than the test set. If your model gets an A+ on the practice test (95%), but fails the final exam (50%), it has overfit the data. It memorized the noise and specific quirks of the training data instead of learning the general rules.
