# Exercise

## How models make predictions

### Concept: The Prediction Rule
As we learned in the *Math of Linear Classifiers* guide, once a linear model calculates its raw output using the dot product (`(Coefficients @ Features) + Intercept`), making the actual prediction is simple. 

It acts like the 50-yard line on a football field. It simply looks at the **sign** of the raw output:
* **Positive (+):** Predict Class 1
* **Negative (-):** Predict Class 0

---

### Instructions

**Question:** Which classifiers make predictions based on the sign (positive or negative) of the raw model output?

**Possible answers:**
* [ ] Logistic regression only
* [ ] Linear SVMs only
* [ ] Neither
* [ ] Both logistic regression and Linear SVMs

---

### Solution

**Correct Answer:** `Both logistic regression and Linear SVMs`

**Why this is correct:**
Both `LogisticRegression` and `LinearSVC` are linear classifiers. This means their `.predict()` functions are mathematically identical. They both calculate the raw output using the exact same equation, and they both predict the final class based purely on whether that resulting number is positive or negative!
