## Classification loss functions

### Concept: What makes a good loss function?
When evaluating a loss function for classification, we have to look at how it behaves when the model is wrong (negative raw output) versus when the model is right (positive raw output).

A good classification loss function should:
1. Have a high penalty when the raw output is negative (incorrect prediction).
2. Have a penalty of 0 (or close to 0) when the raw output is positive (correct prediction).
3. **Crucially:** It should *not* penalize the model for being "too correct" (having a very high positive raw output).

### Instructions

**Question:** Look at the four loss functions plotted in the graph. Which of the four loss functions makes sense for classification?

* **Line 1 (Solid Black):** Drops immediately to 0 when positive.
* **Line 2 (Dashed Orange):** Increases steadily when negative, stays at 0 when positive.
* **Line 3 (Dash-Dot Magenta):** Hits 0 at a specific point, but then increases if the output gets too high.
* **Line 4 (Dotted Red):** Parabola that penalizes both large negative and large positive numbers.

**Possible answers:**
* [ ] (1)
* [x] (2)
* [ ] (3)
* [ ] (4)

---

### Solution

**Correct Answer:** `(2)`

**Why this is correct:**
* **(2) is the Hinge Loss (used by SVMs).** It correctly penalizes the model for being wrong (the loss goes up as the output gets more negative). But once the model is confident and correct (raw output > 1), the loss drops to zero and stays there. It doesn't punish the model for being *too* confident.
* *(1)* is the 0-1 loss, which makes sense conceptually but is too hard for computers to optimize.
* *(3) and (4)* actually punish the model for having a very high positive raw output. In classification, a high positive output just means the model is extremely confident in its correct answer. We should never penalize a model for being "too correct"!
