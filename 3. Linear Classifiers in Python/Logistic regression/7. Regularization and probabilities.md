## Regularization and probabilities

### Concept: How C affects confidence
In this exercise, you will observe the effects of changing the regularization strength (`C`) on the predicted probabilities.

Remember from the concept guide: strong regularization (a small `C`) shrinks the coefficients. Smaller coefficients mean the raw model output doesn't get as large. If the raw output doesn't get large, the Sigmoid function won't be pushed as close to 1.0 or 0.0. 

Therefore, strong regularization prevents the model from becoming overly confident!

### Solution

```python
from sklearn.linear_model import LogisticRegression
import numpy as np

# Set the regularization strength
model = LogisticRegression(C=1)

# Fit and plot
model.fit(X,y)
plot_classifier(X,y,model,proba=True)

# Predict probabilities on training points
prob = model.predict_proba(X)

# Use numpy to find the absolute highest probability the model outputted
print("Maximum predicted probability", np.max(prob))
```

**Takeaway:** If you were to change `C=1` to `C=0.1` (increasing the regularization strength), you would see the `np.max(prob)` drop significantly! A heavily regularized model is a more cautious model, which helps prevent overfitting on noisy data.
