## Jointly tuning gamma and C with GridSearchCV

### Concept: The Grid Search Bake-off
In the previous exercise the best value of `gamma` was `0.001` using the default value of `C`, which is `1`. In this exercise you'll search for the best combination of `C` and `gamma` simultaneously using `GridSearchCV`.

As in the previous exercise, the 2-vs-not-2 digits dataset is already loaded, but this time it's split into the variables `X_train`, `y_train`, `X_test`, and `y_test`. Even though cross-validation already splits the training set into parts, it's often a good idea to hold out a completely separate test set to make absolutely sure the cross-validation results are sensible and haven't overfit.

### Solution

```python
from sklearn.svm import SVC
from sklearn.model_selection import GridSearchCV

# Instantiate an RBF SVM
svm = SVC()

# Instantiate the GridSearchCV object and run the search
# Notice how the menu now has two items! (3 C values * 5 gamma values = 15 combinations)
parameters = {'C':[0.1, 1, 10], 'gamma':[0.00001, 0.0001, 0.001, 0.01, 0.1]}

# Pass in the model and the parameter grid menu
searcher = GridSearchCV(svm, param_grid=parameters)

# Fit the grid search to the TRAINING data only!
searcher.fit(X_train, y_train)

# Report the best parameters and the corresponding score
print("Best CV params", searcher.best_params_)
print("Best CV accuracy", searcher.best_score_)

# Report the test accuracy using these best parameters
# Score the completely unseen test data to verify the model generalizes well
print("Test accuracy of best grid search hypers:", searcher.score(X_test, y_test))
```

**Takeaway:** This is why it is called a "**Grid** Search"! Because we handed it 3 values for `C` and 5 values for `gamma`, the computer built a 3x5 grid. It exhaustively built and tested 15 entirely different SVM models to figure out which exact combination of Slack (`C`) and Smoothness (`gamma`) worked best for this specific dataset!
