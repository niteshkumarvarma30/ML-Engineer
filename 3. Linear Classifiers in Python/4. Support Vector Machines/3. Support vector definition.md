## Support vector definition

### Concept: Identifying Support Vectors
In the previous concept guides, we learned that a Support Vector Machine (SVM) minimizes the Hinge Loss. 

The most important takeaway was the "Zero Loss Zone." If a data point is correctly classified and the model is highly confident about it, the Hinge Loss drops exactly to zero. Because the penalty is zero, the SVM completely ignores these points!

The points it *does not* ignore (the ones with a penalty greater than zero) are called **Support Vectors**. 

Support Vectors are comprised of two groups of data points:
1. Points that are correctly classified, but are dangerously close to the boundary (they don't have enough confidence to reach zero loss yet).
2. Points that are incorrectly classified (they have a high penalty because they are on the wrong side of the boundary).

---

### Instructions

**Question:** Look at the Hinge Loss diagram. Which of the following is a true statement about support vectors? 

**Possible Answers:**
* [ ] (1) All support vectors are classified correctly.
* [ ] (2) All support vectors are classified incorrectly.
* [ ] (3) All correctly classified points are support vectors.
* [x] (4) All incorrectly classified points are support vectors.

---

### Solution

**Correct Answer:** `(4)`

**Why this is correct:**
* Option 1 is false: As we can see on the left side of the Hinge Loss graph (the red zone), incorrectly classified points have a massive loss penalty. Because their loss is not zero, they are support vectors.
* Option 2 is false: As we can see in the middle of the Hinge Loss graph (the blue zone from 0 to 1), points can be correctly classified but still have a loss penalty greater than zero. Therefore, some correctly classified points are support vectors.
* Option 3 is false: If a point is correctly classified and has a raw output of `> 1`, its loss hits flat zero and it is ignored (it is NOT a support vector).
* **Option 4 is true:** Every single incorrectly classified point (the entire red zone on the left side of the graph) has a loss penalty greater than zero. Because their penalty is never zero, **all incorrectly classified points are mathematically guaranteed to be support vectors!**
