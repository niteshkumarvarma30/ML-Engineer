## Effect of removing examples

### Concept: Proving the "Zero Loss" Zone
In the concept guide, we claimed that an SVM completely ignores any data points that aren't support vectors (the easy, correctly classified points that fall into the flat "Zero Loss" zone). 

We claimed that if you literally deleted all of those easy points from your dataset, the model's boundary line wouldn't move an inch! 

In this exercise, you will write the Python code to prove that this mathematical claim is 100% true. The `svm.support_` attribute in scikit-learn stores an array of the index numbers of the support vectors.

---

### Instructions

1. Train a linear SVM on the whole data set (`X` and `y`).
2. Create a new data set (`X_small` and `y_small`) containing *only* the support vectors by slicing `X` and `y` using the `svm.support_` array.
3. Train a new linear SVM on the smaller data set.

*(When you run this in the platform, you will see two identical plots printed. The second plot has far fewer dots, but the boundary line is in the exact same place!)*

### Solution

```python
from sklearn.svm import SVC

# Train a linear SVM on the full dataset
svm = SVC(kernel="linear")
svm.fit(X, y)
plot_classifier(X, y, svm, lims=(11,15,0,6))

# Make a new data set keeping only the support vectors
print("Number of original examples", len(X))
print("Number of support vectors", len(svm.support_))

# Slice the data using the index numbers stored in svm.support_
X_small = X[svm.support_]
y_small = y[svm.support_]

# Train a new SVM using ONLY the support vectors
svm_small = SVC(kernel="linear")
svm_small.fit(X_small, y_small)
plot_classifier(X_small, y_small, svm_small, lims=(11,15,0,6))
```

**Takeaway:** This is why SVMs are so incredibly fast and computationally cheap! If you have a massive dataset of a million rows, but only 5,000 of them are tricky support vectors near the boundary, the SVM algorithm effectively deletes the other 995,000 rows from its memory and only performs math on the 5,000 that matter.
