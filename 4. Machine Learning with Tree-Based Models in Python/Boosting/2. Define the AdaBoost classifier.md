## Define the AdaBoost classifier

### Concept: Building the Sequential Army
To build an AdaBoost ensemble, we first have to build the "Weak Learner" that will act as the base foundation for the entire sequence. 

Unlike a Random Forest where the trees are allowed to grow deep and complex, we want our base estimator here to be incredibly simple. We usually use a "Decision Stump" (a tree with `max_depth=1`), but in this exercise, we will allow it to ask exactly two questions by setting `max_depth=2`. 

Once we have our weak learner, we pass it directly into the `AdaBoostClassifier` and tell it to build an army of 180 of them, sequentially fixing each other's mistakes!

As a first step, you'll start by instantiating an AdaBoost classifier.

* Import `AdaBoostClassifier` from `sklearn.ensemble`.
* Instantiate a `DecisionTreeClassifier` with `max_depth` set to 2.
* Instantiate an `AdaBoostClassifier` consisting of 180 trees and setting the `base_estimator` to `dt`.

### Solution

```python
# Import DecisionTreeClassifier
from sklearn.tree import DecisionTreeClassifier

# Import AdaBoostClassifier
from sklearn.ensemble import AdaBoostClassifier

# Instantiate dt
dt = DecisionTreeClassifier(max_depth=2, random_state=1)

# Instantiate ada
ada = AdaBoostClassifier(base_estimator=dt, n_estimators=180, random_state=1)
```
