## Evaluate the 10-fold CV error

### Concept: Calculating CV-Error
To get a highly accurate estimate of how our model will perform on unseen data (without touching the Test Set), we use 10-Fold Cross-Validation. 

Because `cross_val_score` defaults to maximizing scores, it returns Negative MSE. We simply multiply the array by `-1` to flip the scores back to positive, calculate the Mean of the 10 folds, and finally take the Square Root to get the CV RMSE!

### Instructions
In this exercise, you'll evaluate the 10-fold CV Root Mean Squared Error (RMSE) achieved by the regression tree `dt` that you instantiated in the previous exercise.

In addition to `dt`, the training data including `X_train` and `y_train` are available in your workspace. We also imported `cross_val_score` from `sklearn.model_selection`.

Note that since `cross_val_score` has only the option of evaluating the negative MSEs, its output should be multiplied by negative one to obtain the MSEs. The CV RMSE can then be obtained by computing the square root of the average MSE.

* Compute `dt`'s 10-fold cross-validated MSE by setting the `scoring` argument to `'neg_mean_squared_error'`.
* Compute RMSE from the obtained MSE scores.

### Solution

```python
# Compute the array containing the 10-folds CV MSEs
MSE_CV_scores = - cross_val_score(dt, X_train, y_train, cv=10, 
                                  scoring='neg_mean_squared_error',
                                  n_jobs=-1)

# Compute the 10-folds CV RMSE
RMSE_CV = (MSE_CV_scores.mean())**(1/2)

# Print RMSE_CV
print('CV RMSE: {:.2f}'.format(RMSE_CV))
```
