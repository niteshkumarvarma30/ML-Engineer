## Set the tree's hyperparameter grid

### Concept: Building the Menu
Now that we know the names of our hyperparameters, we need to build the menu for the computer to test. 

We do this using a standard Python Dictionary. The **keys** are the exact string names of the hyperparameters (e.g., `'max_depth'`), and the **values** are Lists containing all the different numbers we want the computer to test!

In this grid, the computer will test a total of 12 different combinations (3 depths * 4 leaf sizes).

### Instructions
In this exercise, you'll manually set the grid of hyperparameters that will be used to tune the classification tree `dt` and find the optimal classifier in the next exercise.

* Define a grid of hyperparameters corresponding to a Python dictionary called `params_dt` with:
  * the key `'max_depth'` set to a list of values 2, 3, and 4
  * the key `'min_samples_leaf'` set to a list of values 0.12, 0.14, 0.16, 0.18

### Solution

```python
# Define params_dt
params_dt = {
    'max_depth': [2, 3, 4],
    'min_samples_leaf': [0.12, 0.14, 0.16, 0.18]
}
```
