## Set the hyperparameter grid of RF

### Concept: Building a Massive Menu
We are now going to build a grid (the menu) for our Random Forest. 

Take a close look at the grid you are about to build. You are testing 3 different options for `n_estimators`, 3 options for `max_features`, and 3 options for `min_samples_leaf`. 

That means the computer is going to test exactly 27 different combinations (3 x 3 x 3 = 27)!

### Instructions
In this exercise, you'll manually set the grid of hyperparameters that will be used to tune `rf`'s hyperparameters and find the optimal regressor. For this purpose, you will be constructing a grid of hyperparameters and tune the number of estimators, the maximum number of features used when splitting each node and the minimum number of samples (or fraction) per leaf.

* Define a grid of hyperparameters corresponding to a Python dictionary called `params_rf` with:
  * the key `'n_estimators'` set to a list of values 100, 350, 500
  * the key `'max_features'` set to a list of values 'log2', 'auto', 'sqrt'
  * the key `'min_samples_leaf'` set to a list of values 2, 10, 30

### Solution

```python
# Define the dictionary 'params_rf'
params_rf = {
    'n_estimators': [100, 350, 500],
    'max_features': ['log2', 'auto', 'sqrt'],
    'min_samples_leaf': [2, 10, 30]
}
```
