## Train your first classification tree

### Concept: Training a Classification Tree
In the previous concepts, we learned that a Decision Tree classifier predicts categories by learning a sequence of if-else questions. To use a Classification Tree in scikit-learn, we use `DecisionTreeClassifier`. 

Just like linear models, the workflow is:
1. **Instantiate**: Create the model object (e.g., `dt = DecisionTreeClassifier(max_depth=6)`). Here, `max_depth` acts as a stopping criterion to prevent overfitting.
2. **Fit**: Train the model on the training data (`dt.fit(X_train, y_train)`).
3. **Predict**: Generate predictions on unseen test data (`dt.predict(X_test)`).
