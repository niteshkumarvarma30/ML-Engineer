# 1. Introduction to Decision Tree Regression

Decision Trees can solve two different problems.

## Classification

Predict categories.

Examples

- Pass / Fail
- Spam / Not Spam
- Disease / Healthy

Output

```
Yes

No
```

---

## Regression

Predict continuous values.

Examples

- House Price
- Temperature
- Sales
- Stock Price

Example Dataset

| Area (sq ft) | Price (Lakhs) |
|---------------|---------------|
|1000|40|
|1200|42|
|1500|38|
|1800|40|

Output

```
40

42

38

40
```

Unlike classification,

there are **no classes**.

---

# 2. Why Can't Regression Trees Use Gini or Entropy?

Gini and Entropy require **class probabilities**.

Example

```
Positive

Negative
```

or

```
Yes

No
```

They calculate

```
P(Yes)

P(No)
```

But regression outputs are

```
40

42

38

40
```

Question

```
What is P(40)?

What is P(42)?
```

There are no fixed classes.

Every value may be different.

Therefore,

Gini and Entropy cannot be used.

---

# 3. Goal of Regression Trees

Instead of asking

> "Are the classes pure?"

Regression Trees ask

> "Are the target values similar?"

Example

Leaf A

```
40

41

39

42
```

All numbers are close.

Good leaf.

---

Leaf B

```
20

70

150

40
```

Numbers are spread far apart.

Bad leaf.

The objective is

```
Create leaf nodes containing
similar target values.
```

---

# 4. Why Measure Spread?

Suppose we have two groups.

Group A

```
40

41

42

39
```

Group B

```
20

70

150

40
```

Group A has very little variation.

Group B has huge variation.

We need a mathematical quantity that measures

```
Spread

or

Variation
```

That quantity is called

```
Variance
```

# 5. Mean of a Leaf Node

Suppose a leaf contains

```
40

42

38

40
```

Question

What should be the prediction?

Decision Trees predict

```
Mean(Target Values)
```

Mean

```
(40+42+38+40)/4

=160/4

=40
```

Therefore

Every future sample reaching this leaf

will be predicted as

```
40
```

# 7. Mean Squared Error (MSE)

After finding the mean,

we measure

how far every value is from the mean.

Formula

```
MSE

=

(1/n)

Σ(yi−ȳ)²
```

where

```
yi

=

Actual Target Value

ȳ

=

Mean of Target Values

n

=

Number of Samples
```

---

Leaf

```

42

38

40
```

Find Mean

```

```

Step 2

Calculate Errors

| Actual | Mean | Error |
|---------|------|-------|
|40|40|0|
|42|40|2|
|38|40|-2|
|40|40|0|

Step 3

Square Errors

| Error | Squared Error |
|--------|---------------|
|0|0|

|0|0|

Average

```
MSE

=

=8/4
```

This leaf has

```
MSE = 2
```

Very small.

Therefore

This is a good leaf.

# 10. Why Square the Errors?

Suppose

Prediction

```
50
```

Actual

```
52
```

Error

```
2
```

Another sample

Prediction

```
50
```

Actual

```
48
```

Error

```
-2
```

If we simply add

```
2 + (-2)

=0
```

Errors cancel.

Incorrect.

Instead,

Square them.

```
2² =4

(-2)² =4
```

Now

Every error becomes positive.

Large mistakes receive much larger penalties.

# 11. Weighted Mean Squared Error

Suppose

Parent Node

```
10 Samples
```

Split

↓

Left Child

```
6 Samples

MSE =3
```

Right Child

```
4 Samples

MSE =4
```

Weights

```
6/10

and

4/10
```

Weighted MSE

```
(6/10)×3

+

(4/10)×4

=

1.8+1.6

=3.4
```

Another split

```
Left MSE =1

Right MSE =2
```

Weighted MSE

```
(6/10)×1

+

(4/10)×2

=

1.4
```

Since

```
1.4

<

3.4
```

The second split is better.

Decision Trees always choose

```
Minimum Weighted MSE
```

# 12. Variance Reduction

Suppose

Parent Variance

```
100
```

After splitting

Weighted Variance

```
35
```

Reduction

```
100−35

=65
```

This reduction is called

```
Variance Reduction
```

Decision Trees choose

```
Maximum Variance Reduction
```

Exactly like Information Gain.

# 14. Classification Tree vs Regression Tree

| Classification Tree | Regression Tree |
|----------------------|-----------------|
| Predicts Classes | Predicts Numbers |
| Uses Gini / Entropy | Uses MSE / Variance |
| Goal: Pure Classes | Goal: Similar Target Values |
| Prediction = Majority Class | Prediction = Mean(Target Values) |
| Choose Minimum Weighted Gini | Choose Minimum Weighted MSE |
| Information Gain | Variance Reduction |

# Key Takeaways

- Decision Tree Regression predicts **continuous values**, not classes.
- Gini and Entropy cannot be used because there are **no class probabilities**.
- Regression Trees measure the **spread of target values** instead of impurity.
- The **mean** of the target values becomes the prediction at each leaf.
- The **Mean Squared Error (MSE)** measures how far the target values are from the leaf's mean.
- During training, the algorithm tries every possible split and computes the **Weighted MSE**.
- The split with the **smallest Weighted MSE** (or equivalently, the **largest Variance Reduction**) is selected.
- This process repeats recursively until the stopping criteria are met, producing the final regression tree.
