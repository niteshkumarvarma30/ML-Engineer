## Linear regression vs regression tree

### Concept: Comparing Regression Models
Linear Regression is a powerful algorithm, but it has a massive weakness: it assumes there is a straight-line relationship between the features and the target. If the true relationship is curvy or non-linear (like a U-shape), Linear Regression will fail.

A Regression Tree, however, makes no such assumptions. By using If/Else questions to chop the data into small rectangular regions, it can easily capture highly complex, non-linear relationships. Let's compare the RMSE of both models to see which one performs better on this specific dataset!
