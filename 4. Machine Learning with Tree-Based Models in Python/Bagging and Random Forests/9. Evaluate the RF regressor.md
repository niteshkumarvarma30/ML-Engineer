## Evaluate the RF regressor

### Concept: Aggregating the Regression
Now that the Random Forest has finished training its 25 highly diverse trees, it is time to unleash them on the Test Set.

When we call `rf.predict(X_test)`, the Random Forest will pass the new test data into all 25 trees. Each tree will output a continuous number (its prediction for how many bikes will be rented). Finally, the Random Forest will calculate the **Average (Mean)** of all 25 predictions to give us our final `y_pred`!

### Instructions
You'll now evaluate the test set RMSE of the random forests regressor `rf` that you trained in the previous exercise.

The dataset is processed for you and split into 80% train and 20% test. The features matrix `X_test`, as well as the array `y_test` are available in your workspace. In addition, we have also loaded the model `rf` that you trained in the previous exercise.

* Import `mean_squared_error` from `sklearn.metrics` as `MSE`.
* Predict the test set labels and assign the result to `y_pred`.
* Compute the test set RMSE and assign it to `rmse_test`.

### Solution

```python
# Import mean_squared_error as MSE
from sklearn.metrics import mean_squared_error as MSE

# Predict the test set labels
y_pred = rf.predict(X_test)

# Evaluate the test set RMSE
rmse_test = (MSE(y_test, y_pred))**(1/2)

# Print rmse_test
print('Test set RMSE of rf: {:.2f}'.format(rmse_test))
```
