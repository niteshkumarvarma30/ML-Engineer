# Grid Search vs. Random Search

We have learned about two incredible tools for automating hyperparameter tuning: Grid Search and Random Search.

Before we move on to even more advanced methods, it is crucial to stop and compare these two techniques side-by-side so you know exactly which tool to pull out of your toolbox!

## 1. What do they have in common?

Even though they search differently, the setup process for both tools is almost exactly the same.

*   **Automation:** Both are automated ways to test different hyperparameter combinations without you having to write messy `for` loops manually.
*   **The "Menu" (Parameter Grid):** For both tools, you must define the "menu" of hyperparameters and values you want to test.
*   **Garbage In, Garbage Out:** For both tools, your final model will only be as good as the menu you give it. If you provide silly or terrible values, neither tool will be able to magically fix them!
*   **The Grading Rubric:** Both tools require you to define a Cross-Validation scheme (like `cv=5`) and a scoring metric (like `accuracy` or `neg_mean_squared_error`) so they know how to grade the models fairly.

## 2. What are the key differences?

The difference lies entirely in how they read the menu.

### Grid Search (The Perfectionist)
*   **The Method:** It is completely exhaustive. It tests every single possible combination on the menu. There is no sampling or guessing.
*   **The Cost:** It is incredibly computationally expensive.
*   **The Guarantee:** Because it tests literally everything, it is 100% mathematically guaranteed to find the absolute best score available in your sample space.

### Random Search (The Adventurer)
*   **The Method:** It randomly grabs a subset of combinations from the menu (based on the `n_iter` you set). It defaults to a "uniform distribution," meaning every combination has an equal chance of being blindly drawn from the hat.
*   **The Cost:** It is highly economical and much faster.
*   **The Guarantee:** It is not guaranteed to find the absolute best score. However, because of the math of probability, it has a very high chance of finding a "good enough" score in a fraction of the time!

## 3. The Ultimate Decision: Which should I use?

As Data Scientists always say: "It depends!" However, you can use this simple checklist to decide which algorithm to run:

### Choose Grid Search if:
*   Your dataset is relatively small.
*   You only have 1 or 2 hyperparameters to tune.
*   You have plenty of time and computing power, and you absolutely must find the perfect mathematical combination.

### Choose Random Search if:
*   **You have a massive dataset:** Training even a single model takes a long time, so you can't afford to run thousands of tests.
*   **You have lots of hyperparameters:** If you have 3 or more hyperparameters, the Grid Search combinations will explode exponentially. Random Search prevents this.
*   **You have limited computing power/time:** If you need a great model by the end of the day, Random Search will quickly get you a highly competitive result without freezing your laptop!
