# Scikit-Learn's GridSearchCV

We know that a Grid Search tests every single possible combination of hyperparameters to find the absolute best model.

Instead of writing massive, confusing nested `for` loops by hand, Scikit-Learn gives us a magical all-in-one tool called `GridSearchCV`.

## 1. The 6 Steps of a Grid Search

*(Look at the Steps in a Grid Search screenshot).* Before we write any code, we have to make 6 decisions:

*   **Algorithm:** Which model are we tuning? (e.g., Random Forest, Logistic Regression).
*   **Hyperparameters:** Which dials do we want to turn?
*   **Values:** What are the exact numbers we want to test on those dials?
*   **Cross-Validation:** How many folds do we want to use to grade the models?
*   **Scoring:** What is the grading rubric? (e.g., Accuracy, Mean Squared Error).
*   **Extras:** Do we want to record extra training times or use parallel processing?

## 2. Breaking Down the GridSearchCV Inputs

*(Look at the GridSearchCV Object Inputs screenshot).* We pass our 6 decisions into the tool using these specific arguments:

### A. `estimator` (The Algorithm)
This is the base model you want to tune.
**Rule:** You can only put *one* algorithm in a Grid Search object at a time. (e.g., `estimator=RandomForestRegressor()`).

### B. `param_grid` (The Menu)
*(Look at the GridSearchCV 'param_grid' screenshots).* This is where you list the hyperparameters and values you want to test.
*   **Must be a Dictionary:** You cannot just pass a list. It must be a Python dictionary where the keys are the names of the hyperparameters, and the values are lists of numbers to test.
*   **The Typo Trap:** The keys in your dictionary MUST be spelled exactly like the real hyperparameters in Scikit-Learn. If you pass a fake parameter (like `'best_choice': [10, 20]`), the entire search will crash with a `ValueError`!

### C. `cv` (Cross-Validation)
This tells the computer how many folds to use when grading each combination. Simply passing an integer (like `cv=5` or `cv=10`) will automatically set up standard K-Fold cross-validation!

### D. `scoring` (The Grading Rubric)
How do we know which square on the grid was the "best"? We have to tell it how to keep score.
You can use strings for built-in metrics (like `scoring='accuracy'`) or create your own custom scoring functions.

### E. `n_jobs` (Hiring More Workers)
Grid Search is computationally expensive. `n_jobs` allows you to split the work across your computer's CPU cores!
If you set `n_jobs=4`, the computer will build 4 different models at the exact same time in parallel!
**Warning:** If you set `n_jobs=-1`, it will use 100% of your computer's processing power. Your models will train incredibly fast, but your computer might freeze if you try to open a web browser or do other work while it runs.

### F. `refit` (The Ultimate Time-Saver)
If you set `refit=True`, the Grid Search tool does something amazing at the very end.
Once it finds the absolute best combination of hyperparameters, it *automatically* builds a brand new model using those perfect settings, and trains it on your entire dataset.

## 3. Putting it all together (The Code)

*(Look at the Building a GridSearchCV Object and Using a GridSearchCV Object screenshots).* Here is exactly how we write it in Python!

```python
from sklearn.model_selection import GridSearchCV
from sklearn.ensemble import RandomForestClassifier

# 1. Define the base model (The Estimator)
rf_class = RandomForestClassifier()

# 2. Define the Menu (The Parameter Grid)
# This will test 4 depths x 4 leaf samples = 16 combinations!
parameter_grid = {
    'max_depth': [2, 4, 6, 8],
    'min_samples_leaf': [1, 2, 4, 6]
}

# 3. Build the Grid Search Object!
grid_rf_class = GridSearchCV(
    estimator=rf_class,
    param_grid=parameter_grid,
    scoring='accuracy',
    n_jobs=4,           # Run 4 models at a time
    cv=10,              # 10-Fold Cross Validation
    refit=True          # Automatically retrain the best model at the end!
)

# 4. Run the Search!
# This single line of code automatically builds and tests all 160 models (16 combos x 10 folds)!
grid_rf_class.fit(X_train, y_train)

# 5. Make Predictions
# Because we set refit=True, we don't have to extract the best model manually. 
# We can just use the 'grid_rf_class' object directly to predict on new data!
predictions = grid_rf_class.predict(X_test)
```
