# Understanding Grid Search Output

You just ran `GridSearchCV`. Your computer spent the last 10 minutes testing dozens of different hyperparameter combinations.

Now that it is finished, where are the results? Scikit-Learn stores all the answers inside the Grid Search object as **Properties** (attributes that end with an underscore `_`).

You access them using dot notation: `grid_search_object.property_name`

The output is broken down into three main categories:
1.  **A Results Log** (The complete report card of every test).
2.  **The Best Results** (Shortcuts to the winning model).
3.  **Extra Information** (Behind-the-scenes administrative data).

## 1. The Results Log (.cv_results_)

*(Look at your .cv_results_ screenshots).*

The `cv_results_` property contains a massive dictionary detailing exactly what happened during every single test. To make it readable, we immediately convert it into a Pandas DataFrame!

```python
import pandas as pd

# Convert the giant dictionary into a beautiful Pandas DataFrame!
cv_results_df = pd.DataFrame(grid_search_object.cv_results_)

print(cv_results_df.shape)
# Output: (12, 19)
```

*(In this example, the shape is 12 rows by 19 columns. This means our Grid Search tested 12 different combinations of hyperparameters, and recorded 19 pieces of information about each test!)*

Here is exactly what those 19 columns tell you:

### A. The 'Time' Columns
*   `mean_fit_time` & `std_fit_time`: How many seconds it took the computer to train the model on average across the 5 cross-validation folds.
*   `mean_score_time` & `std_score_time`: How many seconds it took to grade the test set.

### B. The 'Param' Columns
These columns tell you exactly what "recipe" (hyperparameters) was used for that specific row's test.
*   `param_max_depth`: e.g., 10
*   `param_min_samples_leaf`: e.g., 2
*   `param_n_estimators`: e.g., 100
*   `params`: A dictionary containing all the parameters combined `{'max_depth': 10, 'min_samples_leaf': 2, ...}`.

### C. The 'Score' Columns
This is the actual grading rubric for the 5 Cross-Validation folds!
*   `split0_test_score` through `split4_test_score`: The score for each individual fold.
*   `mean_test_score`: The final average score across all 5 folds.
*   `std_test_score`: How consistent the scores were (the standard deviation).
*(Note: If you asked it to record training scores, you will also see `mean_train_score` columns here!)*

### D. Finding the Winner (rank_test_score)
Scikit-Learn makes it incredibly easy to find the winning row. It adds a column called `rank_test_score`. The row with the best `mean_test_score` gets a rank of `1`.

```python
# Extract the absolute best row from the massive DataFrame!
best_row = cv_results_df[cv_results_df['rank_test_score'] == 1]
```

## 2. The Best Results (The Shortcuts)

Do you really want to convert a dictionary to a Pandas DataFrame and filter it just to find the winning parameters? No!

Scikit-Learn provides dedicated shortcut properties to instantly grab the winning information:

| Property | What it tells you | Example Output |
| :--- | :--- | :--- |
| `best_params_` | The exact dictionary of hyperparameters that won the competition. | `{'max_depth': 10, 'n_estimators': 100}` |
| `best_score_` | The actual best `mean_test_score` achieved by the winner. | `0.854` |
| `best_index_` | The exact row number (index) in the `cv_results_` table where the winner lives. | `3` |

### The Ultimate Prize: `best_estimator_`

When you set `refit=True` during your Grid Search setup, Scikit-Learn does something amazing.

Once it finds the best hyperparameters, it automatically builds a brand new model using those perfect settings, and trains it on your entire dataset. It saves this fully trained, battle-ready model in the `best_estimator_` property!

```python
# Extract the winning model
winning_model = grid_search_object.best_estimator_

# Immediately use it to predict new data! No retraining required!
predictions = winning_model.predict(X_new)
```

## 3. Extra Information

There are a few extra properties included in the object that you will rarely use, but are helpful for administrative tracking:

*   `scorer_`: Tells you what grading function was used (e.g., Accuracy or Mean Squared Error).
*   `n_splits_`: Tells you how many cross-validation folds were used.
*   `refit_time_`: Tells you exactly how many seconds it took to train that final `best_estimator_` on the whole dataset!
