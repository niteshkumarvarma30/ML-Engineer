# Bayesian Hyperparameter Tuning

We know that Grid Search and Random Search are "Uninformed." They blindly test hyperparameters. If they test a `max_depth` of 2 and get a terrible score, they don't learn anything from it. They just blindly move on to the next guess.

To make the computer smarter, we use an Informed Search. We want the computer to say: "Wow, a depth of 2 was terrible. I should probably test deeper numbers from now on!"

The most popular way to do this is using **Bayesian Statistics**.

## 1. What is Bayes Rule?

Bayes Rule is a famous 250-year-old mathematical formula. At its core, it is simply a way to update your beliefs based on new evidence.

Let's look at the medical example from the lesson:

*   **The Prior Belief ($P(A)$):** Before we know anything about a patient, we know that 5% of the general population has a specific disease. If a random person walks into the hospital, our baseline guess is that they have a 5% chance of being sick.
*   **The New Evidence ($P(B)$):** We run a test and find out this specific person has a genetic predisposition to the disease.
*   **The Update (The Posterior - $P(A\vert{}B)$):** We plug this new evidence into Bayes' math formula. The formula calculates that because they have this genetic marker, their chance of having the disease just jumped from 5% to 10%.

**The Takeaway:** We had an initial guess, we received new evidence, and we used math to update our guess to be much more accurate.

## 2. Applying Bayes to Machine Learning

We can use this exact same logic to tune our hyperparameters!

*   **The Prior:** The computer picks a random hyperparameter combination and builds a model.
*   **The Evidence:** The computer checks the cross-validation score of that model.
*   **The Update:** It uses Bayes' math to update its "brain." It now knows which areas of the grid are bad and which are promising.
*   **The Next Guess:** It uses its updated brain to pick a smarter combination for the next round!

## 3. How to do this in Python (Meet Hyperopt)

To do this in Python, we use a popular package called `hyperopt`.
To set it up, you need to give it three specific things:

### A. The Domain (The Grid)

In a standard Grid Search, you give the computer a hard list of numbers (e.g., `[2, 4, 6, 8]`).
In Hyperopt, you give it **Probability Distributions**.

For example, instead of a hard list, you tell it to use a uniform distribution between 2 and 10. This allows the Bayesian math to smoothly slide its guesses up and down a scale!

```python
from hyperopt import hp

# Set up the domain (the menu of options)
# 'quniform' means it will pick numbers evenly between 2 and 10, stepping by 1.
space = {
    'max_depth': hp.quniform('max_depth', 2, 10, 1),
    'learning_rate': hp.uniform('learning_rate', 0.001, 0.5)
}
```

### B. The Objective Function (The Scorekeeper)

Hyperopt needs a custom function to know how to grade the models.

**The Catch:** Hyperopt is hard-coded to always MINIMIZE the final score.
If your grading rubric is "Accuracy," you want the highest number possible. To trick Hyperopt into maximizing your accuracy, you must tell it to minimize `1 - Accuracy`. (e.g., If your accuracy is 0.90, it returns a loss of 0.10. Hyperopt will try to shrink that 0.10 down to 0!).

```python
from sklearn.model_selection import cross_val_score
from sklearn.ensemble import GradientBoostingClassifier

def objective_function(params):

    model = GradientBoostingClassifier(
        max_depth=int(params['max_depth']),
        learning_rate=params['learning_rate']
```

### C. The Optimization Algorithm (fmin)

Finally, we put it all together and unleash the algorithm!
Hyperopt uses a specific Bayesian algorithm called TPE (Tree-structured Parzen Estimator) to do the heavy lifting.

```python
from hyperopt import fmin, tpe, Trials
import numpy as np

# We use Trials() to save the results of every single guess so we can look at them later
results_log = Trials()

# Unleash the Bayesian Search!
best_params = fmin(
    fn=objective_function, # The scorekeeper
    space=space,           # The domain/grid
    algo=tpe.suggest,      # The Bayesian brain (TPE)
    max_evals=50,          # Only guess 50 times
    trials=results_log,    # Where to save the history
    rstate=np.random.default_rng(42) # The random seed
)

print("The smartest parameters found were:", best_params)
```

**The Result:** Even though you only let it guess 50 times, because it actually learned from every single mistake, it will likely find a much better hyperparameter combination than a blind Random Search ever could!
