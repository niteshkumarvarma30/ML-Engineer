# Automating Hyperparameter Tuning

Now that we know what hyperparameters are, we have to actually choose the numbers to test.

Instead of typing out 50 different models by hand to see which one works best, we can use Python to automate the entire process! Here is how to do it efficiently.

## 1. The "Silly Values" Trap

Before we automate anything, we need to know what numbers not to test. *(Look at your Silly Hyperparameter Values screenshot).*

Some numbers are technically allowed by the computer, but they are logically useless. If you test these, you are just wasting time and computer memory!

*   **Random Forest with 2 trees:** If you set `n_estimators=2`, is it really a "forest"? No. A Random Forest needs hundreds of trees to get the "wisdom of the crowd." Testing 2 or 5 trees is a waste of time.
*   **KNN with 1 neighbor:** If you set `n_neighbors=1`, the model just looks at the single closest dot and copies it. It has no "voting" power and will wildly overfit.
*   **Tiny Increments:** If you already tested 500 trees, testing 501 trees is not going to magically change your accuracy. Test in larger leaps!

## 2. Automating the Search (The for Loop)

*(Look at the Automating Hyperparameter Choice screenshot).*
If you want to test a KNN model with 5, 10, and 20 neighbors, doing it manually is tedious:

```python
knn_5 = KNeighborsClassifier(n_neighbors=5)
knn_10 = KNeighborsClassifier(n_neighbors=10)
knn_20 = KNeighborsClassifier(n_neighbors=20)
```

**The Fix:** *(Look at the Automating Hyperparameter Tuning screenshot).* We can use a simple Python `for` loop to do all the heavy lifting!

```python
# 1. Create a list of the numbers you want to test
neighbors_list = [3, 5, 10, 20, 50, 75]

# 2. Create an empty list to store the report cards (scores)
accuracy_list = []

# 3. Run the loop!
for test_number in neighbors_list:
    # Build the model using the current number
    model = KNeighborsClassifier(n_neighbors=test_number)
    
    # Train it and test it
    predictions = model.fit(X_train, y_train).predict(X_test)
    accuracy = accuracy_score(y_test, predictions)
    
    # Save the score to our report card list!
    accuracy_list.append(accuracy)

# 4. Put the results into a beautiful Pandas DataFrame
results_df = pd.DataFrame({'neighbors': neighbors_list, 'accuracy': accuracy_list})
print(results_df)
```

## 3. Visualizing the Sweet Spot (Learning Curves)

Looking at the table above, the accuracy stops improving after 20 neighbors. But what if we tested hundreds of values? A table becomes impossible to read.

Instead, we draw a Learning Curve.
*(Look at your Learning Curves screenshots).*

1.  We use `range(5, 500, 5)` to generate a massive list of numbers from 5 to 500, stepping by 5 each time.
2.  We run our `for` loop on all of them.
3.  We plot the results on a line graph using `matplotlib.pyplot`.

```python
import matplotlib.pyplot as plt

# Plot the X-axis (Neighbors) and Y-axis (Accuracy)
plt.plot(results_df['neighbors'], results_df['accuracy'])

plt.xlabel('n_neighbors')
plt.ylabel('Accuracy')
plt.title('Accuracy for different n_neighbors')
plt.show()
```

**How to read the Learning Curve Graph:**
*(Look at the graph in your final Learning Curves image).* The line shoots straight up at the beginning, but quickly hits a completely flat ceiling. This visually proves that adding more than 20 neighbors is a complete waste of time and computational power!

## 4. The Decimal Trick (np.linspace)

Python's built-in `range()` function is great, but it has a fatal flaw: It only works with whole numbers (integers).

What if you are testing a hyperparameter that requires decimals (like the `learning_rate` or a regularization penalty)? You can't use `range()`.

*(Look at your A handy trick for generating values screenshot).* To generate decimals, we use NumPy's `linspace` (Linear Space) function!

```python
import numpy as np

# np.linspace(start, end, number_of_items)
# "Give me exactly 5 numbers, evenly spaced between 1.0 and 2.0"
print(np.linspace(1, 2, 5))

# Output: [1.0, 1.25, 1.5, 1.75, 2.0]
```

This is the ultimate tool for quickly building a list of decimal hyperparameters to feed into your `for` loops or Grid Searches!
