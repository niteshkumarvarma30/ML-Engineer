# Intro to Model Parameters

Welcome to the world of Hyperparameter Tuning!

Modern machine learning algorithms are incredibly complex and have dozens of different settings. If you just rely on the default settings provided by scikit-learn, you are leaving a lot of accuracy on the table.

Before we can tune a model's Hyperparameters (the settings you control), we must first understand the model's Parameters (the things the model learns on its own).

## 1. The Dataset: Credit Card Defaults

*(See the The dataset screenshot)*

To practice tuning, we will be using a real-world dataset about credit card defaults in Taiwan.

*   **The Features (X):** 24 attributes about the financial history of 30,000 customers (e.g., How many months have their payments been delayed?).
*   **The Target (y):** Did they default on their loan? (Yes or No).

## 2. What exactly is a "Parameter"?

Parameters are the internal rules, numbers, and decisions that a model learns during the training process.

**The Golden Rule:** You DO NOT and CANNOT set these manually. The algorithm discovers them completely on its own when you hit `.fit()`.

Let's look at what these parameters look like in two completely different types of models.

## 3. Parameters in Logistic Regression

*(See the Parameters in Logistic Regression screenshots)*

Because Logistic Regression is a linear model, its parameters are the Coefficients (the math weights assigned to every single column in your dataset).

Once you fit the model, you can find these parameters hiding in the `.coef_` attribute!

```python
from sklearn.linear_model import LogisticRegression
import pandas as pd

# 1. Fit the model
log_reg_clf = LogisticRegression()
log_reg_clf.fit(X_train, y_train)

# 2. Extract the learned parameters (coefficients)
# We zip the column names together with the coefficients to make it readable
zipped_together = list(zip(X_train.columns, log_reg_clf.coef_[0]))
coefs = pd.DataFrame(zipped_together, columns=["Variable", "Coefficient"])

# 3. Sort them to see the most important parameters!
coefs.sort_values(by=["Coefficient"], axis=0, inplace=True, ascending=False)
print(coefs.head(3))
```

**The Output Table:**

| Variable | Coefficient |
| :--- | :--- |
| PAY_0 | 0.000751 |
| PAY_5 | 0.000438 |
| PAY_4 | 0.000435 |

**What did the model learn?** The model learned that the `PAY` columns (which represent how many months a payment was delayed) have the highest positive math weights. It figured out on its own that delayed payments are the biggest predictor of a loan default!

## 4. Parameters in a Random Forest

*(See the Parameters in Random Forest screenshots)*

Random Forests do not use linear math, so they don't have coefficients. They play a game of "20 Questions." So, what does a tree actually learn?

It learns the questions! Specifically, it learns which feature to split on, and what exact number to use for the split.

If you pull a single tree out of a trained Random Forest (`rf_clf.estimators_[7]`) and visualize it, you will see exactly what it learned:

*   **Node 1 Parameter:** `PAY_AMT4 <= 3869.5`
*   **Node 2 Parameter:** `BILL_AMT6 <= 20571.5`

You didn't tell the computer to split the data at exactly $3,869.50. The algorithm learned that specific parameter perfectly on its own during training!

**Code Tip:** You can programmatically extract these exact numbers using the `tree.feature` and `tree.threshold` attributes!

## 5. The Scikit-Learn Documentation Secret

*(See the Where to find Parameters screenshot)*

If parameters are generated automatically, how do you know what they are called in Python so you can look at them?

You have to check the scikit-learn documentation for the specific algorithm you are using.
**The Secret:** Do not look under the "Parameters" section of the website! Look under the "Attributes" section.

In scikit-learn, anything generated after the `.fit()` process is considered an Attribute, and it will almost always have a trailing underscore at the end of its name (e.g., `.coef_`, `.estimators_`, `.classes_`).
