# Parameters vs. Hyperparameters

We talk a lot about "tuning" our machine learning models to make them better. But what exactly are we tuning?

To understand this, we have to look at the two different types of settings inside a machine learning model: Parameters and Hyperparameters.

## 1. Model Parameters (The Computer's Job)

Model Parameters are the rules and numbers that the model learns completely on its own by studying the data. You do not set these manually.

*(Look at your Linear regression parameters screenshot).*
When you build a Linear Regression model, it has to draw a straight line through the data. To draw that line, it needs to know the slope (coefficient) and the starting point (intercept).

*   **The Code:** You use `lr.fit(X, y)` to tell the model to study the data.
*   **The Result:** Only after the model finishes studying do the parameters magically appear! You can view them using `.coef_` and `.intercept_`.

```python
from sklearn.linear_model import LinearRegression

lr = LinearRegression()

# If you try to print lr.coef_ here, you will get an ERROR! The model hasn't learned anything yet.

# Let the model study the data (This is when it calculates the Parameters)
lr.fit(X, y)

# NOW the parameters exist!
print(lr.coef_)      # Output: [2.5, -0.4, 1.2]
print(lr.intercept_) # Output: 10.5
```

## 2. Model Hyperparameters (Your Job)

Hyperparameters are the settings that the model cannot learn on its own. You, the Data Scientist, must manually set these before the training even begins!

Think of Hyperparameters as the dials and knobs on the outside of the machine.

*(Look at your Random forest hyperparameters screenshot).*
If you are building a Random Forest, you have to tell the computer how to build the forest before you hit `.fit()`. Here are a few common ones:

*   `n_estimators`: How many total trees should be in the forest?
*   `max_depth`: How many questions deep is each tree allowed to grow?
*   `min_samples_split`: If a leaf has 4 observations in it, is it allowed to split again? (If we set `min_samples_split=5`, the tree is strictly forbidden from splitting that leaf!).

```python
from sklearn.ensemble import RandomForestRegressor

# We set the HYPERPARAMETERS manually before the model ever sees the data!
rf = RandomForestRegressor(n_estimators=100, max_depth=5, min_samples_split=4)
```

## 3. What is Hyperparameter Tuning?

Because the model can't learn the hyperparameters on its own, how do we know which numbers are the best? Is `n_estimators=100` better than `n_estimators=500`?

We have to guess and check! This is called Hyperparameter Tuning.

*(Look at your Specifying ranges screenshot).*
We create a list of possible options (a range) for each dial. Then, we run the model multiple times, picking different combinations from our lists to see which combination gets the highest accuracy score!

```python
import random

# Create a menu of options to test
n_estimators_list = [50, 100, 150, 200]
max_depth_list = [3, 5, 10, 15]

# Pick a random combination to test!
random_trees = random.choice(n_estimators_list)
random_depth = random.choice(max_depth_list)
```

## 4. The "Too Many Dials" Problem

If you want to see every single hyperparameter a model has, you can use the `.get_params()` method.

*(Look at your Too many hyperparameters! screenshot).* When you run `rfc.get_params()`, it spits out a massive dictionary with 16 different hyperparameters!

**The Golden Rule:** Do not try to tune all 16 of them at the same time!
If you try to test every single combination of 16 different settings, your computer will literally take years to finish training.

**General Guideline:** Start small. Pick 2 or 3 basic hyperparameters that you actually understand (like `n_estimators` and `max_depth`), test a few ranges for them, and see how much your model improves!
