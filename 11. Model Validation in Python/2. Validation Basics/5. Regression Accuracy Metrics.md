# Regression Accuracy Metrics

When you build a Regression Model, you are trying to predict a continuous number (e.g., the number of points a basketball player will score, the win-percentage of a candy, or the number of puppies a dog will have).

You cannot grade these models using standard "Accuracy" percentages. Instead, you have to measure your **Error** (how far away your guess was from the true answer).

Here are the two main ways we measure this error in Scikit-Learn.

## 1. Mean Absolute Error (MAE)

*(See the Mean absolute error (MAE) screenshots)*

**The Concept:** This is the simplest and most intuitive metric. It just takes the absolute distance between your guess and the real answer, and averages them all together.

If you predict a dog will have 4 puppies, and it actually has 6, your absolute error is 2.

**The Formula:** $$MAE = \frac{\sum_{i=1}^{n} \vert{}y_i - \hat{y}_i\vert{}}{n}$$
(In English: Add up the absolute value of all your mistakes, and divide by the total number of guesses).

**When to use it:** Use MAE when you want to treat all mistakes equally, and you do not want to be sensitive to outliers.

**Example:** You are predicting your monthly gas bill. Most months you spend $40. One month you took a massive cross-country road trip and spent $400. MAE won't let that one crazy road trip ruin the average error of your normal months.

**The Python Code:**

```python
from sklearn.metrics import mean_absolute_error

# 1. Ask your trained model to make predictions on the Test Set
test_predictions = rfr.predict(X_test)

# 2. Compare the real answers (y_test) to the model's guesses
mae_score = mean_absolute_error(y_test, test_predictions)
print(mae_score) 
# Output: 9.99 (Meaning the model is off by about 9.99 percentage points on average)
```

## 2. Mean Squared Error (MSE)

*(See the Mean squared error (MSE) screenshots)*

**The Concept:** This is the most widely used regression metric. Instead of just taking the absolute difference, it squares the difference before averaging it.

**The Formula:** $$MSE = \frac{\sum_{i=1}^{n} (y_i - \hat{y}_i)^2}{n}$$
(In English: Subtract the guess from the real answer, square that mistake, add them all up, and divide by the total number of guesses).

**When to use it:** Use MSE when you want to severely punish large errors (outliers).

**Example:** If your guess is off by 2, MSE records an error of 4 ($2^2$). If your guess is off by 10, MSE records a massive error of 100 ($10^2$). It forces the model to pay close attention to extreme outliers (like ensuring it learns to predict that random family road trip!).

**The Python Code:**

```python
from sklearn.metrics import mean_squared_error

mse_score = mean_squared_error(y_test, test_predictions)
print(mse_score)
# Output: 141.4
```

## 3. Summary Comparison Table

Here is a quick cheat sheet to remember the differences. *(Note: Because MSE squares the numbers, you can never directly compare an MAE score to an MSE score!)*

| Feature | Mean Absolute Error (MAE) | Mean Squared Error (MSE) |
|---|---|---|
| **How it treats mistakes** | Treats all points equally. | Allows large outlier errors to contribute much more to the overall penalty. |
| **Sensitivity to Outliers** | Low (Ignores crazy anomalies) | High (Panics over crazy anomalies) |
| **Math Formula** | $\vert{}Actual - Predicted\vert{}$ | $(Actual - Predicted)^2$ |
| **Output Units** | Same as the original data (e.g., Dollars) | Squared units (e.g., Dollars-squared) |

## 4. Advanced Trick: Accuracy for a Subset of Data

What if you don't care about the overall average? What if you want to know exactly how well your model predicts Chocolate candies vs. Non-Chocolate candies?

Look at your Accuracy for a subset of data screenshot. You can filter your `X_test` and `y_test` arrays using a boolean mask before you run your error metric!

```python
# Assuming Column Index 1 is the "Is_Chocolate?" dummy variable (1 = Yes, 0 = No)

# 1. Filter the test set to ONLY show Chocolate candies, and make predictions
chocolate_preds = rfr.predict(X_test[X_test[:, 1] == 1])

# 2. Calculate the MAE for ONLY the Chocolate candies!
choc_mae = mean_absolute_error(y_test[X_test[:, 1] == 1], chocolate_preds)
print(f"Chocolate Error: {choc_mae}") # Output: 8.79

# 3. Do the same for Non-Chocolate candies (Column 1 == 0)
nonchocolate_preds = rfr.predict(X_test[X_test[:, 1] == 0])
nonchoc_mae = mean_absolute_error(y_test[X_test[:, 1] == 0], nonchocolate_preds)
print(f"Non-Chocolate Error: {nonchoc_mae}") # Output: 10.99
```

**The Verdict:** Because the error is lower for Chocolate (8.79) than Non-Chocolate (10.99), we know our Random Forest model is much better at predicting the win-percentage of chocolate candies!
