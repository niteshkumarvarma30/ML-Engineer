# Classification Metrics

Classification accuracy metrics are quite a bit different than regression ones. Remember, with classification models, we are predicting what **category** an observation falls into.

There are many accuracy metrics available for classification:
*   **Precision**
*   **Recall** (also called sensitivity)
*   **Accuracy**
*   **Specificity**
*   **F1-Score**, and its variations

We will focus on **precision**, **recall**, and **accuracy** as each of these are easy to understand and have very practical applications.

## 1. The Confusion Matrix

When making predictions, especially if there is a binary outcome, the confusion matrix is one of the first outputs you should review. It is a 2x2 matrix that shows how your predictions faired across the two outcomes.

### Creating a Confusion Matrix with scikit-learn

We can create a confusion matrix using scikit-learn's `confusion_matrix()` function.

```python
from sklearn.metrics import confusion_matrix
cm = confusion_matrix(y_test, test_predictions)
print(cm)
```
**Output:**
```text
array([[ 23,   7],
       [  8,  62]])
```

In this matrix, the **row index represents the true category**, and the **column index represents the predicted category**.

```python
# Accessing specific values: cm[<true_category_index>, <predicted_category_index>]
cm[1, 0]
```
**Output:** `8` *(This represents the number of true 1s that were incorrectly predicted to be 0).*

### Confusion Matrix Breakdown

Here is a visual breakdown of what each quadrant represents in a binary (0 or 1) classification:

| | Predicted 0 | Predicted 1 |
|---|---|---|
| **Actual 0** | **23 (TN)**<br>True Negative: Predict/Actual are both 0 | **7 (FP)**<br>False Positive: Predicted 1, actual 0 |
| **Actual 1** | **8 (FN)**<br>False Negative: Predicted 0, actual 1 | **62 (TP)**<br>True Positive: Predict/Actual are both 1 |

All of the main accuracy metrics can be calculated using the values from this matrix!

---

## 2. Accuracy

Accuracy is the easiest metric to understand and represents the overall ability of your model to correctly predict the classification.

**The Concept:** We add the values that were correctly predicted (True Negatives + True Positives), and divide by the total number of observations.

**The Formula:**
$$Accuracy = \frac{TN + TP}{Total} = \frac{23 + 62}{23 + 7 + 8 + 62} = 0.85$$

*(In this example, 85% of our predictions were correct).*

---

## 3. Precision

Precision focuses on the number of true positives out of **all predicted positive values**.

**The Concept:** We correctly predicted 62 true values (TP) but also accidentally predicted 7 false positives (FP).

**The Formula:**
$$Precision = \frac{TP}{TP + FP} = \frac{62}{62 + 7} = 0.90$$

**When to use it:** Precision is used when we **don't want to overpredict positive values**.
*Example:* If it costs $2,000 to fly in potential new employees for an interview, a company only wants to invite candidates they really believe will pass. High precision ensures that when the model says "Yes (1)", it is very likely correct.

---

## 4. Recall (Sensitivity)

Recall focuses on finding **all actual positive values**.

**The Concept:** We correctly predicted 62 true positives (TP), but we missed 8 false negatives (FN).

**The Formula:**
$$Recall = \frac{TP}{TP + FN} = \frac{62}{62 + 8} = 0.88$$

**When to use it:** Recall is used when we **can't afford to miss any positive values**.
*Example:* If a patient has a small chance of having cancer, we want to flag them for additional tests. The cost of missing a patient who actually has cancer (False Negative) is far greater than the cost of a few extra tests (False Positive).

---

## Summary in scikit-learn

Accuracy, precision, and recall are all calculated similarly in scikit-learn. Just provide the true and predicted values to get the single metric back:

```python
from sklearn.metrics import accuracy_score, precision_score, recall_score

accuracy = accuracy_score(y_test, test_predictions)
precision = precision_score(y_test, test_predictions)
recall = recall_score(y_test, test_predictions)
```
