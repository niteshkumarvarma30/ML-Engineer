**Solution:**

```python
from sklearn.metrics import mean_absolute_error

# Find the East conference teams
east_teams = labels == "E"

# Find the West conference teams
west_teams = labels == "W"

# Create arrays for the true and predicted values
true_east = y_test[east_teams]
preds_east = predictions[east_teams]
true_west = y_test[west_teams]
preds_west = predictions[west_teams]

# Print the accuracy for the East teams
print('The MAE for East teams is {}'.format(
    mean_absolute_error(true_east, preds_east)
))

# Print the accuracy for the West teams
print('The MAE for West teams is {}'.format(
    mean_absolute_error(true_west, preds_west)
))
```
