# Leave-One-Out Cross-Validation (LOOCV)

We know that K-Fold Cross-Validation chops our dataset into $K$ slices (e.g., 5 slices). It trains on 4 slices and tests on the 1 remaining slice, repeating the process 5 times.

But what if your dataset is incredibly small? You can't afford to lock away 20% of your data for testing. You need to use almost all of it for training.

Enter Leave-One-Out Cross-Validation (LOOCV).

## 1. What is LOOCV?

LOOCV takes the K-Fold concept to the absolute extreme. It sets $K$ equal to $n$ (the total number of rows in your entire dataset).

**How it works:**
If you have a dataset with exactly 100 rows:

*   **Model 1:** The computer trains the model on 99 rows, and tests it on Row #1.
*   **Model 2:** The computer trains the model on 99 rows (including Row 1), and tests it on Row #2.
*   **Model 3:** It trains on 99 rows and tests on Row #3.

*(This repeats 100 times until every single row has been the lone test subject exactly once).*

At the end, it takes the 100 individual error scores and averages them together to get the final grade!

## 2. When to Use It (And When to Run Away)

*(Look at your When to use LOOCV? screenshot).* Because this method is so extreme, it has distinct pros and cons.

✅ **USE IT WHEN:**

*   **Your data is extremely limited:** If you only have 50 rows of data in total, LOOCV allows you to use 49 rows for training every single time, giving your model as much information as mathematically possible to learn from!
*   **You want the absolute best error estimate:** Because every single point gets tested individually against a model trained on almost the entire dataset, this gives you the most highly accurate, unbiased estimate of how your model will perform on a single new real-world point.

❌ **BE CAUTIOUS WHEN:**

*   **You have a lot of data:** If your dataset has 100,000 rows, LOOCV will literally train your model 100,000 separate times. Your computer will likely freeze or take weeks to finish.
*   **You are tuning hyperparameters:** If you are using Grid Search to test 50 different parameter combinations, and each combination has to run 100,000 times... you are going to be waiting forever. LOOCV is highly computationally expensive!

## 3. How to Code LOOCV in Scikit-Learn

*(Look at your LOOCV Example screenshot).*

You don't actually need a special new function for this. You just use the exact same `cross_val_score()` shortcut we learned previously, but you change the `cv` parameter!

Instead of typing `cv=5`, you tell the computer to count how many rows are in your dataset (`X.shape[0]`), and you plug that massive number in!

```python
from sklearn.model_selection import cross_val_score
from sklearn.metrics import make_scorer, mean_squared_error

# 1. Find 'n' (The total number of rows in your dataset)
n = X.shape[0]

# 2. Create your custom scoring metric (e.g., Mean Squared Error)
mse_scorer = make_scorer(mean_squared_error)

# 3. Run the Cross-Validation!
# By setting cv=n, Scikit-Learn automatically knows to do Leave-One-Out!
cv_results = cross_val_score(estimator=rfr, X=X, y=y, scoring=mse_scorer, cv=n)

# 4. Check the results
# If n=100, this prints a massive list of 100 separate error scores
print(cv_results)

# 5. Get your final, highly accurate average error!
print(cv_results.mean())
```
