# Scikit-Learn's cross_val_score

In our previous lesson, we learned the gold-standard method for evaluating a model: K-Fold Cross-Validation.

We wrote a manual `for` loop that chopped the data into 5 slices, trained a new model on 4 slices, tested it on the 5th, and repeated the process 5 times.

What if I told you Scikit-Learn has a "Magic Button" that does that entire loop for you in one line of code?

## 1. The Magic Button: cross_val_score()

*(Look at your cross_val_score() screenshot: image_7e2755.png).*

Instead of messing with indices and `for` loops, you just pass your data into this function, and it handles all the splitting, training, and testing automatically!

Here are the 4 main parameters you need to give it:

| Parameter | What it means | Example |
| :--- | :--- | :--- |
| `estimator` | The specific machine learning model you want to test. | `RandomForestRegressor()` |
| `X` | Your complete dataset of features (the clues). | `X_train` |
| `y` | Your complete array of target values (the answers). | `y_train` |
| `cv` | The number of cross-validation splits (folds) you want to make. | `cv=5` (A 5-Fold split) |

## 2. Changing the Grading Rubric (make_scorer)

By default, `cross_val_score` will use a standard grading rubric depending on your model:

*   **For Classification:** It calculates overall Accuracy (Percentage right).
*   **For Regression:** It calculates R-Squared ($R^2$).

But what if you want to grade your regression model using Mean Squared Error (MSE) instead?

*(Look at your Using scoring and make_scorer screenshot: image_7e2afc.png).*

You have to create a custom grader using a tool called `make_scorer()`.

```python
from sklearn.metrics import mean_squared_error, make_scorer

# 1. Take the standard MSE function and wrap it in make_scorer to build a custom grader
mse_grader = make_scorer(mean_squared_error)

# 2. Pass that new grader into the cross_val_score function!
cv_results = cross_val_score(rfc, X, y, cv=5, scoring=mse_grader)
```

## 3. The Full Pipeline and Results

*(Look at your Load all of the sklearn methods and Accessing the results screenshots: image_7e2dc1.png and image_7e2dfe.png).*

When you run `cross_val_score`, it does not output a single number. Because we set `cv=5`, the model takes 5 separate tests. The output is a list of exactly 5 error scores!

```python
print(cv_results)
# Output: [196.765, 108.563, 85.963, 222.594, 140.942]
```

Notice how wildly different those scores are! The lowest error was ~85, but the highest error was ~222. If we had just done a single random Train/Test split, we might have gotten the 85 by pure luck and thought our model was a genius!

Because we used Cross-Validation, we see the whole truth. How do we summarize this?

### A. The Final Grade (The Mean)

We calculate the average of all 5 scores to get our final, realistic, "cheat-proof" estimate of how the model will perform in the real world.

```python
print(cv_results.mean())
# Output: 150.965
```

### B. Model Stability (The Standard Deviation)

We calculate the Standard Deviation to see how wildly the model's scores bounced around.

```python
print(cv_results.std())
# Output: 51.676
```

**How to read this:** A small standard deviation means the 5 scores were very tight and close together. The model is highly consistent and stable! A large standard deviation (like 51.6) means the model is highly sensitive to exactly how the data was shuffled.
