# Exercise

## When to use LOOCV

Which of the following are reasons you might **NOT** run LOOCV on the provided `X` dataset? The `X` data has been loaded for you to explore as you see fit.

*   **A:** The `X` dataset has 122,624 data points, which might be computationally expensive and slow.
*   **B:** You cannot run LOOCV on classification problems.
*   **C:** You want to test different values for 15 different parameters

### Possible answers

*   A & B
*   B & C
*   A & C
*   A

**Solution:**

**A & C**

*Both A and C are correct reasons to avoid LOOCV. LOOCV trains a model 'n' times (where 'n' is the number of rows). With 122,624 rows, it would train 122,624 models! Add in testing 15 different parameters, and your computer would be calculating for a very long time. LOOCV is best reserved for small datasets.*
