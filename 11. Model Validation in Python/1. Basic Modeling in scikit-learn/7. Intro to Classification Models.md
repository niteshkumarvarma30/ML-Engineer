# Intro to Classification Models

Welcome to the world of Classification!

Up until now, we have mostly talked about Regression models (models that predict a continuous number, like a house price or a person's age).

But what if the answer isn't a number? What if the answer is a category?

*   What is the newborn baby's hair color? (Brown, Blonde, Black)
*   What genre of music is this? (Rock, Rap, Jazz)
*   Did the patient pass or fail the test? (Pass, Fail)

When the response variable is categorical, we use Classification Models.

## 1. The Dataset: Tic-Tac-Toe

To test our classification skills, we are going to use a famous, fun dataset: The Tic-Tac-Toe End-Game Dataset.

*   **The Features (X):** The dataset has 9 columns. Each column represents one of the 9 squares on a Tic-Tac-Toe board. The cells contain either "X", "O", or "b" (blank).
*   **The Target (y):** The final column is our answer key. It simply says whether Player 1 won the game (positive) or did not win the game (negative).

Because the answer is a strict category (Win or Loss), this is the perfect dataset for a Classification model!

## 2. Generating Hard Answers (`.predict()`)

Look at your Using `.predict()` for classification screenshot.
Once you have trained your model (like a `RandomForestClassifier`), you can hand it brand new, unseen Tic-Tac-Toe boards and ask it to guess the winner!

```python
import pandas as pd

# 1. Ask the model to make predictions on the new test boards
predictions = rfc.predict(X_test)

# 2. See the results!
# We can wrap the predictions in a Pandas Series and use .value_counts() 
# to quickly tally up how many Wins (1) and Losses (0) the model guessed.
print(pd.Series(predictions).value_counts())
```

## 3. Generating Probabilities (`.predict_proba()`)

Sometimes, you don't want a hard "Yes" or "No" answer. You want to know exactly how confident the model is.

Look at your Predicting probabilities screenshot. We use a special method called `.predict_proba()`.

```python
# Ask the model for the raw percentages instead of the final guess
probabilities = rfc.predict_proba(X_test)
print(probabilities[1])
```

**The Output:** `[0.10, 0.90]`

**How to read this:** Every row will output an array of probabilities that always sums to 1.0 (100%). For this specific Tic-Tac-Toe board, the model is saying: "I am 10% sure Player 1 will lose, and 90% sure Player 1 will win!"

## 4. Looking Under the Hood (`.get_params()` and `.score()`)

Finally, look at your Methods continued screenshot. Scikit-Learn gives us two excellent administrative tools to check on our model.

### A. What settings am I using? (`.get_params()`)

If someone hands you a trained model, how do you know what hyperparameters they used? (e.g., How many trees are in this Random Forest?). You ask the model using `.get_params()`.

```python
# Prints a dictionary showing every single setting inside the model
print(rfc.get_params())
```

### B. How did I do? (`.score()`)

If you want to quickly grade your model without importing a bunch of complicated metric tools, you can just use the built-in `.score()` method!

For classification models, this method calculates Accuracy (the percentage of observations the model correctly labeled, ranging from 0.0 to 1.0).

```python
# Grade the model on the test data!
accuracy = rfc.score(X_test, y_test)
print(f"Model Accuracy: {accuracy}")
# Output: 0.89 (Almost 90% of the Tic-Tac-Toe games were predicted correctly!)
```
