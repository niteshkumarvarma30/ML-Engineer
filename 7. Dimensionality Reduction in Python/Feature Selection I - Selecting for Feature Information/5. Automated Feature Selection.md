# Concept

## Automated Feature Selection

In the last lesson, we learned that if we have too many columns, our model will suffer from the Curse of Dimensionality. We need to delete the bad columns.

But what if you have a massive dataset with 6,000 rows and 94 columns (like the ANSUR body measurement dataset)? You don't have time to manually look at 94 different scatterplots! You need to automate the process.

Here are two automated ways to find and destroy bad columns.

---

### 1. The "Boring Column" Filter (Variance Threshold)

**The Concept:** If you ask 100 people what their favorite color is, and 99 of them say "Blue," that question is boring. It doesn't help you tell those people apart. In math, we call this **Low Variance**. If a column's numbers barely change, the column is useless to a machine learning model.

**The Tool:** Scikit-learn has a tool called `VarianceThreshold`. You tell it exactly how much variance a column must have to be considered "interesting."

*   If a column's variance is above the threshold $\rightarrow$ Keep it.
*   If a column's variance is below the threshold $\rightarrow$ Trash it.

> [!WARNING]
> **The Normalization Trap**
>
> There is a massive mathematical trap here. Big numbers naturally have bigger variances.
> If you measure someone's weight in Grams, the variance will be a huge number. If you measure it in Tons, the variance will be a tiny decimal.
> 
> If you just run `VarianceThreshold` on raw data, it will unfairly delete all the columns with naturally small numbers!
> 
> **The Fix:** Before you run the threshold, you must **Normalize** the variance. You simply divide every column by its average (mean). This puts all the columns on a perfectly fair, level playing field!

---

### 2. The "Blank Column" Filter (Missing Values)

**The Concept:** In the real world, datasets are messy. People forget to fill out forms, or sensors break. These missing values show up in Pandas as `NaN` (Not a Number).

If a column is missing 1% of its data, you can just impute it (guess the average).
But if a column is missing 50% of its data? It's a terrible feature. You should completely delete the column.

**The Tool:** We use Pandas to calculate the exact ratio of missing values in every column. If that ratio crosses our threshold (e.g., 30% missing), we drop it!

---

### 3. The Secret Weapon: Boolean Masks

To actually delete the columns, we use a trick called a **Boolean Mask**.
Think of a mask as a VIP list for a nightclub. It is simply a list of `True` and `False` values.

*   Feature 1? `True` (Let it in).
*   Feature 2? `False` (Kick it out).

You pass this mask into your DataFrame using the `.loc[:, mask]` command, and Pandas will instantly delete all the `False` columns!

---

### 4. Cheat Sheet: Python Code

Here is how you automate both of these filters in Python!

#### A. Filtering Low Variance

```python
import pandas as pd
from sklearn.feature_selection import VarianceThreshold

# 1. THE NORMALIZATION FIX
# Divide the dataset by its own mean to level the playing field
normalized_df = df / df.mean()

# 2. Create the Selector 
# (Since we normalized, the variances are tiny, so we use a tiny threshold like 0.005)
selector = VarianceThreshold(threshold=0.005)

# 3. Fit the selector to the normalized data
selector.fit(normalized_df)

# 4. Get the VIP List (The Boolean Mask)
# This returns an array like: [True, True, False, True...]
mask = selector.get_support()

# 5. Apply the Mask to the ORIGINAL dataset!
# We use .loc[:, mask]. 
# The ':' means "Keep all rows". The 'mask' tells it which columns to keep!
reduced_df = df.loc[:, mask]
```

#### B. Filtering Missing Values

```python
# 1. Count the missing values (NaNs) in every column
missing_counts = df.isna().sum()

# 2. Divide by the total number of rows (len) to get a ratio between 0.0 and 1.0
missing_ratio = missing_counts / len(df)

# 3. Create the VIP List (The Boolean Mask)
# We ask a True/False question: Is the missing ratio less than 30%?
mask = missing_ratio < 0.3

# 4. Apply the Mask!
# Any column that had 30% or more missing data is instantly deleted.
reduced_df = df.loc[:, mask]
```
