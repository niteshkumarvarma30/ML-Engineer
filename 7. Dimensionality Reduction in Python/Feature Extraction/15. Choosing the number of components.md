### Solution

**Step 1, 2, & 3 Solution:**
```python

                 ('reducer', PCA(n_components=10))])

# Fit the pipe to the data
pipe.fit(ansur_df)

# Plot the explained variance ratio
plt.plot(pipe['reducer'].explained_variance_ratio_)

plt.ylabel('Explained variance ratio')
```
