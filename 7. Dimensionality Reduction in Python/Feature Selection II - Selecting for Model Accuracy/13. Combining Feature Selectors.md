# Combining Feature Selectors

In machine learning, we learned that Ensemble Models (like Random Forests) are powerful because they combine hundreds of weak trees into one massive, smart "Board of Directors." If one tree makes a mistake, the others vote and overrule it.

We can apply this exact same "Voting" logic to Feature Selection!

Instead of trusting just one algorithm to tell us which features to delete, we can ask three completely different algorithms to interview the features. If a feature gets enough votes, it stays. If it doesn't, we drop it!

## 1. The First Voter: Automated Lasso (LassoCV)

In a previous lesson, we used Lasso to automatically shrink useless coefficients to exactly 0.0.
But there was a catch: we had to manually guess the perfect alpha penalty.

To fix this, Scikit-Learn has a magical tool called `LassoCV`.

The CV stands for Cross-Validation. Instead of you guessing the alpha, `LassoCV` automatically tests dozens of different alphas behind the scenes and picks the absolute perfect one for you!

**The Vote:** Any feature that survives `LassoCV` (its coefficient is not zero) gets a `True` vote. If it was crushed to zero, it gets a `False` vote. We save this as `lcv_mask`.

## 2. The Second Voter: Random Forest (with RFE)

Next, we bring in a completely different type of model: A Random Forest Regressor.
Because it uses Decision Trees instead of linear math, it looks at the data from a totally different perspective.

We wrap it in RFE (Recursive Feature Elimination) so it automatically drops the weakest links.

**The Vote:** Any feature the Random Forest decides to keep gets a `True` vote. We save this as `rf_mask`.

## 3. The Third Voter: Gradient Boosting

Finally, we bring in a third algorithm: A Gradient Boosting Regressor.
Just like Random Forest, it calculates its own `feature_importances_`.

**The Vote:** Any feature that gradient boosting deems important gets a `True` vote. We save this as `gb_mask`.

## 4. Tallying the Votes!

Now we have three different lists of True and False votes (Boolean Masks).
In Python, True equals 1 and False equals 0. We can stack these lists on top of each other and add them up using `np.sum()`!

### The Code: How to Count the Votes

```python
import numpy as np

# 1. Stack the masks and sum them up vertically (axis=0)
# This looks at Feature 1 across all three masks, then Feature 2, etc.
votes = np.sum([lcv_mask, rf_mask, gb_mask], axis=0)

# Example Output of 'votes': [3, 1, 2, 0, 3, ...]
# Feature 1 got 3 votes!
# Feature 2 got 1 vote.
# Feature 4 got 0 votes (all models hated it).

# 2. Decide how strict you want to be
# Let's say a feature MUST get at least 2 votes to survive
final_mask = votes >= 2

# Example Output of 'final_mask': [True, False, True, False, True, ...]

# 3. Apply the final VIP list to the dataset!
X_reduced = X.loc[:, final_mask]
```

## How Strict Should You Be?

You are in total control of the final voting threshold:

*   **The Conservative Approach (votes >= 1):** "I don't want to accidentally lose any good information. If even one model thinks this feature is useful, keep it."
*   **The Balanced Approach (votes >= 2):** "I want a majority rules system." (This is what we used in the code above).
*   **The Aggressive Approach (votes == 3):** "I only want the absolute best features. A feature must get a unanimous 'Yes' from all 3 models to stay."
