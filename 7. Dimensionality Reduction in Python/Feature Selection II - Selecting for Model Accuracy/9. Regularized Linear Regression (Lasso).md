# Concept

## Regularized Linear Regression (Lasso)

So far, we have looked at how to reduce dimensions by throwing away columns manually or using trees. But what if we could use a math formula that automatically figures out which columns are useless and deletes them for us while training?

We can do this using Regularized Linear Regression. Here is exactly how it works, based on the visual examples in your lesson.

### 1. The Setup: Creating a "Rigged" Dataset

To understand how regression models learn, the instructor created a fake dataset where we know the absolute truth.

![Setup Part 1](images/Screenshot%202026-07-09%20172632.png)
![Setup Part 2](images/Screenshot%202026-07-09%20172657.png)

We have 3 features ($x_1, x_2, x_3$) and a Target ($y$).
The instructor created the target using this exact formula:
$y = 20 + 5x_1 + 2x_2 + 0x_3 + error$

*   **The Intercept:** 20 (The starting point).
*   **The Good Features:** $x_1$ gets multiplied by 5, and $x_2$ gets multiplied by 2. They heavily impact the target.
*   **The Useless Feature:** $x_3$ gets multiplied by 0. It has absolutely no effect on the target. It is a complete distraction!

### 2. Standard Linear Regression (The Problem)

If we feed this data into a standard `LinearRegression()` model, it tries to learn those secret numbers (coefficients).

![Standard Linear Regression](images/Screenshot%202026-07-09%20172756.png)
![Standard Linear Regression Coefs](images/Screenshot%202026-07-09%20172833.png)

*   **What it guessed:** `[4.95, 1.83, -0.05]`
*   **The R-Squared (Accuracy):** 97.6%

It did a great job guessing $x_1$ and $x_2$. But look at $x_3$. Instead of giving it a perfect 0.0, the model got slightly confused by the random noise and gave it a small coefficient of -0.05.
If you have hundreds of useless features, the model will give all of them tiny coefficients, resulting in massive overfitting.

### 3. The Loss Function (The Gray Squares)

Why did the model get distracted? Because of its Loss Function.

Standard Linear Regression uses Mean Squared Error (MSE).
Look at the graph with the diagonal line and the gray squares.

![The Loss Function](images/Screenshot%202026-07-09%20172840.png)
![The Loss Function Visual](images/Screenshot%202026-07-09%20172853.png)

1.  The model draws a line.
2.  It measures the distance from the line to the real data point, and draws a literal square out of that distance.
3.  Its only goal in life is to make the total area of those gray squares as small as possible.

Because it is obsessed with shrinking the gray squares, it will use every single feature (even useless ones like $x_3$) to try and warp the line to perfectly hit every dot. This is overfitting!

### 4. The Fix: Adding Regularization (Lasso)

To stop the model from overfitting, we change the rules of the game. We add a Regularization Penalty to the MSE.

![Adding Regularization Lasso](images/Screenshot%202026-07-09%20172943.png)

Look at the formula in your image:
**Total Loss = MSE + $\alpha(|\beta_1| + |\beta_2| + |\beta_3|)$**

The model now has two competing goals:
1.  **Make the model accurate:** Shrink the gray squares (MSE).
2.  **Make the model simple:** Keep the coefficients ($\beta$) as close to zero as possible!

This specific penalty (using absolute values) is called **L1 Regularization**, or **Lasso** (Least Absolute Shrinkage and Selection Operator).

### 5. Lasso in Action (Tuning Alpha)

The strictness of this new penalty is controlled by Alpha ($\alpha$).

![Lasso in Action Tuning Alpha](images/Screenshot%202026-07-09%20173016.png)

#### Scenario A: Alpha is too high (The Default)

If we run `Lasso()` with its default settings ($\alpha=1.0$), the penalty is very strict.

![Lasso Alpha too high](images/Screenshot%202026-07-09%20173033.png)

*   **The Coefficients:** `[4.07, 0.59, 0.0]`
*   **The R-Squared:** 86.1%
*   **The Verdict:** It successfully crushed the useless $x_3$ coefficient to exactly 0.0 (acting as an automatic feature selector!). BUT, the penalty was so strict that it also crushed the good coefficients ($4.07$ instead of $5$, and $0.59$ instead of $2$). The model became too simple, and accuracy plummeted to 86%.

#### Scenario B: Alpha is "Just Right"

We need to relax the penalty. We change the code to `Lasso(alpha=0.05)`.

![Lasso Alpha Just Right](images/Screenshot%202026-07-09%20173052.png)
![Lasso Summary](images/Screenshot%202026-07-09%20173111.png)

*   **The Coefficients:** `[4.91, 1.76, 0.0]`
*   **The R-Squared:** 97.4%
*   **The Verdict:** Perfect! The penalty is just strong enough to keep the useless $x_3$ completely erased (0.0), but it is loose enough to allow $x_1$ and $x_2$ to grow back to their correct, true sizes. We get our amazing 97.4% accuracy back, but with a much simpler, robust model!

### Cheat Sheet: Python Code

Here is how you execute standard Linear Regression vs. Lasso Regression to automatically delete useless features!

```python
from sklearn.linear_model import LinearRegression, Lasso

# 1. Standard Linear Regression (Prone to overfitting useless features)
lr = LinearRegression()
lr.fit(X_train, y_train)

print("Standard Coefficients:", lr.coef_) 
# Output: [4.95, 1.83, -0.05] (Failed to ignore feature 3)

# 2. Lasso Regression (With tuned alpha)
# We set alpha=0.05 to balance accuracy with simplicity
la = Lasso(alpha=0.05)
la.fit(X_train, y_train)

print("Lasso Coefficients:", la.coef_)
# Output: [4.91, 1.76, 0.] (Successfully crushed feature 3 to exactly zero!)
print("Lasso R-Squared:", la.score(X_test, y_test))
```
