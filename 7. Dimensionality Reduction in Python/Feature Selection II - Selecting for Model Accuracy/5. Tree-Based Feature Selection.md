# Concept

## Tree-Based Feature Selection

In previous lessons, we used Logistic Regression to find the best features. But remember the "Golden Rule" of linear models? You have to scale the data first so the coefficients are fair.

What if you don't want to deal with scaling? You use a Random Forest!

### 1. Why Random Forests are Magic

A Random Forest is an ensemble of hundreds of Decision Trees.
Because Decision Trees just play a game of "20 Questions" (e.g., "Is Height > 60?"), they don't care about the scale of the numbers. They naturally avoid the curse of dimensionality and rarely overfit, even with the default settings.

When a Random Forest trains, it keeps a running tally of exactly which questions (features) did the best job of splitting the data. Questions asked near the top of the tree (the Root) are highly important, while questions asked at the tiny bottom branches are less important.

### 2. Feature Importances (Reading the Forest's Mind)

Once the Random Forest finishes training, you can literally ask it to hand you its tally sheet using the `feature_importances_` attribute.

**The Magic Math:**
Unlike Logistic Regression coefficients (which can be any random large or small number), a Random Forest automatically converts its scores into percentages. 
The sum of all feature importances will always equal exactly `1.0` (100%).

*   If a feature has a score of `0.14`, it means that feature contributed 14% of the brainpower to the final predictions.
*   If a feature has a score of `0.00`, the forest completely ignored it.

#### The Manual Mask Method

You can use these percentages to manually drop weak features using a Boolean Mask!

```python
from sklearn.ensemble import RandomForestClassifier

# 1. Train the model (No scaling required!)
rf = RandomForestClassifier()
rf.fit(X_train, y_train)

# 2. Create a VIP List (Mask)
# Keep only the features that contributed more than 10% (0.1) to the model!
mask = rf.feature_importances_ > 0.1

# 3. Apply the mask to shrink the dataset
X_reduced = X.loc[:, mask]
```

### 3. RFE with Random Forests (The Automated Way)

Just like we did with Logistic Regression, we can wrap a Recursive Feature Eliminator (RFE) around our Random Forest to automatically drop the weakest features and retrain the model.

> [!WARNING]
> **The Time Problem**
> 
> Random Forests are heavy. If you have 94 features and you want to reduce it down to 6, RFE has to train the entire Random Forest, drop 1 feature, train the entire forest again, drop 1 feature, etc. Doing this 88 times in a row will take a massive amount of computing time!

**The Fix (The `step` parameter):**
To speed things up, we use the `step` parameter inside RFE. 
If we set `step=10`, we tell RFE: *"Instead of dropping the weakest feature one-by-one, chop off the bottom 10 weakest features all at once, then retrain."*

This drastically reduces the number of times the forest has to rebuild itself, saving you huge amounts of time!

### 4. Cheat Sheet: Python Code

Here is how you write the optimized RFE code with a Random Forest:

```python
from sklearn.feature_selection import RFE
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 1. Setup RFE
# We want exactly 6 features.
# We drop 10 features at a time (step=10) to make it run fast!
rfe = RFE(estimator=RandomForestClassifier(), 
          n_features_to_select=6, 
          step=10, 
          verbose=1)

# 2. Fit RFE to the training data
rfe.fit(X_train, y_train)

# 3. See the surviving features!
# rfe.support_ acts as our Boolean Mask
surviving_columns = X.columns[rfe.support_]
print("Best Features:", surviving_columns)

# 4. Check the accuracy of the shrunken model
y_pred = rfe.predict(X_test)
print("Accuracy:", accuracy_score(y_test, y_pred))
```
