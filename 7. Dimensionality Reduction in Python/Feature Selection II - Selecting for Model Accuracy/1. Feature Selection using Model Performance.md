# Concept

## Feature Selection using Model Performance

So far, we have deleted columns that were "boring" (low variance), "blank" (missing data), or "redundant" (highly correlated).

But what if you have 10 columns left, and you only want to keep the 2 absolute best ones? You can't just guess. Instead, you train a machine learning model and ask the model which columns it found the most useful!

### 1. The Model's "Brain": Coefficients

When you train a linear model (like Logistic Regression), it figures out the math by assigning a "weight" or Coefficient to every single column.

*   **High Coefficient** (e.g., `7.46`): The model relies heavily on this feature. It is incredibly important.
*   **Near-Zero Coefficient** (e.g., `0.14`): The model basically ignores this feature. Because multiplying any number by 0 equals 0, this feature contributes almost nothing to the final prediction.

If a feature has a coefficient close to zero, it is safe to throw it in the trash!

> [!WARNING]
> **The Golden Rule: You MUST Scale First!**
> 
> You can only compare coefficients if you have put all your features on a level playing field using `StandardScaler`.
> 
> If you don't scale your data, a tiny coefficient might just mean the original numbers in that column were massive (like Salary in dollars vs. Age in years). By scaling the data so every column has a mean of 0 and a variance of 1, you guarantee that the coefficients are a true measure of importance.

### 2. The Manual Method (Dropping one by one)

If you look at the ANSUR dataset example in the lesson:

**Ansur dataset sample**
| Gender | chestdepth | handlength | neckcircumference | shoulderlength | earlength |
|---|---|---|---|---|---|
| Female | 243 | 176 | 326 | 136 | 62 |
| Female | 219 | 177 | 325 | 135 | 58 |
| Male   | 259 | 193 | 400 | 145 | 71 |
| Male   | 253 | 195 | 380 | 141 | 62 |

*   We trained a Logistic Regression model to predict Gender. It scored 99% accuracy.
*   We looked at the coefficients using `lr.coef_`.
*   The `handlength` feature had an absurdly tiny coefficient (`0.14`) compared to `neckcircumference` (`7.46`).
*   We manually dropped `handlength`, retrained the model, and the accuracy stayed at 99%. The feature was completely useless!

### 3. The Automated Method: RFE (Recursive Feature Elimination)

Doing this manually for 100 columns would take forever. Furthermore, if you drop a column, the model's math changes, so the other coefficients will shift around!

To do it perfectly, we use **Recursive Feature Elimination (RFE)**.

"Recursive" just means it repeats a cycle over and over:
1. It trains the model on all features.
2. It looks at the coefficients and drops the single weakest feature.
3. It retrains the model from scratch on the remaining features (because the coefficients will shift!).
4. It drops the next weakest feature.
5. It repeats this until it reaches the exact number of features you asked for.

### 4. Cheat Sheet: Python Code

Here is how you use RFE in Scikit-Learn to automatically boil your dataset down to the best features!

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.feature_selection import RFE
from sklearn.metrics import accuracy_score

# 1. Split the data
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)

# 2. SCALE THE DATA (Crucial so we can compare coefficients fairly)
scaler = StandardScaler()
X_train_std = scaler.fit_transform(X_train)
X_test_std = scaler.transform(X_test)

# 3. Setup the RFE Tool
# We tell it we want to use LogisticRegression, and we only want to keep the 2 best features!
rfe = RFE(estimator=LogisticRegression(), n_features_to_select=2, verbose=1)

# 4. Fit RFE to the scaled training data
# This triggers the automated loop of training, dropping the weakest link, and retraining!
rfe.fit(X_train_std, y_train)

# ==========================================
# 5. INSPECTING THE RESULTS
# ==========================================

# rfe.support_ gives us a True/False mask (VIP list) of the features it kept
kept_features = X.columns[rfe.support_]
print("Kept Features:", kept_features)

# rfe.ranking_ tells us exactly when a feature was eliminated. 
# Rank 1 means it survived to the end! Rank 4 means it was eliminated early.
print("Feature Rankings:", dict(zip(X.columns, rfe.ranking_)))

# 6. Test the final, reduced model!
# Even with just 2 features, the model will likely still perform amazingly well.
y_pred = rfe.predict(X_test_std)
print("Final Accuracy:", accuracy_score(y_test, y_pred))
```
