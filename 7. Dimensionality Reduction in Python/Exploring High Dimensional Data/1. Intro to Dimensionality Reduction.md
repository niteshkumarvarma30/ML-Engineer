# Concept

## Intro to Dimensionality Reduction

When working with data, you will often hear the phrase "Dimensionality." In simple terms, dimensionality just means the number of columns (features) your dataset has.

If a dataset has 500 columns, it is "High-Dimensional." While having lots of data sounds good, having too many columns makes it incredibly hard for machine learning algorithms to find patterns. Dimensionality Reduction is the process of safely deleting or squishing those columns to make the dataset smaller and easier to analyze.

Let's break down the basics using the Pokémon dataset!

---

### 1. The Golden Rule: "Tidy Data"

Before doing any data science, your data must be "Tidy." This means it follows a strict grid format:

*   **Columns = Variables (Features):** Every column represents one specific trait. (e.g., Name, Type, Attack, Speed).
*   **Rows = Observations:** Every row represents one single entity. (e.g., The entire first row is dedicated completely to Bulbasaur).
*   **Cells = Values:** Every intersection has a single piece of information.

---

### 2. Checking Dimensions with `.shape`

How do you know how big your dataset is? You use the Pandas `.shape` attribute.

| Name | Type | HP | Attack | Defense | Speed | Generation |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Bulbasaur | Grass | 45 | 49 | 49 | 45 | 1 |
| Ivysaur | Grass | 60 | 62 | 63 | 60 | 1 |
| Venusaur | Grass | 80 | 82 | 83 | 80 | 1 |
| Charmander | Fire | 39 | 52 | 43 | 65 | 1 |
| Charmeleon | Fire | 58 | 64 | 58 | 80 | 1 |

```python
pokemon_df.shape
```
> `(5, 7)`

**What it means:** The first number is the rows (5 Pokémon). The second number is the columns (7 features).

Therefore, this dataset currently has a **Dimensionality of 7**.

---

### 3. When to Reduce Dimensions (The "Zero Variance" Rule)

How do we decide which columns to throw away? We look for columns that have **No Variance**.
Variance means change or difference. If a column is exactly the same for every single row, it is completely useless for finding patterns or differences between the Pokémon.

**Looking at the table above:** Notice the `Generation` column. Every single Pokémon in this tiny dataset has a `1` in that column.

Because it never changes, it provides zero helpful information. We can safely drop this column, instantly reducing our dimensionality from 7 down to 6!

---

### 4. The `.describe()` Method (For Numbers)

To quickly find useless columns without having to read the whole spreadsheet with your own eyes, we use `pokemon_df.describe()`.

By default, this function looks only at numeric columns and calculates summary math.

```python
pokemon_df.describe()
```

| | HP | Attack | Defense | Speed | Generation |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **count** | 5.0 | 5.0 | 5.0 | 5.0 | 5.0 |
| **mean** | 56.4 | 61.8 | 59.2 | 66.0 | 1.0 |
| **std** | 15.9 | 13.0 | 15.4 | 14.7 | 0.0 |
| **min** | 39.0 | 49.0 | 43.0 | 45.0 | 1.0 |
| **25%** | 45.0 | 52.0 | 49.0 | 60.0 | 1.0 |
| **50%** | 58.0 | 62.0 | 58.0 | 65.0 | 1.0 |
| **75%** | 60.0 | 64.0 | 63.0 | 80.0 | 1.0 |
| **max** | 80.0 | 82.0 | 83.0 | 80.0 | 1.0 |

**Looking at the table:** Look at the `std` (Standard Deviation) row. Standard Deviation is a mathematical measure of variance (how spread out the numbers are).

*   The HP has an std of 15.9 *(lots of variance)*.
*   The Generation has an std of **0.0**.

Whenever you see a standard deviation of 0.0, it is mathematical proof that the column never changes and can be safely dropped!

---

### 5. The `.describe(exclude='number')` Method (For Text)

What about columns that contain text, like Name or Type? The standard `.describe()` ignores them because it can't calculate a standard deviation for the word "Grass".

If you pass `exclude='number'` into the function, it switches modes to analyze text/categorical data!

```python
pokemon_df.describe(exclude='number')
```

| | Name | Type |
| :--- | :--- | :--- |
| **count** | 5 | 5 |
| **unique** | 5 | 2 |
| **top** | Charmander | Grass |
| **freq** | 1 | 3 |

**Looking at the table:** It tells us the count (5 items total) and the unique count (how many distinct words there are).

*   **The Type Column:** We can see there are only `2` unique types. The top (most frequent) type is `Grass`, and its freq (frequency) is `3`. (Meaning 3 out of the 5 Pokémon are Grass-type!).

By understanding the shape, variance, and summaries of your dataset, you are taking the crucial first steps toward cleaning it up and preparing it for advanced Dimensionality Reduction techniques (like PCA) later on!
