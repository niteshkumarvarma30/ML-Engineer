# Concept

## XGBoost for Regression

In the previous chapter, we used XGBoost to solve Classification problems. We were predicting categories (e.g., "Will this person buy insurance? Yes or No").

Now, we are stepping into the world of **Regression**.

---

### 1. What is Regression?

Regression is the branch of machine learning where you try to predict a **continuous, real number**.

* **Classification Example:** Is this animal a Dog or a Cat?
* **Regression Example:** Based on a baby's weight and genetics at birth, exactly how tall will they be in centimeters when they are 30 years old? Or, what will the exact price of this house be in dollars?

Because we are predicting a sliding scale of infinite numbers, we can't grade the model using "Accuracy." *(If a house costs $300,000 and your model predicts $300,001, it is technically "wrong," but an accuracy score of 0% would be unfair!)*.

Instead, we have to measure the **Error** (the distance between our guess and the true answer).

---

### 2. The Two Heavyweight Metrics

When grading a Regression model, data scientists almost always use one of two metrics.

#### A. RMSE (Root Mean Squared Error)
This is the absolute most common metric for regression. Here is how it calculates your grade:

1. **The Difference:** It looks at your guess vs. the true answer *(e.g., You guessed 10, the answer was 15. The difference is -5)*.
2. **The Square:** It squares that difference. ($-5 \times -5 = 25$). This does two things: it makes all negative numbers positive, and it massively punishes big mistakes. *(An error of 2 becomes 4, but an error of 10 blows up to 100!)*.
3. **The Mean:** It calculates the average of all these squared penalties across your entire dataset.
4. **The Root:** Finally, it takes the square root of that average to shrink the number back down to a readable, normal scale.

* **When to use it:** Use RMSE when making a massive mistake is highly dangerous to your business, and you want to mathematically penalize the model heavily for wild outliers.

#### B. MAE (Mean Absolute Error)
This is the simpler, more human-readable metric.

1. **The Absolute Difference:** It looks at the distance between your guess and the answer, and just ignores the negative sign. *(If you guess 10 and the answer is 15, the error is simply 5)*.
2. **The Mean:** It just adds up all the errors and finds the average.

* **When to use it:** Use MAE when you want a simple, easy-to-explain number *(e.g., "Our model is off by an average of $500 per house")*. It treats all errors equally, so it doesn't freak out over one or two massive outliers like RMSE does. *(However, computers prefer the math behind RMSE, so MAE is used less frequently to actually train models)*.

---

### 3. The "Chameleon" Algorithms

Some algorithms are "one-trick ponies." For example, standard Logistic Regression can only do classification.

However, some algorithms are **chameleons**: they can do both Classification AND Regression without breaking a sweat.

**Decision Trees are the ultimate chameleons.**

* If you want to do classification, they drop the data into a leaf node and take a **Majority Vote**.
* If you want to do regression, they drop the data into a leaf node and calculate the **Average**.

Because Decision Trees are so effortlessly flexible, they make the absolute perfect building blocks (Base Learners) for the XGBoost algorithm!

---

### 4. Objective Functions (The Rules of the Game)

To tell XGBoost how to measure its mistakes during training, we must define an **Objective Function** (also known as a Loss Function).

This is the penalty score the model is trying to minimize. You must pass this setting into XGBoost so it knows what kind of math to do!

* `reg:squarederror`: Use this for Regression. It tells the model to minimize the Squared Error (RMSE).
* `binary:logistic`: Use this for Binary Classification. It tells the model to output probabilities (0.0 to 1.0) for a Yes/No question.

---

### 5. Base Learners (Trees vs. Lines)

XGBoost is an ensemble. It is a factory made up of many individual workers. Those individual workers are called **Base Learners**.

The idea is that each Base Learner is relatively weak. On its own, it makes lots of mistakes. But when you add hundreds of them together, their random mistakes cancel each other out, and their good guesses combine into one massive, highly accurate prediction.

XGBoost gives you a choice of which workers to hire:

* **Tree Booster (`gbtree`):** This is the default. The factory is filled with Decision Trees (CARTs). They are amazing at capturing curvy, non-linear relationships.
* **Linear Booster (`gblinear`):** You can actually fire the trees and replace them with standard Linear Regression models! If your data is perfectly linear, you can use XGBoost to simply calculate a highly optimized, regularized straight line.

---

### 6. Cheat Sheet: Python Code Examples

Here is how you write the code for Regression in XGBoost. Notice that we use the familiar Scikit-Learn API for the Tree models, but we use the Native Learning API (with the `DMatrix`) for the Linear models!

#### Example A: Trees as Base Learners (Scikit-Learn API)

```python
import xgboost as xgb
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

# 1. Load Data & Split
boston_data = pd.read_csv("boston_housing.csv")
X, y = boston_data.iloc[:, :-1], boston_data.iloc[:, -1]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=123)

# 2. Instantiate the XGBRegressor
# Note the objective is set for regression!
xg_reg = xgb.XGBRegressor(objective='reg:squarederror', n_estimators=10, seed=123)

# 3. Fit and Predict
xg_reg.fit(X_train, y_train)
preds = xg_reg.predict(X_test)

# 4. Grade the Test using RMSE
rmse = np.sqrt(mean_squared_error(y_test, preds))
print("Tree RMSE: %f" % (rmse))
```

#### Example B: Linear Base Learners (Native Learning API)

To use linear base learners, we have to switch over to XGBoost's native API.

```python
# ... (Assuming X_train and X_test are already split) ...

# 1. Convert data to the highly optimized DMatrix
DM_train = xgb.DMatrix(data=X_train, label=y_train)
DM_test = xgb.DMatrix(data=X_test, label=y_test)

# 2. Define the Parameter Dictionary
# We explicitly tell it to use the "gblinear" booster instead of trees!
params = {
    "booster": "gblinear", 
    "objective": "reg:squarederror"
}

# 3. Train the model using xgb.train()
xg_reg_linear = xgb.train(params=params, dtrain=DM_train, num_boost_round=10)

# 4. Predict (Make sure you pass the DMatrix to the predict function!)
preds_linear = xg_reg_linear.predict(DM_test)

# 5. Grade the Test using RMSE
rmse_linear = np.sqrt(mean_squared_error(y_test, preds_linear))
print("Linear RMSE: %f" % (rmse_linear))
```
