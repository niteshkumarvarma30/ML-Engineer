# Exercise

## When should you use grid search and random search?

### Concept: The Drawbacks of Uninformed Search
Now that you've seen some of the drawbacks of grid search and random search, which of the following most accurately describes why both random search and grid search are non-ideal search hyperparameter tuning strategies in all scenarios?

### Possible Answers

1. Grid Search and Random Search both take a very long time to perform, regardless of the number of parameters you want to tune.
2. Grid Search and Random Search both scale exponentially in the number of hyperparameters you want to tune.
3. The search space size can be massive for Grid Search in certain cases, whereas for Random Search the number of hyperparameters has a significant effect on how long it takes to run.
4. Grid Search and Random Search require that you have some idea of where the ideal values for hyperparameters reside.

---

### Solution

**Correct Answer:** 4

**Explanation:**
* **Option 1 (Incorrect):** This is false. If you only have a few parameters in your grid, Grid Search is very fast. And Random Search's time is entirely dictated by the `n_iter` parameter you set.
* **Option 2 (Incorrect):** The *search space* scales exponentially, but the actual time to perform a Random Search does not, because you artificially limit it with `n_iter`.
* **Option 3 (Incorrect):** As mentioned above, the number of hyperparameters does not significantly affect how long Random Search takes, because you explicitly tell it how many iterations (`n_iter`) it is allowed to run.
* **Option 4 (Correct):** Because Grid Search and Random Search are "uninformed" (meaning they don't use AI to learn from their past guesses), you are entirely responsible for building the "menu" of options they test. If the true ideal `max_depth` is `3`, but you build a grid containing `[10, 20, 30]`, neither method will ever find the true optimal model. You *must* have a general, educated intuition of where the ideal hyperparameter values live before you start searching!
