## Which of these is a binary classification problem?

### Concept: Binary vs. Multi-class
Great! A classification problem involves predicting the category a given data point belongs to out of a finite set of possible categories. 

Depending on how many possible categories there are to predict, a classification problem can be either binary or multi-class. 

* **Binary:** Exactly 2 options (True/False, 1/0, Yes/No, Cat/Not Cat).
* **Multi-class:** 3 or more options (Cat/Dog/Bird, Small/Medium/Large).

### Instructions
Let's do another quick refresher here. Your job is to pick the **binary** classification problem out of the following list of supervised learning problems.

### Possible Answers
* **Predicting whether a given image contains a cat.** (Correct Answer)
* Predicting the emotional valence of a sentence (Valence can be positive, negative, or neutral).
* Recommending the most tax-efficient strategy for tax filing in an automated accounting system.
* Given a list of symptoms, generating a rank-ordered list of most likely diseases.

### Solution
The correct answer is predicting whether a given image contains a cat. This is binary because there are exactly two options: Yes (it has a cat) or No (it does not).

*(Note: Emotional valence has 3 options so it is multi-class. Tax strategy is a recommendation engine, and generating a rank-ordered list is a ranking engine!)*
