# Exercise

## Which of these is a classification problem?

### Concept: Identifying the Task
Before you can build an XGBoost model, you have to know what kind of problem you are actually trying to solve! 

Remember the rules:
* **Regression:** Predicting a continuous number (e.g., Price, Temperature, Height).
* **Classification:** Predicting a category (e.g., Yes/No, Cat/Dog/Bird).
* **Clustering:** Grouping things together *without* knowing the answer in advance (Unsupervised).
* **Recommendation:** Suggesting items based on past history.

### Instructions
Given below are 4 potential machine learning problems you might encounter in the wild. Pick the one that is a classification problem.

### Possible Answers
* Given past performance of stocks and various other financial data, predicting the exact price of a given stock (Google) tomorrow.
* Given a large dataset of user behaviors on a website, generating an informative segmentation of the users based on their behaviors.
* **Predicting whether a given user will click on an ad given the ad content and metadata associated with the user.** (Correct Answer)
* Given a user's past behavior on a video platform, presenting him/her with a series of recommended videos to watch next.

### Solution
The correct answer is predicting whether a given user will click on an ad. The answer is a category (Yes they clicked, or No they didn't). 

*(Note: Predicting exact price is Regression, segmenting users is Clustering, and presenting videos is Recommendation!)*
