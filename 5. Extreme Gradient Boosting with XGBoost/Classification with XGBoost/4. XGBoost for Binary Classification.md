# 1. Introduction

XGBoost (Extreme Gradient Boosting) is one of the most powerful supervised learning algorithms.

Unlike a normal Decision Tree, XGBoost builds many small trees sequentially.

Each new tree learns from the mistakes (errors) of all previous trees.

For classification, the target is

```
0 or 1
```

Instead of predicting the class directly, XGBoost predicts the **probability** of belonging to class 1.

# 5. Why Log Odds?

Instead of storing probability,

XGBoost stores

```
Log Odds
```

Odds

$$ Odds = \frac{P}{1-P} $$

Example

$$ P = 0.6 $$

Odds

$$ \frac{0.6}{0.4} = 1.5 $$

Now

take logarithm.

$$ LogOdds = \log(1.5) = 0.405 $$

This becomes

Model 1 Prediction.

Notice

```
0.405 is NOT a probability.
```

It is simply an internal score.

---

# 6. Convert Log Odds to Probability

XGBoost uses

Sigmoid Function

$$ P = \frac{e^{LogOdds}}{1+e^{LogOdds}} $$

Substitute

$$ LogOdds = 0.405 $$

$$ P = \frac{e^{0.405}}{1+e^{0.405}} = 0.60 $$

So

```
Log Odds

↓

Sigmoid

↓

Probability
```

# 10. Similarity Score

Unlike regression,

classification uses

$$ SS = \frac{(\sum residual)^2}{\sum p(1-p)+\lambda} $$

where

```
Residual = Actual - Prediction
```

and

```

```

# 14. Learning Rate

XGBoost never applies the whole correction.

Instead

$$ NewPrediction = OldPrediction + \eta \times TreeOutput $$

where

```

```

Example

```

```

# 19. Final Prediction Formula

Final Model

$$ F(x) = F_0(x) + \eta T_1(x) + \eta T_2(x) + ... + \eta T_n(x) $$

where

```
F0 = Initial Log Odds

T1, T2... = Decision Trees
```

Probability

$$ P = \frac{e^{F(x)}}{1+e^{F(x)}} $$

Prediction

```
P > 0.5

↓

Class = 1

Else

Class = 0
```

# 20. Regression vs Classification

|Regression|Classification|
|------------|---------------|
|Initial Prediction = Mean|Initial Prediction = Log Odds|
|Residual = Actual - Prediction|Pseudo Residual = Actual - Probability|
|Output = Number|Output = Probability|
|Loss = MSE|Loss = Log Loss|
|Leaf = Average Residual|Leaf = Newton Update|
|Similarity = (Σr)²/(n+λ)|Similarity = (Σr)²/(Σp(1-p)+λ)|

# 22. Important Formulas

## Odds

$$ Odds = \frac{P}{1-P} $$

---

## Log Odds

$$ LogOdds = \log \left( \frac{P}{1-P} \right) $$

---

## Sigmoid

$$ P = \frac{e^x}{1+e^x} $$

---

## Pseudo Residual

$$ Residual = Actual - Probability $$

---

## Similarity Score

$$ SS = \frac{(\sum residual)^2}{\sum p(1-p)+\lambda} $$

---

## Gain

$$ Gain = SS_L + SS_R - SS_P $$

---

## Leaf Output

$$ Leaf = \frac{\sum residual}{\sum p(1-p)+\lambda} $$

---

## Model Update

$$ Prediction_{new} = Prediction_{old} + \eta \times TreeOutput $$

---

## Final Probability

$$ P = \frac{e^{Prediction}}{1+e^{Prediction}} $$

# 23. Interview Questions

### Why use Log Odds instead of Probability?

Because probabilities are restricted to [0,1], while log-odds can take any real value, making optimization easier.

---

### Why use Sigmoid?

To convert unrestricted log-odds into valid probabilities between 0 and 1.

---

### What are Pseudo Residuals?

The difference between the actual class label and the predicted probability:

$$ Residual = y - p $$

---

### Why does XGBoost Classification use \(p(1-p)\)?

Because it represents the second derivative (Hessian) of the logistic loss and measures the uncertainty of each prediction. It is used in the Newton update for faster optimization.

---

### Why use Learning Rate?

The learning rate prevents the model from making overly large corrections in a single step, reducing overfitting and improving generalization.

---
