# Exercise

## Using XGBoost

### Concept: Identifying the Sweet Spot
XGBoost is a powerful library that scales very well to many samples and works for a variety of supervised learning problems. That said, as you learned in the previous notes, you shouldn't always pick it as your default machine learning library when starting a new project, since there are some situations in which it is not the best option. 

In this exercise, your job is to consider the below examples and select the one which would be the best use of XGBoost.

### Possible Answers

1. Visualizing the similarity between stocks by comparing the time series of their historical prices relative to each other.
2. Predicting whether a person will develop cancer using genetic data with millions of genes, 23 examples of genomes of people that didn't develop cancer, 3 genomes of people who wound up getting cancer.
3. Clustering documents into topics based on the terms used in them.
4. Predicting the likelihood that a given user will click an ad from a very large clickstream log with millions of users and their web interactions.

---

### Solution

**Correct Answer:** 4

**Explanation:**
* **Option 1 (Incorrect):** This is an unsupervised learning/visualization task (time series similarity), not a supervised learning task.
* **Option 2 (Incorrect):** This is the "Danger Zone". You have a tiny dataset (`n = 26`) and extreme high dimensionality (`p = millions`). XGBoost will severely overfit this dataset.
* **Option 3 (Incorrect):** This is an unsupervised learning task (clustering) working with unstructured data (text documents).
* **Option 4 (Correct):** This is the exact "Sweet Spot" for XGBoost! It is a supervised classification problem predicting a probability, with a massive dataset (millions of rows) of structured tabular data (web interactions), where the number of rows is far greater than the number of features.
