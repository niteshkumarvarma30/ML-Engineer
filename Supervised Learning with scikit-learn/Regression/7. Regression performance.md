## Regression performance

Now you have fit a model, `reg`, using all features from `sales_df`, and made predictions of sales values, you can evaluate performance using some common regression metrics.

The variables `X_train`, `X_test`, `y_train`, `y_test`, and `y_pred`, along with the fitted model, `reg`, all from the last exercise, have been preloaded for you.

Your task is to find out how well the features can explain the variance in the target values, along with assessing the model's ability to make predictions on unseen data.

* Calculate the model's R-squared score by passing the test feature values and the test target values to an appropriate method.
* Calculate the model's root mean squared error using `y_test` and `y_pred`.
* Print `r_squared` and `rmse`.

### Solution

Here is the completed code for evaluating your regression model.

```python
# Import root_mean_squared_error
from sklearn.metrics import root_mean_squared_error

# Compute R-squared
r_squared = reg.score(X_test, y_test)

# Compute RMSE
rmse = root_mean_squared_error(y_test, y_pred)

# Print the metrics
print("R^2: {}".format(r_squared))
print("RMSE: {}".format(rmse))
```

### Explanation of the Filled Blanks:

**1. Importing the Metric:**
* `from sklearn.metrics import root_mean_squared_error`: All evaluation metrics for testing how well your models perform are stored in the `sklearn.metrics` module.

**2. Computing R-squared:**
* `reg.score(X_test, y_test)`: Linear regression models in scikit-learn have a built-in method called `.score()` that automatically calculates the $R^2$ value. You must pass it the unseen features (`X_test`) and the actual unseen answers (`y_test`) so it can make predictions and grade itself.

**3. Computing RMSE (Root Mean Squared Error):**
* `root_mean_squared_error(y_test, y_pred)`: Unlike the `.score()` method, metric functions usually require you to directly compare the actual answers (`y_test`) against the predicted answers (`y_pred`) that you generated in the previous step.

> [!NOTE]
> RMSE measures the average error of your predictions in the exact same units as your target variable. If you are predicting sales in dollars, an RMSE of 15 means your predictions are off by an average of $15.

**4. Printing the Metrics:**
* We just pass our newly created variables (`r_squared` and `rmse`) into the `.format()` method to inject them into the print statements!

### Why do we pass `y_pred` to `root_mean_squared_error`, but not to `reg.score()`?

That is a great question! It all comes down to who is doing the math.

The difference happens because `reg.score()` is a method built directly into your model, while `root_mean_squared_error()` is just a standalone math formula.

Here is exactly what is happening under the hood:

**1. `reg.score(X_test, y_test)` is a 2-in-1 shortcut**
Because `.score()` is attached to your model (`reg`), it still remembers all its training. When you pass it the features (`X_test`), it actually does two things automatically:
1. It silently runs `.predict(X_test)` behind the scenes to generate its own `y_pred`.
2. It immediately compares its hidden `y_pred` against the `y_test` you provided to calculate the R-squared score.

Because it calculates the predictions itself, you don't need to pass `y_pred` to it.

**2. `root_mean_squared_error(y_test, y_pred)` is "blind"**
This function comes from the `sklearn.metrics` module. It is just a standalone mathematical formula.

It does not know what your `reg` model is, and it doesn't know how to look at `X_test` features to make predictions. All it knows how to do is compare two lists of numbers. Because it cannot generate predictions on its own, you must hand it the `y_pred` list that you generated manually earlier.

#### The Alternate Way (Using `y_pred` for R-squared)
If you wanted to, you could calculate R-squared the exact same way as RMSE. Scikit-learn has a standalone metric function for it called `r2_score`.

If you used that standalone function instead of the model's shortcut, you would pass `y_pred` to it, like this:

```python
from sklearn.metrics import r2_score

# Now they both look exactly the same!
r_squared = r2_score(y_test, y_pred)
rmse = root_mean_squared_error(y_test, y_pred)
```
