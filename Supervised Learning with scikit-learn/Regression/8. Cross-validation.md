# 8. Cross-validation

Cross-validation is a technique used to evaluate a machine learning model's performance much more reliably than using a single `train_test_split`.

To understand why we need it, we first have to look at the main weakness of the standard `train_test_split`.

### The Problem with a Single Train/Test Split
When you split your data into an 80% training set and a 20% testing set, the split is usually random. Because it's random, you might get "lucky" or "unlucky."

* **Lucky:** All the easy-to-predict data ends up in your test set. Your model scores an $R^2$ of 95%, making you think it's a genius.
* **Unlucky:** All the weird, outlier data ends up in your test set. Your model scores an $R^2$ of 40%, making you think it's terrible.

In reality, your model's true performance is highly dependent on which specific rows of data ended up in that 20% testing pile.

### The Solution: Cross-Validation (k-fold)
Cross-validation solves this by ensuring that every single row of data gets to be in the test set exactly once. The most common version of this is called **k-fold cross-validation** (where "k" is just the number of splits, usually 5). Here is how 5-fold cross-validation works:

You take your entire dataset and divide it into 5 equal chunks (called "folds").

* **Split 1:** You hide Chunk 1 to use as your Test Set. You train the model on Chunks 2, 3, 4, and 5. You calculate your metric (like $R^2$).
* **Split 2:** You hide Chunk 2 to use as your Test Set. You train the model on Chunks 1, 3, 4, and 5. You calculate your metric.
* You repeat this process 5 times, so every single chunk gets a turn being the Test Set.

#### Visualization of 5-Fold Cross-Validation

| Iteration | Fold 1 | Fold 2 | Fold 3 | Fold 4 | Fold 5 | Result |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **Split 1** | **Test Data** | Train Data | Train Data | Train Data | Train Data | Metric 1 |
| **Split 2** | Train Data | **Test Data** | Train Data | Train Data | Train Data | Metric 2 |
| **Split 3** | Train Data | Train Data | **Test Data** | Train Data | Train Data | Metric 3 |
| **Split 4** | Train Data | Train Data | Train Data | **Test Data** | Train Data | Metric 4 |
| **Split 5** | Train Data | Train Data | Train Data | Train Data | **Test Data** | Metric 5 |

### The Result
At the end of the process, instead of having just one $R^2$ score, you have five different $R^2$ scores.

You then calculate the average (mean) of those 5 scores. This average score gives you a much more trustworthy, confident measure of how your model will actually perform in the real world on truly unseen data.

---

## Cross-validation in scikit-learn

In scikit-learn, this is extremely easy to do using the `cross_val_score` function:

```python
from sklearn.model_selection import cross_val_score

# This automatically splits, trains, and tests the data 5 times!
cv_scores = cross_val_score(reg, X, y, cv=5)

print(cv_scores) 
# Output: [0.75, 0.72, 0.78, 0.74, 0.76]

print(cv_scores.mean()) 
# Output: 0.75
```

### Advanced Cross-validation using `KFold`
Sometimes you want more control over exactly how the data is split. For example, you might want to shuffle the dataset before breaking it into folds, and set a `random_state` so the shuffle is perfectly reproducible.

We can do this using the `KFold` object. Let's do a 6-fold cross-validation:

```python
from sklearn.model_selection import cross_val_score, KFold
from sklearn.linear_model import LinearRegression

# Setup KFold (n_splits=6, shuffle=True to mix data, random_state for reproducibility)
kf = KFold(n_splits=6, shuffle=True, random_state=42)

# Instantiate model
reg = LinearRegression()

# Compute cross-validation scores using our kf object
cv_results = cross_val_score(reg, X, y, cv=kf)
```

### Evaluating cross-validation performance
Once you have your array of scores, you can use `numpy` to compute useful statistics like the mean, standard deviation, and a 95% confidence interval.

```python
import numpy as np

# Print the array of 6 scores
print(cv_results)
# Output: [0.70262578, 0.7659624, 0.75188205, 0.76914482, 0.72551151, 0.73608277]

# Calculate Mean and Standard Deviation
print(np.mean(cv_results), np.std(cv_results))
# Output: 0.7418682216666667 0.023330243960652888

# Calculate 95% Confidence Interval
print(np.quantile(cv_results, [0.025, 0.975]))
# Output: [0.7054865, 0.76874702]
```
