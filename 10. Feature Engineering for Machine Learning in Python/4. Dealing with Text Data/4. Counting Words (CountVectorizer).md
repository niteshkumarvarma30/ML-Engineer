# Counting Words (CountVectorizer)

We know that machine learning models only understand math. If we want a computer to read a President's inaugural address, we have to translate the text into numbers.

The easiest and most common way to do this is called Bag of Words (or Word Counting).

## 1. The "Text to Columns" Concept

Look at your first screenshot (image_0e5f36.png). It perfectly illustrates how we turn a sentence into a math grid.

**The Sentence:**
"The objective of the course is to introduce the students to the concepts of machine learning."

**The Translation:**
We take every single unique word in that sentence and make it its own column. Then, we simply tally up how many times each word was used!

*   of: 3
*   the: 3
*   to: 2
*   machine: 1

Instead of reading the English sentence, the computer now just reads a row of numbers: `[1, 3, 3, 1, 1, 2, 1, 1, 1, 1, 1]`.

**How the Numbers Line Up:**
That entire array of numbers represents exactly one single row in our new mathematical spreadsheet.

Here is how the grid is organized:
*   Every Row represents one specific document or sentence (e.g., Row 1 is Sentence 1, Row 2 is Sentence 2).
*   Every Column represents a unique word from the dictionary, usually sorted in alphabetical order.

For the sentence we analyzed ("The objective of the course..."), it becomes Row 1. The computer fills in the numbers across the columns like this:

| Row (Sentence) | concepts | course | introduce | is | learning | machine | objective | of | students | the | to |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| Row 1 | 1 | 1 | 1 | 1 | 1 | 1 | 1 | 3 | 1 | 3 | 2 |

If we fed the computer a brand new second sentence, like "The machine is learning", it would become Row 2. The computer would put a `1` under the columns for the words that were used, and a `0` under the columns for the words that were missing!

## 2. Scikit-Learn's Automatic Counter

You don't have to write a custom loop to count millions of words. Scikit-Learn has a built-in tool for this called `CountVectorizer`.

**The "Too Many Words" Problem**

If you analyze 50 different speeches, your dictionary of unique words might grow to 10,000 words. That means your spreadsheet will have 10,000 columns! That is way too much data for a model to process efficiently.

**The Fix: `min_df` and `max_df`**

Look at your Specifying the vectorizer screenshot (image_0e6277.png). We can pass rules into the `CountVectorizer` to filter out useless words!

```python
from sklearn.feature_extraction.text import CountVectorizer

# min_df=0.1 means: "If a word doesn't appear in at least 10% of the speeches, delete it. It's too rare to be useful."
# max_df=0.9 means: "If a word appears in more than 90% of the speeches, delete it. It's too common (like 'the' or 'and') to be a unique clue."
cv = CountVectorizer(min_df=0.1, max_df=0.9)
```

## 3. The 3-Step Process

Here is the exact code workflow shown in your screenshots to process the text!

### Step A: Fit and Transform

*(See images 0e62d5, 0e62f7, and 0e6602)*
You can do the 2-step process (`.fit()` then `.transform()`), but the pro-shortcut is to do it all at once using `.fit_transform()`.

```python
# The tool memorizes the vocabulary and counts the words all at once!
cv_transformed = cv.fit_transform(speech_df['text_clean'])
```

**The Sparse Matrix Catch:** If you look at the output in the screenshot, it doesn't look like a normal array. It says `<58x8221 sparse matrix>`.
Because 99% of the word counts for any given speech will be 0, Python compresses the grid to save memory. To turn it back into a normal grid of numbers, you must use `.toarray()`.

```python
cv_array = cv_transformed.toarray()
```

### Step B: Get the Feature Names

*(See image 0e65c2)*
Right now, `cv_array` is just a giant grid of numbers. We don't know which column belongs to which word! We extract the column headers using `.get_feature_names()`.

```python
# Returns a list like: ['aback', 'abandon', 'abandonment', ...]
word_headers = cv.get_feature_names()
```

### Step C: Glue it back to Pandas

*(See images 0e663b and 0e6678)*
Finally, we want to put this beautiful new math into a Pandas DataFrame so we can use it!

```python
import pandas as pd

# 1. Create a new DataFrame using our numbers and our word headers
# We use .add_prefix() so the columns look like "Counts_abandon" instead of just "abandon"
cv_df = pd.DataFrame(cv_array, columns=word_headers).add_prefix('Counts_')

# 2. Glue the new math columns onto our original spreadsheet side-by-side! (axis=1)
speech_df_new = pd.concat([speech_df, cv_df], axis=1, sort=False)
```

**The Final Result:** Your dataset now has thousands of brand new columns (like `Counts_aback`, `Counts_abandon`), filled perfectly with the number of times that exact word appeared in that specific row's speech!
