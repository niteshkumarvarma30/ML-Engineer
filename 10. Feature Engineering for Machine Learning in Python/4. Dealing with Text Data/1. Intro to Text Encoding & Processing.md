# Intro to Text Encoding & Processing

Up until now, our data has always been neatly organized into columns (like "Age" or "Salary").

But what if you are analyzing a massive dataset of President's speeches, customer reviews, or emails? This is called Unstructured Data. Machine learning models only understand math. They cannot read English. Before we can feed text to a model, we must clean it and translate it into numbers.

Here are the very first steps to cleaning up messy text data using Pandas!

## 1. Removing the "Garbage" (Punctuation and Symbols)

Look at your first screenshot of George Washington's speech. It has commas, hyphens (-), and colons (:).

To a computer, "Apple" and "Apple," (with a comma) are two completely different words! We have to strip out all the punctuation so we are left with just the pure letters.

**The Fix: Regular Expressions (Regex)**
Instead of writing 50 lines of code to manually delete every single comma, period, and question mark, we use a search pattern called Regex.

Look at the code in your Removing unwanted characters screenshot:

```python
# The pattern '[^a-zA-Z]' acts like a strict bouncer at a club.
# [a-zA-Z] means "The VIP list is every lowercase and uppercase letter."
# The caret (^) means "NOT". 
# So the bouncer says: "If you are NOT a letter, you get replaced by a blank space!"

speech_df['text'] = speech_df['text'].str.replace('[^a-zA-Z]', ' ')
```

*Note: Whenever you want Pandas to do text-editing on a whole column, you have to use the special `.str` tool first!*

## 2. The "Capitalization" Problem

Now our text is just pure letters. But we have another problem: To a computer, the word "Data" and the word "data" are completely different words just because of the capital "D".

**The Fix: Lowercasing**
Look at the Standardize the case screenshot. We force every single letter in the entire dataset to become lowercase.

```python
# Instantly translates everything to lower case!
speech_df['text'] = speech_df['text'].str.lower()
```

Now, "Data" and "data" both become "data". The computer won't get confused and double-count them!

## 3. Extracting Basic Features (Math Clues!)

Before we do heavy text-to-number translation, we can actually extract some really helpful math clues directly from the structure of the text!

### A. Character Count

How long is the speech? We can count every single letter and space using `.len()`.

```python
speech_df['char_cnt'] = speech_df['text'].str.len()
```

### B. Word Count

How many words did the President use?
First, we use `.split()` to chop the giant paragraph into a list of individual words (it naturally chops them wherever there is a space). Then, we use `.len()` to count how many words ended up in that list!

```python
# Chop it into words, then count the words!
speech_df['word_cnt'] = speech_df['text'].str.split().str.len()
```

### C. Average Word Length

If a President uses massive, complicated words, their "Average Word Length" will be high. If they use simple words, it will be low.

Because we already calculated the total characters and total words above, we can just do basic math!

```python
# Total characters divided by total words = Average word length!
speech_df['avg_word_length'] = speech_df['char_cnt'] / speech_df['word_cnt']
```

By doing this, you just took a giant, messy paragraph of text and engineered three brand new, clean mathematical columns (`char_cnt`, `word_cnt`, and `avg_word_length`) that a machine learning model can easily learn from!
