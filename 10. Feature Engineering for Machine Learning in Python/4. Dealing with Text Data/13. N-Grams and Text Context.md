# N-Grams and Text Context

So far, we have been using the Bag-of-Words model (like `CountVectorizer` or `TfidfVectorizer`).

Think of this literally as a giant bag. You take a sentence, chop it up into individual words, and dump all those words into a bag. You shake the bag up, and pull the words out one by one to count them.

## 1. The Problem: Losing the Context

When you shake the bag, you completely destroy the order of the words.

Imagine a customer writes a review: *"I was never not happy with the service!"*

If you use a standard Bag-of-Words, the computer chops this up into single words: `["I", "was", "never", "not", "happy", "with", "the", "service"]`.

**The Flaw:** The computer sees the word "happy" and gives it a point. The model might falsely assume this is a positive review, completely missing the fact that the words "not" and "never" were right next to it!

## 2. The Solution: N-Grams

To fix this, we force the computer to group consecutive words together instead of chopping them all up individually. We call these groups **N-Grams**.

*   **Unigram (1-gram):** Single words. (e.g., "happy", "not")
*   **Bi-gram (2-gram):** Pairs of words. (e.g., "not happy")
*   **Tri-gram (3-gram):** Three words. (e.g., "never not happy")

By creating columns for Bi-grams instead of Unigrams, your model learns that "not happy" is one single concept, perfectly preserving the context!

## 3. How to use N-Grams in Scikit-Learn

Look at your Using N-grams screenshot. Scikit-learn makes this incredibly easy. You don't need a new tool; you just add the `ngram_range` argument to your normal Vectorizer!

The range takes two numbers: `(minimum_length, maximum_length)`.

```python
from sklearn.feature_extraction.text import CountVectorizer

# ngram_range=(2, 2) means: "Only give me pairs of words (Bi-grams). No single words!"
# ngram_range=(1, 2) would mean: "Give me single words AND pairs of words!"
cv = CountVectorizer(ngram_range=(2, 2))

# Fit and transform the text
cv_array = cv.fit_transform(speech_df['text_clean']).toarray()

# Now the feature names are pairs! (e.g., 'abide thy', 'ability and')
```

## 4. The Sanity Check (Finding Common Words)

Whenever you generate new text features, you should do a quick sanity check to make sure the computer isn't extracting garbage. A great way to do this is to add up the columns and find the most popular N-grams!

Look at the code in your Finding common words screenshots:

```python
import pandas as pd

# 1. Put the math array into a DataFrame, using the Bi-gram pairs as column names
cv_df = pd.DataFrame(cv_array, columns=cv.get_feature_names()).add_prefix('Counts_')

# 2. Add up all the columns vertically to get a total count for every single phrase!
tv_bi_counts = cv_df.sum()

# 3. Sort them from highest to lowest and print the top 5
print(tv_bi_counts.sort_values(ascending=False).head())
```

Because these phrases make logical sense, we can confidently pass this data into a machine learning model!
