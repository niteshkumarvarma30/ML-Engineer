# Scaling and Transforming New Data

You have cleaned your data, removed the outliers, scaled the numbers, and trained a beautiful machine learning model.

But what happens when you want to use that model in the real world on a brand new dataset (or on your hidden Test Set)?

The Golden Rule: You must apply the exact same transformations to the new data that you applied to the training data. Here is how you do it safely!

## 1. Reusing Training Scalers (No Peeking!)

Look at your Reuse training scalers screenshot.

If you used a StandardScaler to shrink your training data, you must also shrink your test data before the model can read it. But there is a massive trap here!

**The Trap:** If you let the scaler calculate a new average using the Test Data, you are committing Data Leakage. You are letting your model peek into the future to adjust its math. Your accuracy scores will be fake and overly optimistic.

**The Fix:** The scaler is only allowed to memorize (`.fit()`) the Training Data. You then force the Test Data to use those exact same memorized rules using only `.transform()`.

**The Python Code:**

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

# 1. FIT (Memorize the rules) ONLY on the training data!
scaler.fit(X_train)

# 2. TRANSFORM the training data
X_train_scaled = scaler.transform(X_train)

# 3. ONLY TRANSFORM the test data (Do NOT fit it!)
X_test_scaled = scaler.transform(X_test)
```

## 2. Reusing Outlier Thresholds

Look at your Training transformations for reuse screenshot.

Let's say you decided to delete extreme outliers from your dataset using the 3-Sigma Rule (3 Standard Deviations from the Mean).

Just like the scaler, you are not allowed to calculate the mean and standard deviation of the Test Set. You must calculate the "safe boundaries" using the Training Set, and then apply those exact same boundaries to the Test Set!

**The Python Code:**

```python
# 1. Calculate the math using ONLY the Training Data
train_mean = X_train.mean()
train_std = X_train.std()

# 2. Calculate the safe boundaries based on the training math
cut_off = train_std * 3
lower = train_mean - cut_off
upper = train_mean + cut_off

# 3. Apply those exact boundaries to the Test Data!
# (Only keep test rows that fall safely inside the training boundaries)
test_no_outliers = X_test[(X_test < upper) & (X_test > lower)]
```

*(Note: As the instructor mentions, deleting rows from your Test Set is actually very rare in the real world, because you usually can't just "delete" a real-world customer who is an outlier! But if you absolutely must, this is the mathematically safe way to do it).*

## 3. The Ultimate "Why": Avoiding Data Leakage

Why are we so incredibly strict about only learning rules from the Training Data?

Because in the real world, the Test Data represents the future.
When you deploy your machine learning model to a live website, you don't have access to tomorrow's data today. You cannot calculate the average salary of users who haven't even visited your website yet!

By strictly calibrating all of your preprocessing tools (Scalers, Imputers, Outlier detectors) on the Training Data only, you perfectly mimic how the real world works. This guarantees that your model's accuracy score is honest, robust, and completely free of Data Leakage!

### Deep Dive: Why transform instead of fit on Test Data?

Think of `fit()` as "calculating and memorizing the rules." If you use a Scaler and call `.fit(X_test)`, the computer calculates the average of the test data. This is cheating! In the real world, the test data represents the future (e.g., customers who haven't visited your website yet). You can't calculate the average of something that hasn't happened yet. If you do this, your model's accuracy scores will be fake.

Think of `transform()` as "applying the memorized rules." When we call `.transform(X_test)`, the computer says, "I'm going to scale this new test data using the exact averages I already memorized from the Training set." This perfectly simulates the real world, where your model relies entirely on past knowledge to handle new data.

### Deep Dive: How the Outlier Code Works

The code snippet you selected does the exact same "Fit/Transform" concept, just manually without a built-in Scikit-Learn tool:

```python
test_no_outliers = X_test[(X_test < upper) & (X_test > lower)]
```

*   **The "Fit" (Happened earlier):** The upper and lower boundary numbers were calculated using the Training Data's mean and standard deviation.
*   **The "Transform" (This line of code):** We are actively applying those training boundaries to the new test data. 

Here is how the Pandas math works step-by-step:
1.  `(X_test < upper)` asks a True/False question for every row: Is this value safely below the ceiling?
2.  `(X_test > lower)` asks a True/False question for every row: Is this value safely above the floor?
3.  The `&` symbol forces both to be true. It creates a master VIP list (a Boolean Mask) of True and False values. A row only gets a True if it sits perfectly between the two boundaries.
4.  Finally, `X_test[...]` applies the mask. It deletes every row that got a False, leaving you with a perfectly clean test set that was filtered using the training rules!
