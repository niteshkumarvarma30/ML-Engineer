# Finding Missing Data

In a perfect world, every spreadsheet you download would be 100% complete. In reality, data is incredibly messy and full of blanks.

Before you can build a machine learning model, you have to become a detective and hunt down these missing values!

## 1. Why is Data Missing?

Look at your first screenshot. Missing data (often represented in Python as NaN or "Not a Number") happens for several very human reasons:

*   **Collection Errors:** Someone filling out a paper survey forgot to flip the page and missed a question.
*   **Management/Typo Errors:** The person typing the paper survey into the computer accidentally skipped a line.
*   **Intentional Omissions:** A user filling out an online form felt uncomfortable sharing their Age or Salary, so they intentionally left the box blank.

## 2. Why do we care?

Why can't we just ignore the blank cells?

*   **Calculators break on blanks:** Machine learning algorithms (like Linear Regression) are just giant math equations. If you try to multiply `5 * [Blank]`, the computer panics and the model crashes. It requires a value for every single row and column.
*   **Blanks are clues:** Sometimes, missing data is actually a secret piece of information. For example, if a column asks "How many children do you have?" and it is blank, it might just be the person's way of saying they have 0 children!

## 3. How to Hunt for Missing Data (The Pandas Tools)

Pandas provides us with three amazing tools to investigate our datasets and find exactly where the holes are.

### Tool 1: The Bird's-Eye View (`.info()`)

*(See your Missing value discovery screenshot)*

When you first load a dataset, you should always run `df.info()`.
It prints out a list of all your columns and tells you exactly how many "Non-Null" (not blank) values exist in each one.

If your dataset has 1,000 rows, but the Gender column says it only has 693 non-null values, you instantly know that about 300 people left that question blank!

### Tool 2: The Exact Count (`.isnull().sum()`)

*(See your Finding missing values screenshot)*

If you want an exact count of the missing blank spaces, you chain two methods together:

```python
# 1. .isnull() asks a True/False question for every single cell: "Are you blank?"
# 2. .sum() adds up all the "True" answers!
missing_counts = df.isnull().sum()
print(missing_counts)
```

**The Result:** This gives you a perfectly clean list showing exactly how many blanks exist in every single column.

### Tool 3: The Opposite Search (`.notnull()`)

*(See your Finding non-missing values screenshot)*

Sometimes, you only want to look at the rows that actually have data. You can use the exact opposite tool: `.notnull()`.

It asks: "Do you actually have a value here?" If the cell has data, it returns True. If it is blank, it returns False. You can use this as a mask to filter your dataset and only look at the complete, healthy rows!
