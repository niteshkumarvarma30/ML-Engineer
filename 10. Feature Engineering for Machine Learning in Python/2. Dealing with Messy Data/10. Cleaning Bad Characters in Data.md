# Cleaning "Bad Characters" in Data

In our previous lessons, we learned that Machine Learning models are just giant calculators. If you hand them a word (a text string), they will crash.

But what happens when you have a column for Salary, and it looks like this: `$100,000`?

## 1. The Disguise (Why Numbers Become "Objects")

To a human, `$100,000` is obviously a number.
To a computer, the dollar sign (`$`) and the comma (`,`) are letters/symbols.

Because of those symbols, Pandas gets confused. When you load the data, Pandas slaps an `object` (text) data type on the entire column instead of an `int` or `float`. If you try to run `.mean()` or feed it to a model, it will break.

*(See the Bad characters screenshots)*

```python
print(df['RawSalary'].head())
```

If we check the data type directly:

```python
print(df['RawSalary'].dtype)
```

**Output:**
```
dtype('O')
```
*(Note: 'O' stands for Object/String!)*

## 2. The Fix: String Replacement (`str.replace`)

Look at your *Dealing with bad characters* screenshot. Because Pandas currently thinks the column is a string of text, we can use text-editing tools on it!

We use the `.str.replace()` method. It finds a specific symbol and replaces it with whatever we want. In this case, we want to replace the comma with absolutely nothing (an empty string `''`).

```python
# Tell Pandas to look at the strings, find the commas, and delete them!
df['RawSalary'] = df['RawSalary'].str.replace(',', '')

# Now that the commas are gone, we can safely force it to become a math number!
df['RawSalary'] = df['RawSalary'].astype('float')
```

## 3. The "Bouncer" Method (`to_numeric(errors='coerce')`)

What if you run the code above, but it still crashes? That means there is another weird symbol hiding somewhere in your 10,000 rows of data (like a `£` or a `?`).

Instead of reading 10,000 rows with your own eyes to find the weird symbol, you can use Pandas to hunt it down!

Look at the *Finding other stray characters* screenshots. We use the `pd.to_numeric()` function with a special rule: `errors='coerce'`.

**How it works:** It acts like a bouncer at a club. It grabs every single cell and tries to turn it into a number. If it finds a cell with a weird symbol that it can't figure out, instead of crashing the whole program, it just throws the cell in the trash and replaces it with a blank `NaN`.

```python
# Try to force everything into a number. Turn unreadable garbage into NaNs!
coerced_vals = pd.to_numeric(df['RawSalary'], errors='coerce')

# Now, show me only the rows that got turned into NaNs!
print(df[coerced_vals.isna()].head())
```

**Output:**
```
0           NaN
2           NaN
4     $51408.00
Name: RawSalary, dtype: object
```

**The Reveal:** By looking at the rows that failed, you instantly see the culprit! Ah, there are dollar signs (`$`) hidden in the data!

## 4. The Pro Shortcut: Method Chaining

Look at your final screenshot (*Chaining methods*).

```python
# Instead of this:
df['column_name'] = df['column_name'].method1()
df['column_name'] = df['column_name'].method2()
df['column_name'] = df['column_name'].method3()

# You can do the same as:
df['column_name'] = df['column_name']\
    .method1().method2().method3()
```

Now we know we have to delete commas, delete dollar signs, AND convert the column to a float. Instead of writing three separate lines of code, we can "chain" them all together in one fluid motion!

```python
# Look how clean and readable this is! 
# It reads left-to-right: Replace commas, THEN replace dollar signs, THEN turn into a float.
df['RawSalary'] = df['RawSalary'].str.replace(',', '').str.replace('$', '').astype('float')
```

By chaining methods, you make your code incredibly fast, efficient, and easy for other Data Scientists to read!
