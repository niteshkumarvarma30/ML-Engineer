# Filling Continuous Missing Data

In our last lesson, we learned that the easiest way to deal with missing data (NaN) is to just delete the row entirely using `.dropna()`.

However, in the real world, deleting data is often not an option. Here is why, and how we use math to fill in the blanks instead!

## 1. Why is Deleting Data Dangerous?

Look at your first screenshot (Deleting missing values).

Imagine you build a machine learning model to predict if a customer will buy a product. You train the model on a perfectly clean dataset where you deleted anyone missing their Age.

**The Real-World Problem:**
Tomorrow, a brand new customer visits your website. They want to buy something, but they leave the Age box blank.
If your model was trained by simply deleting missing rows, it will completely freeze and crash when it sees this new customer. You cannot just "delete" a real-world customer from existence! You must have a strategy to guess their missing information.

*(See the What else can you do? screenshot)*
*   **Categorical columns:** Replace missing values with the most common occurring value or with a string that flags missing values such as 'None'
*   **Numeric columns:** Replace missing values with a suitable value

## 2. The Solution: Measures of Central Tendency

If a column contains continuous numbers (like Salary, Age, or Temperature), what is the safest number to guess for a blank cell?

*(See the Measures of central tendency screenshot)*
The safest guess is the "typical" value of the group. We use Measures of Central Tendency:

*   **The Mean:** The mathematical average.
*   **The Median:** The exact middle number if you lined everyone up in order. (This is usually safer if there are crazy billionaires skewing the average!)

**The Caveat:** As the slide points out, filling in 50 blanks with the exact same "Average" number will mathematically shrink the Variance (spread) of your dataset. It makes your data look more uniform than it actually is, but it is a necessary trade-off!

## 3. Calculating the Average in Pandas

*(See the Calculating the measures of central tendency screenshot)*

Pandas makes finding the average incredibly easy. Even better, Pandas is smart enough to completely ignore the NaN blank spaces when doing the math, so it doesn't crash!

```python
print(df['ConvertedSalary'].mean())
print(df['ConvertedSalary'].median())
```

**Output:**
```
92565.16992481203
55562.0
```

You can save these values to variables to use them:

```python
# Calculate the average (Mean)
mean_value = so_train_numeric['ConvertedSalary'].mean()

# Or calculate the middle (Median)
median_value = so_train_numeric['ConvertedSalary'].median()
```

## 4. Filling the Blanks (And the Decimal Problem)

Now we just use the trusty `.fillna()` tool to pour our calculated average into the blank cells.

But there is a catch! *(Look at the Fill the missing values screenshot)*
If you average a bunch of whole numbers, the result is almost always a long decimal (e.g., 32.4563). If the column is supposed to be a whole number (like a person's Age), a decimal doesn't make sense!

You have two ways to fix this:

### Fix A: Convert to Integer Afterward

You can fill the blanks, and then use `.astype('int64')` to force the entire column to chop off the decimals and become whole numbers again.

```python
# 1. Fill the blanks with the exact decimal average
df['ConvertedSalary'] = df['ConvertedSalary'].fillna(
    df['ConvertedSalary'].mean()
)

# 2. Force the whole column back to integers!
df['ConvertedSalary'] = df['ConvertedSalary']\
    .astype('int64')
```

### Fix B: Round the Number First

*(See your final Rounding values screenshot)*

Instead of fixing it afterward, you can just use the `round()` function to round the average into a whole number before you pour it into the blanks!

```python
# 1. Round the mean to a nice whole number and fill in one step!
df['ConvertedSalary'] = df['ConvertedSalary'].fillna(
    round(df['ConvertedSalary'].mean())
)
```
