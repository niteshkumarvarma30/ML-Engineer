# Dealing with Missing Data

In our last lesson, we used Pandas to play detective and find all the missing blank spaces (NaN) in our dataset.

Because machine learning models will immediately crash if they see a blank space, we have to fix them. Here are the three main ways to handle missing data!

## 1. Method A: The "Nuclear" Option (Listwise Deletion)

If you have a massive dataset of 100,000 rows, and only 5 people forgot to write down their Salary, the easiest thing to do is just throw those 5 rows in the trash.

This is formally called Complete Case Analysis or Listwise Deletion.

### How to do it in Pandas

*(See the Listwise deletion in Python screenshots)*

**Example Dataset snippet:**
```
     SurveyDate       ConvertedSalary   Hobby ... \
0  2/28/18 20:20                  NaN     Yes ...
1  6/28/18 13:26              70841.0     Yes ...
2   6/6/18 3:37                   NaN      No ...
3   5/9/18 1:06               21426.0     Yes ...
4  4/12/18 22:41              41671.0     Yes ...
```

#### 1. Drop Everything:
If you want to be ruthless and delete a row if it is missing even one single piece of data, use the `how='any'` argument:

```python
# Drops the whole row if ANY column has a NaN
df = df.dropna(how='any')
```

#### 2. The Targeted Drop (subset):
Usually, you only care about specific columns. If a user forgot to write their favorite color, that's fine. But if they forgot to write their `ConvertedSalary` (the thing you are trying to predict), the row is useless.

```python
# Only drops the row IF the 'ConvertedSalary' is blank. 
# It spares rows that are just missing a favorite color!
df = df.dropna(subset=['ConvertedSalary'])
```

### The Danger of Deletion

While dropping rows is easy, it is dangerous. If you drop a row because it's missing a salary, you are also throwing away that person's Age, Education, and Location. You are throwing perfectly good data in the trash, which starves your machine learning model of examples!

## 2. Method B: The "Fill in the Blanks" Option (Imputation)

If you can't afford to throw rows away, you have to fill in the blanks.

*(See the Replacing with strings screenshot)*

For text/categorical columns, a very safe and common practice is to just replace the blank space with a generic placeholder string, like "Other" or "Not Given".

We do this using the Pandas `.fillna()` method!

```python
# Replace all NaNs in the Gender column with the word 'Not Given'
# inplace=True means "Permanently save this change to my spreadsheet right now"
df['Gender'].fillna('Not Given', inplace=True)
```

## 3. Method C: The "Secret Clue" Option (Recording the Absence)

Sometimes, the fact that a user left a box blank is the most important clue of all.

For example, if an online form asks "How many children do you have?", and the user skips the question, it might literally mean they have 0 children! Or, if they skip the "What is your Salary?" box, it might be a massive behavioral clue that the user is highly secretive.

*(See the Recording missing values screenshot)*

Instead of throwing the row away, or guessing what the missing value is, we create a brand new Yes/No Checkbox that simply records whether the user skipped the question or not!

```python
# 1. Create a new column. 
# If 'Salary' is NOT null, it gets a True. If it is blank, it gets a False.
df['Provided_Salary'] = df['Salary'].notnull()

# 2. Now that we captured the behavioral clue in our new column, 
# we can safely delete the messy original column! (axis=1 means drop the column)
df = df.drop(columns=['Salary'], axis=1)
```

By doing this, you successfully get rid of the NaN values that crash your model, and you keep the secret behavioral clue for your model to learn from!
