# Binarizing & Binning Numeric Data

We already know that machine learning algorithms are basically giant calculators—they love numbers.

So, if your dataset already has numeric columns (like Age, Price, or Number of Violations), you might think: "Great! I don't need to do any feature engineering here."

**Wrong!** Sometimes, giving a model the exact number actually confuses it. We can improve our model by simplifying those numbers using two techniques: **Binarizing** and **Binning**.

## 1. Does the exact size actually matter?

Look at the *Health & Safety toy dataset* in your screenshots. It tracks how many "Major Violations" a restaurant has committed.

*   **Restaurant A:** 0 violations.
*   **Restaurant B:** 1 violation.
*   **Restaurant C:** 15 violations.

Ask yourself a logical business question: Do you really care about the difference between 1 violation and 15 violations? Probably not. If a restaurant has any major violations, you aren't going to eat there!

The exact magnitude (1 vs. 15) is distracting noise. We only care about the direction (Did they have violations: Yes or No?).

## 2. Binarizing (The "Yes/No" Switch)

To fix this, we use **Binarizing**. This simply means turning a wide range of numbers into a strict 1 (Yes) or 0 (No).

Look at the *Binarizing numeric variables* screenshot. Here is how we do it in Pandas using the `.loc` (location) tool:

```python
# 1. Create a brand new column and fill it entirely with 0s (Assume everyone is innocent)
df["Binary_Violation"] = 0

# 2. Use .loc to find anyone with MORE than 0 violations, and change their 0 to a 1!
df.loc[df["Number_of_Violations"] > 0, "Binary_Violation"] = 1
```

**The Result:** Restaurant B (1) and Restaurant C (15) both get a 1 in the new column. The model now just sees a clean, simple rule: Safe (0) vs. Dangerous (1).

## 3. Binning (The "Grouping" Method)

What if you want more than just a Yes/No switch? What if you want to group numbers into a few specific categories? We use **Binning**.

A classic example is Age. Instead of feeding the model exact ages like 14, 16, 45, and 49, we might just want to group them into "Teens" and "Adults".

Look at your *Binning numeric variables* screenshots. Let's group our restaurants into 3 risk categories:

*   **Group 1 (Perfect):** 0 offenses.
*   **Group 2 (Warning):** 1 to 2 offenses.
*   **Group 3 (Danger):** 3 or more offenses.

### The Pandas Tool: `pd.cut()`

To do this, we use the Pandas `cut()` function. You give it your data, the edges of the "buckets" (bins) you want to create, and the labels for those buckets!

```python
import numpy as np
import pandas as pd

# 1. Define the edges of your buckets. 
# We use -np.inf (negative infinity) and np.inf (positive infinity) to safely catch all extreme numbers!
# This creates 3 buckets: [below 0], [between 0 and 2], [above 2]
bins = [-np.inf, 0, 2, np.inf]

# 2. Name your buckets
labels = [1, 2, 3]

# 3. Use pd.cut() to chop up the column and sort them into the buckets!
df["Binned_Group"] = pd.cut(df["Number_of_Violations"], bins=bins, labels=labels)
```

**The Result:** If a restaurant had 50 violations, `pd.cut()` looks at the bins, realizes 50 is larger than 2, and drops it into bucket 3 (Danger).

You successfully took a messy, infinite range of numbers and cleanly categorized them into 3 easy-to-understand groups!
