# The Basics of Feature Engineering

When people talk about Machine Learning, they usually focus on the cool, complex algorithms. But in the real world, data scientists spend most of their time doing Feature Engineering.

## 1. What is Feature Engineering?

Imagine you are trying to predict the price of a house.
A machine learning algorithm is basically just a giant, strict calculator. It expects all the data to be handed to it in a perfect, clean math table (a matrix or vector).

**The Problem:** In the real world, data isn't a perfect math table. A house listing might have text ("Victorian"), dates ("Built in 1995"), True/False checkboxes ("Has Pool: True"), and missing blanks.

**The Solution:** Feature Engineering is the act of taking that messy, raw information and transforming it into clean numerical columns (features) that the calculator can actually understand.

## 2. Step 1: Getting to Know Your Data (Pandas)

Before you can transform your data, you need to know exactly what you are working with. We use the Pandas library in Python to load and inspect our dataset (like the StackOverflow survey data mentioned in the lesson).

Here are the essential Pandas tools shown in your screenshots to inspect your data:

### A. Loading and Peeking

We load the CSV file into a DataFrame (a programmable spreadsheet) and use `.head()` to peek at the first 5 rows to see what it looks like.

```python
import pandas as pd

df = pd.read_csv("stackoverflow_survey.csv")
print(df.head())
```

### B. Checking the Columns

To see a quick list of all the clues (features) we have available, we print the `columns` attribute.

```python
# Prints a list of all the column headers
print(df.columns)
```

## 3. Step 2: Checking the Data Types (dtypes)

This is the most critical step before Feature Engineering. You must ask: "Did the computer import my numbers as actual math numbers, or did it accidentally import them as text?"

You check this using the `dtypes` (Data Types) attribute.

```python
print(df.dtypes)
```

**The Output:** It will print a list of your columns next to their data type:

*   `int64`: Integer (Whole numbers like 42).
*   `float64`: Float (Decimal numbers like 3.14).
*   `object`: Strings/Text (Words like "Python" or "Yes"). *Note: Machine learning models will crash if you feed them object columns!*

## 4. Step 3: Selecting Specific Types

If you have a massive dataset with 100 columns, you might want to separate the math columns from the text columns so you can feature-engineer them differently.

Pandas makes this incredibly easy using the `select_dtypes()` method!

```python
# Create a brand new DataFrame that ONLY contains the Integer columns!
# It will completely ignore all the floats and text objects.
only_integers = df.select_dtypes(include=['int'])

print(only_integers.columns)
```

By separating out your data types, you can easily apply math formulas to your numbers, and safely apply text-encoding (like Dummy Variables) to your objects!
