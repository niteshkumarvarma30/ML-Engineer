# Logistic Regression - Complete Notes (README.md)

1. What is Logistic Regression?

Logistic Regression is a supervised machine learning algorithm used for binary classification problems.

Unlike Linear Regression, which predicts continuous values, Logistic Regression predicts the probability that an input belongs to a class.

Examples:

- Spam / Not Spam
- Pass / Fail
- Disease / No Disease
- Fraud / Not Fraud

The output is always between 0 and 1.

---

2. Why Not Use Linear Regression?

Linear Regression can produce values like:

- -2
- 3.5
- 8

These cannot represent probabilities.

A probability must satisfy:

0 ≤ Probability ≤ 1

Therefore Logistic Regression uses the Sigmoid Function.

---

3. Sigmoid Function

The sigmoid function converts any real number into a probability.

Formula:

                1
σ(z) = ----------------
       1 + e^(-z)

where

z = wᵀx + b

Here

- w = Weights
- x = Input Features
- b = Bias
- z = Linear Combination

The output always lies between

0 < σ(z) < 1

---

4. Example

Suppose

z = 2

Then

σ(2) = 0.88

Meaning

Probability(Class = 1) = 88%

Similarly

z = -2

Then

σ(-2) = 0.12

Meaning

Probability(Class = 1) = 12%

---

5. Decision Boundary

If

Probability ≥ 0.5

Predict

Class 1

Else

Class 0

Since

σ(0)=0.5

Decision Boundary is

wᵀx + b = 0

---

6. Goal of Training

We want to find the best

- Weights (w)
- Bias (b)

such that the model predicts the correct class with high probability.

To achieve this we use

Maximum Likelihood Estimation (MLE)

---

7. What is Likelihood?

Suppose our model predicts

Sample| Correct Probability
1| 0.7
2| 0.4
3| 0.4
4| 0.8

Likelihood is

L = 0.7 × 0.4 × 0.4 × 0.8

L = 0.0896

Likelihood tells us

«"How likely is the observed training data under the current model?"»

Higher likelihood means a better model.

---

8. Where do values like 0.7, 0.4, 0.8 come from?

They are NOT calculated using Maximum Likelihood.

For every training sample,

Step 1

z = wᵀx + b

Step 2

Apply Sigmoid

Probability = 1 / (1 + e^(-z))

The sigmoid outputs probabilities like

0.81
0.63
0.45
0.91

Maximum Likelihood simply multiplies the probabilities of the correct class.

---

9. Why do we Maximize Likelihood?

Suppose

Model A

Likelihood = 0.0896

Model B

Likelihood = 0.1764

Since

0.1764 > 0.0896

Model B predicts the data better.

Therefore we maximize

Likelihood

---

10. Why is Likelihood Difficult?

Suppose we have

10000 training samples.

Likelihood becomes

0.9 × 0.8 × 0.7 × 0.6 × ...

This becomes an extremely tiny number

0.000000000000.....

Problems:

- Numerical Underflow
- Difficult Optimization

---

11. Why Take Log?

Because

log(a × b)

= log(a) + log(b)

Instead of multiplying thousands of numbers,

we simply add logarithms.

Example

Instead of

0.8 × 0.7 × 0.9

we compute

log(0.8)

+ log(0.7)

+ log(0.9)

Advantages

- Prevents Underflow
- Converts Multiplication into Addition
- Easier Differentiation
- Easier Optimization

---

12. Why Maximize Log Likelihood?

Logarithm is a strictly increasing function.

Suppose

Model A

Likelihood = 0.2

Model B

Likelihood = 0.8

Clearly

0.8 > 0.2

Take logarithm

log(0.2) = -1.609

log(0.8) = -0.223

Still

-0.223 > -1.609

The better model remains the better model.

Therefore

Maximize(L)

=

Maximize(log L)

Both produce the same optimal weights.

---

13. Why Take Negative Log?

Gradient Descent is a minimization algorithm.

But

Log Likelihood

must be maximized.

Instead of designing a new optimization algorithm,

we multiply by

-1

Now

Maximize(log L)

↓

Minimize(-log L)

Nothing changes except the optimization direction.

Example

Model A

log L = -10

Model B

log L = -2

Better model

-2 > -10

Multiply by -1

Model A = 10

Model B = 2

Now Gradient Descent minimizes

2

which still selects Model B.

---

14. Negative Log Likelihood

The loss becomes

Loss = -log(L)

This is called

Negative Log Likelihood (NLL)

---

15. Binary Cross Entropy

For Binary Classification,

Negative Log Likelihood becomes

Loss = -(1/n) Σ [ y log(ŷ)

+ (1-y) log(1-ŷ) ]

where

- y = Actual Label
- ŷ = Predicted Probability

Binary Cross Entropy is also called

- Log Loss
- Logistic Loss

All three are identical.

---

16. Why Binary Cross Entropy?

Suppose

Actual Label

y = 1

Then

1-y = 0

Loss becomes

-log(ŷ)

Now suppose

y = 0

Then

Loss = -log(1-ŷ)

Instead of writing two different equations,

Binary Cross Entropy combines both into one formula.

---

17. Gradient Descent

Initially

Random Weights

↓

For every iteration

Step 1

z = wᵀx + b

↓

Step 2

ŷ = Sigmoid(z)

↓

Step 3

Compute BCE Loss

↓

Step 4

Compute Gradients

∂L/∂w

∂L/∂b

↓

Step 5

Update Weights

w = w - α(∂L/∂w)

b = b - α(∂L/∂b)

Repeat until convergence.

---

18. Why Subtract the Gradient?

The gradient points toward increasing loss.

To reduce loss,

we move in the opposite direction.

Hence

w = w - α∇L

where

α = Learning Rate

20. Frequently Asked Questions

Q1. Where do values like 0.7, 0.4, 0.8 come from?

They are the probabilities produced by the Sigmoid Function.

---

Q2. Why use Maximum Likelihood?

Because we want the model to assign the highest possible probability to the correct class.

---

Q3. Why take Log?

Because multiplying thousands of probabilities creates extremely small numbers.

Log converts multiplication into addition.

---

Q4. Why maximize Log Likelihood?

Because logarithm preserves ordering.

The model with the highest likelihood also has the highest log-likelihood.

---

Q5. Why take Negative Log?

Because Gradient Descent minimizes a function.

Taking the negative converts a maximization problem into an equivalent minimization problem.

---

Q6. Why Binary Cross Entropy?

Binary Cross Entropy is simply the Negative Log Likelihood written in a compact form for binary classification.
