### Solution

Here is the completed code for your exercise, along with a breakdown of exactly how the blanks were filled in based on the scikit-learn workflow we discussed earlier.

```python
# Create X and y arrays
X = sales_df.drop("sales", axis=1).values
y = sales_df["sales"].values

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Instantiate the model
reg = LinearRegression()

# Fit the model to the data
reg.fit(X_train, y_train)

# Make predictions
y_pred = reg.predict(X_test)
print("Predictions: {}, Actual Values: {}".format(y_pred[:2], y_test[:2]))
```

### Explanation of the Filled Blanks:
  
**1. Creating the Arrays:**  
* `X = sales_df.drop("sales", axis=1).values`: To get our features (`X`), we take the full dataset and `.drop()` the target column (`"sales"`). The `axis=1` tells pandas to drop the column, not a row. Finally, we use `.values` to convert the remaining data into a 2D NumPy array.  
* `y = sales_df["sales"].values`: We isolate just the target column (`"sales"`) and use `.values` to turn it into a 1D NumPy array for scikit-learn.  

**2. Instantiating the Model:**
* `reg = LinearRegression()`: Since we are predicting a continuous number (sales), we need a regression model. We instantiate the `LinearRegression()` algorithm and assign it to the variable `reg`. *(Note: this assumes you have run `from sklearn.linear_model import LinearRegression` at the top of your script).*

**3. Fitting the Model:**
* `reg.fit(X_train, y_train)`: This is where the actual "learning" happens. We pass the training data (`X_train` and `y_train`) into the `.fit()` method so the model can discover the relationship between the features and the sales.

**4. Making Predictions:**
* `y_pred = reg.predict(X_test)`: Now that the model is trained, we test it. We use the `.predict()` method and feed it the unseen testing data (`X_test`). It outputs an array of its predicted sales numbers, which we save as `y_pred`.
