## Regularized regression: Ridge

In this exercise, you will fit ridge regression models over a range of different alpha values, and print their $R^2$ scores. You will use all of the features in the `sales_df` dataset to predict `"sales"`. The data has been split into `X_train`, `X_test`, `y_train`, `y_test` for you.

A variable called `alphas` has been provided as a list containing different alpha values, which you will loop through to generate scores.

### Instructions
* Import `Ridge`.
* Instantiate `Ridge`, setting alpha equal to `alpha`.
* Fit the model to the training data.
* Calculate the $R^2$ score for each iteration of `ridge`.

### Solution

```python
# Import Ridge
from sklearn.linear_model import Ridge

alphas = [0.1, 1.0, 10.0, 100.0, 1000.0, 10000.0]
ridge_scores = []

for alpha in alphas:
  
  # Create a Ridge regression model
  ridge = Ridge(alpha=alpha)
  
  # Fit the data
  ridge.fit(X_train, y_train)
  
  # Obtain R-squared
  score = ridge.score(X_test, y_test)
  ridge_scores.append(score)

print(ridge_scores)
```

---

### Explanation of the Solution

1. **Importing Ridge**: 
   `from sklearn.linear_model import Ridge`
   Just like standard linear regression, `Ridge` is a linear model available within scikit-learn's `linear_model` module.

2. **Instantiating the Model**: 
   `ridge = Ridge(alpha=alpha)`
   Inside the for loop, we create a new `Ridge` model for each value in the `alphas` list. 
   *(Important Note: Scikit-learn uses the parameter name `alpha` instead of `lambda` ($\lambda$) for the shrinkage penalty, because `lambda` is a reserved keyword in the Python language).*

3. **Fitting the Data**: 
   `ridge.fit(X_train, y_train)`
   We train each newly created Ridge model using the training features and targets so it learns the relationship.

4. **Obtaining R-squared**: 
   `score = ridge.score(X_test, y_test)`
   We evaluate the model using the `.score()` method to calculate the $R^2$ value on the unseen testing data. By appending these scores to a list and printing them, we can observe exactly how different `alpha` penalty values impact the model's ability to generalize to new data!
