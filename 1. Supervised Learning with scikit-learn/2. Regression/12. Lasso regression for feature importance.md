In this exercise, you will fit a lasso regression model to the `sales_df` data and plot the model's coefficients.

### Solution

```python
# Import Lasso
from sklearn.linear_model import Lasso

# Instantiate a lasso regression model
lasso = Lasso(alpha=0.3)

# Fit the model to the data
lasso.fit(X, y)

# Compute and print the coefficients
lasso_coef = lasso.coef_
print(lasso_coef)
plt.bar(sales_columns, lasso_coef)
plt.xticks(rotation=45)
plt.show()
```

---

### Explanation of the Solution

1. **Importing Lasso**: 
   `from sklearn.linear_model import Lasso`
   Just like `Ridge` and `LinearRegression`, `Lasso` lives inside scikit-learn's `linear_model` module.

2. **Instantiating the Model**: 
   `lasso = Lasso(alpha=0.3)`
   We create the Lasso model and explicitly set the shrinkage penalty (`alpha`) to `0.3`.

3. **Fitting the Data**: 
   `lasso.fit(X, y)`
   We train the model on our full dataset (`X` features and `y` target) so it can discover the relationships and decide which feature coefficients it needs to penalize.

4. **Extracting Coefficients**: 
   `lasso_coef = lasso.coef_`
   After the model is fitted, the calculated multipliers (coefficients) for each feature are stored in the `.coef_` attribute. By extracting this array, we can pass it into matplotlib to plot a bar chart. This visualizes exactly which features Lasso aggressively shrunk to zero (meaning they aren't important), and which features survived the penalty (meaning they are highly predictive)!
