### The Bug in the Code

You encountered the following error in your code:
`ValueError: Classification metrics can't handle a mix of binary and continuous targets`

Here is the code that caused the error:
```python
# Import roc_auc_score
from sklearn.metrics import roc_auc_score, confusion_matrix, classification_report

# Calculate roc_auc_score
print(roc_auc_score(y_test, y_pred_probs))

# Calculate the confusion matrix
print(confusion_matrix(y_test, y_pred_probs))  # <-- The error is here!

# Calculate the classification report
print(classification_report(y_test, y_pred_probs))  # <-- And here!
```

### Why did this happen?

The error message "mix of binary and continuous targets" gives us a massive clue. 

* `roc_auc_score` is an evaluation metric that **needs probabilities** (continuous numbers between 0 and 1, like `0.85`) because it calculates the area under the curve across many different thresholds. So passing `y_pred_probs` here is completely correct.
* `confusion_matrix` and `classification_report` **need hard class labels** (binary integers, either `0` or `1`). A confusion matrix is simply counting up discrete categories (e.g., how many times the model guessed 1 and the answer was 1). It doesn't know what to do with a continuous probability of `0.85`.

By passing `y_pred_probs` into the confusion matrix, scikit-learn threw an error because it saw true binary labels (`y_test`) being improperly compared against continuous probabilities (`y_pred_probs`).

---

### The Solution (Corrected Code)

To fix this, we simply need to pass the hard predicted labels (`y_pred`) into the confusion matrix and classification report, while keeping `y_pred_probs` for the ROC AUC score.

```python
# Import metrics
from sklearn.metrics import roc_auc_score, confusion_matrix, classification_report

# Calculate roc_auc_score (Needs PROBABILITIES)
print(roc_auc_score(y_test, y_pred_probs))

# Calculate the confusion matrix (Needs LABELS)
print(confusion_matrix(y_test, y_pred))

# Calculate the classification report (Needs LABELS)
print(classification_report(y_test, y_pred))
```
