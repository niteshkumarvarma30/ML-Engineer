# Machine Learning Basics & Scikit-Learn

Before we start building complex algorithms to predict the future, we have to understand the basic workflow of a Machine Learning project.

The most popular library for doing this in Python is called Scikit-Learn. Here is the ultimate step-by-step checklist for building a model.

## 1. Always Look at Your Data First!

Before you do any math, you must look at your raw data to see if it is clean, messy, or missing pieces.

**Looking at the Numbers:**
As shown in your screenshots, you can quickly inspect your data using:

*   `df.head()`: (For Pandas DataFrames). Shows you the first 5 rows and all the column headers.
*   `array.shape`: (For NumPy arrays). Tells you exactly how big your grid of data is (e.g., `(10, 5)` means 10 rows and 5 columns).
*   `array[:3]`: Prints out the raw numbers for the first 3 rows.

**Visualizing the Data:**
You should always plot your data using tools like Matplotlib (`ax.plot()`) or Pandas (`df.plot()`). Drawing a quick scatterplot or histogram is the absolute fastest way for a human to spot weird outliers or obvious errors before the computer gets confused by them!

## 2. Preparing Data for Scikit-Learn (The "Shape" Rule)

Scikit-Learn models are very strict. They expect your data to be handed to them in a very specific 2-Dimensional shape: `(samples, features)`.

*   **Samples (Rows):** The number of items you are looking at (e.g., 100 different houses).
*   **Features (Columns):** The number of clues you have for each item (e.g., Square Footage, Number of Bedrooms, Age).

**The Dreaded 1D Array Error:**
Look at your *If your data is not shaped properly* screenshot.
Sometimes, you only have one single feature (e.g., you only know the Square Footage of the houses).
If you check `array.shape`, it will say `(10,)`.

This is a 1-Dimensional array. If you hand this to Scikit-Learn, it will crash! It strictly requires 2 dimensions.

**The Fix:** You use the `.reshape()` method to forcefully add that missing dimension.

```python
# The -1 tells the computer: "Keep however many rows you already have."
# The 1 tells the computer: "Force this into exactly 1 column."
array = array.reshape(-1, 1)

# Now array.shape will safely output (10, 1)
```

## 3. The 3-Step Scikit-Learn Workflow

Once your data is perfectly shaped, Scikit-Learn uses the exact same workflow for almost every single model it has!

### Step A: Instantiate & Fit

(See your *Fitting a model* screenshot)
First, you import the model you want to use (like a Support Vector Classifier: `LinearSVC`). You create a blank instance of it, and then you train it by feeding it your Features (`X`) and your Target Answers (`y`).

```python
from sklearn.svm import LinearSVC

# Instantiate the blank model
model = LinearSVC()

# Train the model on the data!
model.fit(X, y)
```

### Step B: Investigate the Model's "Brain"

(See your *Investigating the model* screenshot)
Once the model is trained, how do you know what it learned? You can look at its Coefficients (`.coef_`).

The model assigns one coefficient (a weight/score) to every single feature.

If a feature has a massive coefficient, the model thinks it is incredibly important. If it is close to zero, the model thinks that feature is useless.

### Step C: Predict the Future!

(See your *Predicting with a fit model* screenshot)
Now that the model has learned the rules from the training data, you hand it brand new, unseen data (`X_test`) and ask it to guess the answers!

```python
# The model uses the rules it learned to generate its final guesses!
predictions = model.predict(X_test)
```
