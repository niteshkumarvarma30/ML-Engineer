## Hierarchical clustering of the grain data

### Concept: Building and Plotting the Hierarchy

In the video, you learned that the SciPy `linkage()` function performs hierarchical clustering on an array of samples. 

* **`linkage(samples, method='complete')`**: This function calculates the distances between all the data points and builds the actual hierarchy (the tree) step-by-step. The `method='complete'` argument tells the algorithm how to calculate the distance between clusters (we will learn more about linkage methods later!). The output is an array of `mergings`.
* **`dendrogram(mergings)`**: This function takes that array of `mergings` and visually draws the tree. To make the tree readable when you have a lot of data points, you can use formatting arguments like `leaf_rotation` (to turn the labels 90 degrees) and `leaf_font_size` (to make the text smaller).

Use the `linkage()` function to obtain a hierarchical clustering of the grain samples, and use `dendrogram()` to visualize the result. A sample of the grain measurements is provided in the array `samples`, while the variety of each grain sample is given by the list `varieties`.

### Solution

```python
# Perform the necessary imports
from scipy.cluster.hierarchy import linkage, dendrogram
import matplotlib.pyplot as plt

# Calculate the linkage: mergings
mergings = linkage(samples, method='complete')

# Plot the dendrogram, using varieties as labels
dendrogram(mergings,
           labels=varieties,
           leaf_rotation=90,
           leaf_font_size=6,
)
plt.show()
```
