## Non-negative data

### Concept: Identifying NMF-Compatible Data
As we learned in the previous lesson, NMF (Non-negative Matrix Factorization) is a powerful tool, but it has one strict rule: **It can only be applied to arrays where all features are non-negative (greater than or equal to 0).** 

If a dataset contains even a single negative number, NMF will crash.

---

### Question
Which of the following 2-dimensional arrays are examples of non-negative data?

1. A tf-idf word-frequency array.
2. An array of daily stock market price movements (up and down), where each row represents a company.
3. An array where rows are customers, columns are products and entries are `0` or `1`, indicating whether a customer has purchased a product.

### Possible Answers
* [ ] 1 only
* [ ] 2 and 3
* [x] **1 and 3**

---

### Why this is correct:
* **Option 1 (Word Frequency):** You can't have a negative number of words in a document. The lowest possible frequency is `0` (the word didn't appear). Therefore, this is non-negative.
* **Option 2 (Stock Movements):** Stock prices can go *down*, which means they are represented by negative numbers (e.g., `-1.5%`). Because it contains negative numbers, **NMF cannot be used here.** (You would have to use PCA instead).
* **Option 3 (Purchase History):** The only possible values are `0` (didn't buy) and `1` (did buy). Since both are non-negative, NMF can easily be used to find hidden purchasing patterns (like "The Grocery Shopper" component vs "The Electronics Shopper" component).
