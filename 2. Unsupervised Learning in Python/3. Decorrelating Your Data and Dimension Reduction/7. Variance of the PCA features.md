## Variance of the PCA features

### Concept: Building a Scree Plot

The fish dataset is 6-dimensional. But what is its *intrinsic dimension*? To answer this, you need to plot the variance of the PCA features (a Scree Plot). 

Because the features of the fish dataset were measured on different scales (e.g., weight in grams vs. length in centimeters), you **must standardize the features first** before applying PCA. If you don't, PCA will incorrectly assume that the feature with the largest numbers (like weight) has the most variance, ruining the algorithm.

To do this seamlessly, you will build a scikit-learn pipeline that chains a `StandardScaler` directly into a `PCA` model. After fitting the pipeline, you can extract the calculated variance for each component using the `pca.explained_variance_` attribute and plot it on a bar chart!

* Use the `plt.bar()` function to plot the explained variances, with `features` on the x-axis and `pca.explained_variance_` on the y-axis.
