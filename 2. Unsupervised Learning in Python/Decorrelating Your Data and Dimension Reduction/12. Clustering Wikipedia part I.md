## Clustering Wikipedia part I

### Concept: Building a Text Clustering Pipeline

In the previous guide, you learned that standard `PCA` will crash if you feed it a sparse array (like a word-frequency matrix that is 99% zeros). To compress sparse text data, you must use its twin brother: `TruncatedSVD`.

In this exercise, you will combine everything you've learned to build a powerful machine learning pipeline to cluster Wikipedia articles based on their text content.

You will build a `Pipeline` that first uses `TruncatedSVD` to reduce the massive dimensionality of a pre-computed word-frequency matrix down to a manageable `50` components. Then, it will pass those compressed features directly into a `KMeans` algorithm to group the articles into `6` distinct clusters.

*(Note: We've precomputed the word-frequency matrix for you, so there's no need for a `TfidfVectorizer` in this specific pipeline).*

### Instructions

* Import:

* Create a `TruncatedSVD` instance called `svd` with `n_components=50`.
* Create a `KMeans` instance called `kmeans` with `n_clusters=6`.
* Create a pipeline called `pipeline` consisting of `svd` and `kmeans`.

### Solution

```python
# Perform the necessary imports
from sklearn.decomposition import TruncatedSVD
from sklearn.cluster import KMeans
from sklearn.pipeline import make_pipeline

# Create a TruncatedSVD instance: svd
svd = TruncatedSVD(n_components=50)

# Create a KMeans instance: kmeans
kmeans = KMeans(n_clusters=6)

# Create a pipeline: pipeline
pipeline = make_pipeline(svd, kmeans)
```
