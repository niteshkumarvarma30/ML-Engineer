## The first principal component

### Concept: Visualizing the PCA "Arrow"

We know that PCA identifies the "principal components" (the directions of maximum variance) in our dataset. But how do we actually find them in code?

When you call `model.fit()` on a PCA instance, it calculates and stores these directions as vectors (arrows) inside the `.components_` attribute. The first row (`.components_[0, :]`) is the **first principal component**—the arrow pointing directly down the longest spread of the data. 

PCA also calculates the exact center (mean) of your data cloud and stores it in the `.mean_` attribute. 

In this exercise, you will extract both of these mathematical properties and use `plt.arrow()` to visually draw the first principal component directly on top of a scatter plot!

### Solution

```python
# Make a scatter plot of the untransformed points
plt.scatter(grains[:,0], grains[:,1])

# Create a PCA instance: model
model = PCA()

# Fit model to points
model.fit(grains)

# Get the mean of the grain samples: mean
mean = model.mean_

# Get the first principal component: first_pc
first_pc = model.components_[0,:]

# Plot first_pc as an arrow, starting at mean
plt.arrow(mean[0], mean[1], first_pc[0], first_pc[1], color='red', width=0.01)

# Keep axes on same scale
plt.axis('equal')
plt.show()
```
