## Dimension reduction of the fish measurements

### Concept: Applying the Intrinsic Dimension

In a previous exercise, you built a Scree Plot and used human judgment to determine that `2` was a reasonable choice for the "intrinsic dimension" of the fish measurements (because the variance dropped off a cliff after the second PCA feature). 

Now it is time to actually put that knowledge into practice. You will use PCA for dimensionality reduction, explicitly telling the algorithm to retain only those 2 most important components and throw away the rest of the noise. 

By passing `n_components=2` into the PCA model, you force it to compress the dataset. Notice at the end of the script, when you print the shape of the new `pca_features` array, it will output `(85, 2)`. The original dataset had 6 columns, and now it has successfully been compressed down to 2!

*(Note: The fish measurements have already been scaled for you and are available as `scaled_samples`)*.

### Instructions

* Import `PCA` from `sklearn.decomposition`.
* Create a `PCA` instance called `pca` with `n_components=2`.
* Use the `.fit()` method of `pca` to fit it to the scaled fish measurements `scaled_samples`.
* Use the `.transform()` method of `pca` to transform the `scaled_samples`. Assign the result to `pca_features`.

### Solution

```python
# Import PCA
from sklearn.decomposition import PCA

# Create a PCA model with 2 components: pca
pca = PCA(n_components=2)

# Fit the PCA instance to the scaled samples
pca.fit(scaled_samples)

# Transform the scaled samples: pca_features
pca_features = pca.transform(scaled_samples)

# Print the shape of pca_features
print(pca_features.shape)
```
