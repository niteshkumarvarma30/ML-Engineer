# Mastering t-SNE (t-Distributed Stochastic Neighbor Embedding)

## Introduction: A Better Dimensionality Reduction Technique
**t-SNE** is a statistical method for visualizing high-dimensional data by reducing it to lower-dimensional spaces (typically 2D or 3D). 

This makes it easier to visualize and interpret complex datasets, especially in machine learning and data science.

### Why learn t-SNE if we already have PCA?
Principal Component Analysis (PCA) works well on *linear* data. However, **t-SNE has no such restriction**. Whether the data is linear or non-linear, t-SNE performs well. 

For example, when visualizing the MNIST handwritten digit dataset, t-SNE exhibits superior partitioning of the digits compared to PCA. This improvement happens because the MNIST data is highly non-linear; t-SNE effectively captures this non-linearity, while PCA struggles.

---

## Core Idea of t-SNE

The core idea behind t-SNE is to map high-dimensional data points to a lower-dimensional space in a way that **preserves the local relationships** between points. 

It achieves this by:
1. Measuring the similarity between data points in the high-dimensional space and representing this similarity as probabilities.
2. Constructing a similar probability distribution in the lower-dimensional space.
3. Minimizing the difference between the two distributions using a technique called gradient descent.

### What does "preserving local relationships" mean?
Imagine a dataset where similar data points are located close to each other in a high-dimensional space. Preserving local relationships means that after the dimensionality reduction, these similar points should still be positioned closely together in the new 2D or 3D space. 

Similarly, if two data points are dissimilar (far apart) in the original space, they should remain relatively far apart in the reduced space.

---

## Geometrical Intuition & The 3 Stages of t-SNE

The concept involves computing the similarity between each data point and all other points in the dataset.

### Stage 1: High-Dimensional Similarity
Relying solely on physical Euclidean distance becomes unreliable in higher dimensions due to the "curse of dimensionality." Instead, t-SNE utilizes a probabilistic approach. 

For a data point $x_i$, a **Gaussian (Normal) distribution** is plotted around it. We calculate the distance of every other point $x_j$ to $x_i$ and plot these on the x-axis. The y-axis represents the probability density. This gives us a similarity score: higher probability means they are close neighbors, low probability means they are dissimilar.

Because the density of points varies, the probability of $x_1$ to $x_2$ might not equal $x_2$ to $x_1$.

### Stage 2: Low-Dimensional Similarity
We now project the points into a lower dimension (e.g., 2D) randomly. We recalculate the similarity scores for each point relative to the others. 

However, in this lower-dimensional space, we do **not** use a Gaussian distribution. Instead, we use a **Student's t-distribution** (with one degree of freedom). This is why the algorithm is called *t-distributed*. The heavy tails of the t-distribution prevent the "crowding problem" where points get jammed too closely together in the lower dimension.

### Stage 3: Alignment (Optimization)
We now have two similarity matrices: one for the high dimension and one for the low dimension. To ensure that neighboring points remain close, we adjust the positions of the points iteratively in the lower dimension until its similarity matrix matches the high-dimensional matrix as closely as possible.

---

## Mathematical Formulation

### 1. High-Dimensional Similarity
Given a dataset $X = \{x_1, x_2, ..., x_N\}$, the conditional probability $p_{j|i}$ of picking $x_j$ as the neighbor of $x_i$ under a Gaussian distribution is:

$$p_{j|i} = \frac{\exp(-||x_i - x_j||^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-||x_i - x_k||^2 / 2\sigma_i^2)}$$

The probabilities are then symmetrized to get $p_{ij}$:
$$p_{ij} = \frac{p_{j|i} + p_{i|j}}{2N}$$

### 2. Low-Dimensional Similarity
For the low-dimensional space $Y = \{y_1, y_2, ..., y_N\}$, the similarities $q_{ij}$ are defined using a Student's t-distribution:

$$q_{ij} = \frac{(1 + ||y_i - y_j||^2)^{-1}}{\sum_{k \neq l} (1 + ||y_k - y_l||^2)^{-1}}$$

### 3. Objective Function (Cost Function)
We want to minimize the difference between $p_{ij}$ and $q_{ij}$. We measure this difference using the **Kullback-Leibler (KL) divergence**:

$$C = KL(P || Q) = \sum_i \sum_j p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

### 4. Gradient Descent Optimization
To minimize the KL divergence, we use gradient descent. We compute the gradient of the cost function with respect to the low-dimensional points $y_i$:

$$\frac{\partial C}{\partial y_i} = 4 \sum_j (p_{ij} - q_{ij})(y_i - y_j)(1 + ||y_i - y_j||^2)^{-1}$$

By updating the positions of the points based on this gradient iteratively, the algorithm converges on a beautiful, clustered 2D map.

---

## Why use a Gaussian Distribution in High Dimensions?

1. **Differentiable:** The Gaussian function is mathematically smooth and easy to calculate derivatives for.
2. **Distance to Probability Output:** It seamlessly converts physical Euclidean distances into bounded probabilities.
3. **Graceful Handling of Distance:** It smoothly reflects how close or far points are. As points get further away, the probability decreases gradually.
4. **Control of Density via Variance ($\sigma$):** You can control how tightly the Gaussian wraps around a data point by adjusting the variance. Small variance = high density; large variance = low density.

## Code Example: t-SNE in scikit-learn

```python
import matplotlib.pyplot as plt
from sklearn.manifold import TSNE
from sklearn.datasets import fetch_openml
import numpy as np

# Load MNIST dataset
mnist = fetch_openml('mnist_784', version=1)
X = mnist.data / 255.0
y = mnist.target

# Select a random subset for speed
np.random.seed(42)
indices = np.random.choice(range(X.shape[0]), size=10000, replace=False)
X_subset = X.iloc[indices]
y_subset = y.iloc[indices]

# Apply t-SNE
tsne = TSNE(n_components=2, perplexity=30, n_iter=1000, random_state=42)
X_tsne = tsne.fit_transform(X_subset)

# Plot the result
plt.figure(figsize=(12, 8))
scatter = plt.scatter(X_tsne[:, 0], X_tsne[:, 1], c=y_subset.astype(int), cmap='tab10', s=1)
plt.legend(*scatter.legend_elements(), title="Digits")
plt.title('t-SNE of MNIST')
plt.show()
```

## Hyperparameters in t-SNE

1. **Perplexity:** The most important hyperparameter. It acts as a measure of the effective number of neighbors for each point. 
   * Low perplexity emphasizes local structure. High perplexity brings in global structure.
   * **Typical values:** 5 to 50. You must experiment!
2. **Learning Rate:** Determines the step size at each iteration of gradient descent. 
   * Too high = oscillations. Too low = gets stuck in local minima.
   * **Typical values:** 10 to 1000.
3. **Number of Iterations:** How long the algorithm runs. Default is usually 1000. Increase this for massive datasets.

## Points of Wisdom (Best Practices)

* **Axes have no meaning:** Unlike PCA, the X and Y axes in a t-SNE plot have no interpretable physical meaning. t-SNE is strictly for *visualization*, not for prediction or finding feature importance.
* **Interpreting Clusters:** The visual distance *between* two different clusters on the plot may not have a meaningful interpretation. Avoid over-interpreting global relationships.
* **Reproducibility:** t-SNE starts with a random initialization. If you run it twice, it will look different. Always set a `random_state` (seed) if you need reproducible plots.
* **Scaling Data:** Always scale or normalize your data (e.g., `StandardScaler`) before running t-SNE.
* **Curse of Dimensionality:** If you have an insane number of dimensions, it is highly recommended to run PCA first to reduce the data to ~50 dimensions, and *then* run t-SNE on the PCA output.
* **It's Not a Silver Bullet:** Sometimes other algorithms like UMAP or MDS are more appropriate.

---

## Advantages & Disadvantages

**Advantages:**
* If done correctly, gives highly intuitive and beautiful visualizations.
* Phenomenal at handling non-linear data.
* Excellent at preserving the local structure of the data.

**Disadvantages:**
* **Computationally Expensive:** Very slow on massive datasets.
* **Global Structure:** Not very good at preserving the global (macro) structure of the data.
* **Sensitive:** Highly sensitive to hyperparameters (Perplexity).
* **Local Minima:** Can get stuck in local minima during gradient descent.
* **Interpretation:** The distances and axes are extremely challenging to interpret mathematically.
