## Extracting the cluster labels

### Concept: Flat Clustering with fcluster

In the previous exercise, you saw that the intermediate clustering of the grain samples at a height of 6 on the dendrogram results in exactly 3 clusters. 

Now, you will use the `fcluster()` function to actually extract the cluster labels for this intermediate clustering. By providing the `mergings` array and specifying a height threshold of 6 (using `criterion='distance'`), `fcluster` will return a 1D NumPy array of cluster labels, exactly like `.predict()` does in scikit-learn! 

Finally, you will compare those extracted labels with the true grain varieties using a Pandas cross-tabulation to see how well the hierarchical clustering performed.

The hierarchical clustering has already been performed and `mergings` is the result of the `linkage()` function. The list `varieties` gives the variety of each grain sample.

### Why extract labels and evaluate?

A dendrogram is a fantastic visual tool, but machines cannot read pictures. The purpose of using `fcluster()` is to translate that visual tree into tangible, mathematical data points (an array of numerical labels, like `[1, 1, 2, 3...]`). 

Once we have those labels extracted, we can perform real data analysis. Because we happen to know the true "answer key" for this specific dataset (the `varieties` list), we can build a cross-tabulation table to evaluate how well the hierarchical clustering model discovered the natural groups.

**Interpreting the Cross-Tabulation Results:**

When you run the solution code, your cross-tabulation output will look like this:

```text

labels                                           
1                      14           3           0
2                       0           0          14
3                       0          11           0
```

* **Label 1:** Captured 14 samples of Canadian wheat, but mistakenly grouped in 3 samples of Kama wheat.
* **Label 2:** Perfectly captured all 14 samples of Rosa wheat (with no mixing).
* **Label 3:** Captured 11 samples of Kama wheat (with no mixing).

This table proves that our unsupervised algorithm did an incredible job uncovering the natural differences between the three wheat varieties entirely on its own, based purely on physical measurements!

### Solution

```python
# Perform the necessary imports
import pandas as pd
from scipy.cluster.hierarchy import fcluster

# Use fcluster to extract labels: labels
labels = fcluster(mergings, 6, criterion='distance')

# Create a DataFrame with labels and varieties as columns: df
df = pd.DataFrame({'labels': labels, 'varieties': varieties})

# Create crosstab: ct
ct = pd.crosstab(df['labels'], df['varieties'])

# Display ct
print(ct)
```
