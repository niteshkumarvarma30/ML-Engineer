# StandardScaler vs Normalizer

## Introduction

Both **StandardScaler** and **Normalizer** are preprocessing techniques provided by **scikit-learn**, but they solve **different problems**.

- **StandardScaler** scales **features (columns)**.
- **Normalizer** scales **samples (rows)**.

This difference is extremely important in Machine Learning, especially for algorithms like **K-Means**, **KNN**, **SVM**, and **Neural Networks**.

---

# StandardScaler

## Definition

StandardScaler standardizes every feature independently by removing its mean and scaling it to unit variance.

After scaling:

- Mean = 0
- Standard Deviation = 1

---

## Formula

```text
          x - μ
z = -----------------
          σ
```

where

- **x** = Original value
- **μ** = Mean of the feature (column)
- **σ** = Standard deviation of the feature

---

## What does it actually do?

Suppose we have the dataset

| Height (cm) | Weight (kg) |
|-------------|------------:|
| 150 | 50 |
| 160 | 60 |
| 170 | 70 |
| 180 | 80 |

### Step 1: Compute Mean

Height

```text
μ = (150+160+170+180)/4 = 165
```

Weight

```text
μ = (50+60+70+80)/4 = 65
```

---

### Step 2: Compute Standard Deviation

Height

```text
σ ≈ 11.18
```

Weight

```text
σ ≈ 11.18
```

---

### Step 3: Standardize

For first height

```text
z = (150-165)/11.18
  = -1.34
```

For second height

```text
z = (160-165)/11.18
  = -0.45
```

Similarly

| Original | Standardized |
|-----------|-------------:|
|150|-1.34|
|160|-0.45|
|170|0.45|
|180|1.34|

---

## Interpretation

Negative value

```text
Below average
```

Positive value

```text
Above average
```

Zero

```text
Exactly equal to mean
```

---

## Visualization

```text

```

After Scaling

```text
-1.34  -0.45  0.45  1.34
```

Now every feature has

```text
Mean = 0

Std = 1
```

```

```

## Why use StandardScaler?

Some features may dominate because of their large scale.

Example

| Feature | Range |
|----------|------:|
|Age|18–70|
|Salary|20,000–2,000,000|

Salary would dominate the learning process.

StandardScaler puts both on comparable scales.

---

## Algorithms that benefit

- K-Means
- KNN
- Logistic Regression
- Linear Regression (often)
- SVM
- PCA
- Neural Networks

# Normalizer

## Definition

Normalizer scales **each sample (row)** independently.

Instead of changing columns,

it changes every row so that its length becomes **1**.

---

## Formula (L2 Normalization)

```text
                x
Normalized = ---------
              ||x||
```

where

```text
||x|| = √(x₁²+x₂²+...+xₙ²)
```

This is called the **L2 norm**.

---

## Example

Suppose one sample is

```text
[3,4]
```

Magnitude

```text
√(3²+4²)

= √25

= 5
```

Normalized vector

```text
3/5 = 0.6

4/5 = 0.8
```

Result

```text
[0.6 , 0.8]
```

Its length is now

```text
√(0.6²+0.8²)

= 1
```

---

## Another Example

Suppose

```
Sample 1

[2,2]

Sample 2

[100,100]
```

Both become

```
[0.707,0.707]
```

because they point in the same direction.

Normalizer ignores magnitude and preserves direction.

---

## What is being scaled?

Rows

Original

```
[3 4]

↓

[0.6 0.8]
```

Second row

```
[10 0]

↓

[1 0]
```

Every row is treated independently.

---

# Why K-Means Sometimes Uses Normalizer

Suppose two companies have stock prices

Company A

```
100
105
110
115
```

Company B

```
1000
1050
1100
1150
```

Without normalization

Distance

```
Very large
```

K-Means thinks

```
Different companies
```

But actually

Both increased by **5%**.

Normalizer converts both rows to nearly the same direction.

Now K-Means clusters them together because their **trend** is similar.

---

# StandardScaler vs Normalizer

| StandardScaler | Normalizer |
|----------------|------------|
|Scales columns|Scales rows|
|Uses mean & standard deviation|Uses vector magnitude|
|Mean becomes 0|Vector length becomes 1|
|Variance becomes 1|Magnitude becomes 1|
|Each feature independently|Each sample independently|
|Preserves feature relationships|Preserves direction of samples|
|Useful when feature scales differ|Useful when direction matters|

# Interview Question

### Q1. What is the main difference?

**Answer**

- StandardScaler scales **columns (features)**.
- Normalizer scales **rows (samples)**.

---

### Q2. Which one uses mean and standard deviation?

**Answer**

StandardScaler.

---

### Q3. Which one makes vector length equal to 1?

**Answer**

Normalizer.

---

### Q4. Which one is used before K-Means?

**Answer**

Usually **StandardScaler**.

If clustering depends on the **direction** of samples (e.g., text or stock trends), **Normalizer** is often preferred.

---

# Key Takeaways

- **StandardScaler** standardizes each **feature (column)**:
  - Mean = 0
  - Standard Deviation = 1

- **Normalizer** rescales each **sample (row)**:
  - Vector length = 1
  - Preserves direction
  - Ignores magnitude

- Use **StandardScaler** when features have different units or scales.

- Use **Normalizer** when the **direction or pattern** of each sample is more important than its absolute values (e.g., text vectors, cosine similarity, stock price trends).
