# 1. What is K-Means?

K-Means is an **unsupervised machine learning algorithm**.

Its objective is to divide data into `K` groups called **clusters**.

```text
Similar Data Points
        ↓
     K-Means
        ↓
   ┌────┼────┐
   ↓    ↓    ↓
Cluster Cluster Cluster
   0      1      2
```

K-Means does not initially know what the groups mean.

For example, if we have student data, K-Means might discover:

```text
Cluster 0
→ High CGPA + High Aptitude

Cluster 1
→ Low CGPA + Low Aptitude
```

But K-Means itself does not know:

```text
Cluster 0 = Placed
Cluster 1 = Not Placed
```

The cluster meanings are interpreted later.

---

# 2. Supervised vs Unsupervised Learning

## Supervised Learning

In supervised learning, we have:

```text
X = Features
y = Target
```

Example:

| CGPA | Aptitude | Placement |
| ---: | -------: | --------- |
|  8.5 |       90 | Yes       |
|  8.0 |       88 | Yes       |
|  5.5 |       55 | No        |
|  5.8 |       60 | No        |

The model learns:

```text
X → y
```

For example:

```text
CGPA + Aptitude
       ↓
Classification Model
       ↓
Placed / Not Placed
```

---

## Unsupervised Learning

K-Means does not use the target:

```text
X = Features

No y during training
```

Example:

| CGPA | Aptitude |
| ---: | -------: |
|  8.5 |       90 |
|  8.0 |       88 |
|  5.5 |       55 |
|  5.8 |       60 |

K-Means tries to discover natural groups.

```text
X
↓
K-Means
↓
Clusters
```


Therefore:

```text
K-Means sees:

CGPA
Aptitude

K-Means does NOT see:

Placed
Not Placed
```

The target can be used later for evaluation and interpretation.

```python
X = df[['CGPA', 'Aptitude']]
```

```text
             Aptitude

                |
        A ●     |  B ●
                |
                |
        C ●     |  D ●
                |
                └──────────────→ CGPA
```

# 5. Complete K-Means Training Workflow

The basic process is:

```text
Dataset
   ↓
Select Features X
   ↓
Choose K
   ↓
Initialize Centroids
   ↓
Assign Points
   ↓
Calculate Centroids
   ↓
Calculate Inertia
   ↓
Update Centroids
   ↓
Repeat
   ↓
Final Centroids
```

The important thing is:

> **Inertia is associated with the objective K-Means tries to minimize during training.**

Cross-tabulation is NOT part of this loop.

---

# 6. How K-Means Assigns Points

Suppose:

```text
K = 2
```

and we have two centroids:

```text
Centroid 0
Centroid 1
```

For every data point, K-Means calculates its distance to both centroids.

Example:

```text
Point X

Distance to Centroid 0 = 2.5
Distance to Centroid 1 = 8.7
```

Since:

```text
2.5 < 8.7
```

the point is assigned to:

```text
Cluster 0
```

General rule:

```text
Point
  ↓
Calculate distance to every centroid
  ↓
Find minimum distance
  ↓
Assign point to nearest centroid
```

---

# 7. How Centroids Are Updated

After assigning all points to clusters, K-Means recalculates each centroid.

For a cluster:

```text
Points = 2, 4, 5
```

The centroid is the mean:

```text
Centroid = (2 + 4 + 5) / 3

         = 3.67
```

For another cluster:

```text
Points = 8, 10
```

the centroid is:

```text
Centroid = (8 + 10) / 2

         = 9
```

So:

```text
Cluster 1 → Centroid = 3.67
Cluster 2 → Centroid = 9
```

Then K-Means checks how compact the clusters are.

This is measured using **Inertia / WCSS**.

---

# 8. What is Inertia / WCSS?

Inertia is also called:

```text
Within-Cluster Sum of Squares
(WCSS)
```

It measures how far data points are from the centroid of their assigned cluster.

Conceptually:

```text
          ●
       ●  ●  ●
          |
          C
```

If the points are close to the centroid:

```text
Low Inertia
```

If the points are far away:

```text
High Inertia
```

Therefore:

```text
Lower Inertia
      ↓
More compact clusters
```

The mathematical definition is:

```text
                 K
Inertia = Σ      Σ ||xi - μj||²
                j=1 xi ∈ Cj
```

Where:

```text
xi = Data point

μj = Centroid of cluster j

Cj = Points belonging to cluster j

K = Number of clusters

||xi - μj||² = Squared distance between point and centroid
```

---

# 9. Why Inertia Is Used During Training

K-Means tries to minimize the total squared distance between points and their assigned centroids.

Therefore:

```text
Training Goal:

Minimize Inertia
```

The training process can be understood as:

```text
Assign points
     ↓
Calculate centroids
     ↓
Calculate inertia
     ↓
Move/update centroids
     ↓
Inertia becomes smaller
     ↓
Repeat
```

Eventually, K-Means reaches a point where further updates provide little or no improvement.

---

# 10. Step-by-Step Inertia Example

Dataset:

```text
2, 4, 5, 8, 10
```

Assume:

```text
K = 2
```

Suppose:

```text
Cluster 1 = 2, 4, 5

Cluster 2 = 8, 10
```

## Step 1 — Calculate Centroids

### Cluster 1

```text
(2 + 4 + 5) / 3

= 3.67
```

### Cluster 2

```text
(8 + 10) / 2

= 9
```

---

## Step 2 — Calculate Squared Distances

### Cluster 1

```text
(2 - 3.67)² = 2.79

(4 - 3.67)² = 0.11

(5 - 3.67)² = 1.77
```

Therefore:

```text
Cluster 1 Inertia

= 2.79 + 0.11 + 1.77

= 4.67
```

### Cluster 2

```text
(8 - 9)² = 1

(10 - 9)² = 1
```

Therefore:

```text
Cluster 2 Inertia

= 2
```

---

## Step 3 — Total Inertia

```text
Total Inertia

= Cluster 1 Inertia + Cluster 2 Inertia

= 4.67 + 2

= 6.67
```

Therefore:

```text
Final Inertia = 6.67
```

---

# 11. K-Means Training Loop

The training process is approximately:

```text
                Start
                  ↓
        Initialize centroids
                  ↓
          Assign each point
                  ↓
        Find nearest centroid
                  ↓
       Recalculate centroids
                  ↓
         Calculate Inertia
                  ↓
        Has model converged?
             /          \
           No            Yes
           ↓              ↓
      Repeat          Final model
```

Important:

> **Cross-tabulation is NOT used here.**

Cross-tabulation is performed after training if actual labels are available.

# 13. What is Cross-Tabulation?

Cross-tabulation is a method of comparing:

```text
Actual Class
     VS
Cluster Assignment
```

Example:

```text
Actual labels:

Placed
Not Placed

K-Means output:

Cluster 0
Cluster 1
```

We can compare them using:

```python
pd.crosstab(actual_labels, kmeans.labels_)
```

---

# 14. Cross-Tabulation Is NOT Part of Training

This distinction is critical.

During training:

```text
X
↓
K-Means
↓
Centroids
↓
Inertia
↓
Update
↓
Repeat
```

Cross-tabulation does NOT participate.

After training:

```text
K-Means finished
       ↓
Cluster IDs available
       ↓
Actual labels available?
       ↓
      Yes
       ↓
Cross-Tabulation
```

Cross-tabulation is therefore:

```text
Evaluation / Interpretation
```

not:

```text
Training
```

---

# 15. Perfect Cross-Tabulation Example

Suppose K-Means gives:

```text
A → Cluster 0
B → Cluster 0
C → Cluster 1
D → Cluster 1
```

Actual labels:

```text
A → Placed
B → Placed
C → Not Placed
D → Not Placed
```

Cross-tabulation:

| Actual     | Cluster 0 | Cluster 1 |
| ---------- | --------: | --------: |
| Placed     |         2 |         0 |
| Not Placed |         0 |         2 |

This is excellent.

We can interpret:

```text
Cluster 0 → Mostly Placed

Cluster 1 → Mostly Not Placed
```

---

# 16. Poor Cross-Tabulation Example

Suppose:

```text
A → Cluster 0
B → Cluster 1
C → Cluster 0
D → Cluster 1
```

Cross-tabulation:

| Actual     | Cluster 0 | Cluster 1 |
| ---------- | --------: | --------: |
| Placed     |         1 |         1 |
| Not Placed |         1 |         1 |

Both clusters contain both types of students.

Therefore:

```text
Clusters do not align well
with the actual classes.
```

This indicates poor clustering with respect to those known labels.

# 17. Why Cluster Numbers Have No Meaning

This is one of the most important K-Means concepts.

Suppose:

```text
Cluster 0 → Placed
Cluster 1 → Not Placed
```

K-Means could just as easily produce:

```text
Cluster 1 → Placed
Cluster 0 → Not Placed
```

That is NOT wrong.

Cluster IDs are simply names.

They could theoretically be:

```text
Cluster 0
Cluster 1
```

or:

```text
Cluster 5
Cluster 20
```

The numbers do not represent class labels.

Therefore:

```text
Cluster 0 ≠ Class 0

Cluster 1 ≠ Class 1
```

---

For example:


Then:

```text
K-Means
   ↓

Cross-Tabulation
```

This is useful for understanding whether K-Means discovered groups that correspond to the known categories.

Suppose we have:

```text

Spending Score
```

but no actual class:


```text

   ↓
```

Therefore:


# 20. K Can Be Different From the Number of Actual Classes

This is extremely important.

Suppose your dataset has only two actual labels:

```text
Placed
Not Placed
```

You might think:

```text
2 labels
↓
K must be 2
```

That is NOT required.

K-Means is not trying to reproduce the target labels.

K-Means is trying to find **K groups in the feature space**.

Therefore, you could have:

```text
Actual classes = 2

K = 3
```

and this is completely valid.

The number of clusters and the number of actual classes do not have to be equal.

```text
Number of clusters ≠ Number of classes
```

# 22. How a New Point Is Assigned When K = 3

Now suppose a new student arrives:

```text
CGPA = 7.0
Aptitude = 75
```

Because:

```text
K = 3
```

there are three possible cluster assignments:

```text
             New Point
                 │
       ┌─────────┼─────────┐
       ↓         ↓         ↓
      C0        C1        C2
```

The model calculates:

```text
Distance to C0
Distance to C1
Distance to C2
```

For example:

```text
Distance to C0 = 15
Distance to C1 = 20
Distance to C2 = 4
```

The minimum is:

```text
4
```

Therefore:

```text
New Student → Cluster 2
```

This is the actual K-Means prediction.

K-Means does NOT directly say:

```text
Placed
```

or:

```text
Not Placed
```

Its direct output is:

```text
Cluster 2
```

# 23. Interpreting 3 Clusters With 2 Classes

Suppose:

```text
Cluster 0 → 95% Placed
Cluster 1 → 10% Placed
Cluster 2 → 60% Placed
```

Then we can understand:

```text
Cluster 0
→ High placement rate

Cluster 1
→ Low placement rate

Cluster 2
→ Medium placement rate
```

A new student might be assigned:

```text
New Student
     ↓
Cluster 2
```

Then we can say:

```text
Cluster 2 historically contains
approximately 60% Placed students.
```

This is an interpretation of the cluster.

It is NOT the same thing as K-Means directly learning:

```text
CGPA + Aptitude → Placement
```

## Two clusters can represent the same actual class

Suppose:

| Cluster   | Placed | Not Placed |
| --------- | -----: | ---------: |
| Cluster 0 |     45 |          2 |
| Cluster 1 |      3 |         50 |
| Cluster 2 |     40 |          1 |

Then:

```text
Cluster 0 → Mostly Placed
Cluster 1 → Mostly Not Placed
Cluster 2 → Mostly Placed
```

So:

```text
             K = 3

        ┌──────┼──────┐
        ↓      ↓      ↓
       C0     C1     C2
        ↓      ↓      ↓
    Placed  Not Placed Placed
```

Two clusters can correspond to the same actual class.

This is possible because K-Means discovers structure in the feature space rather than directly learning the class labels.

# 24. Choosing K — The Elbow Method

K-Means requires us to specify:

```python
KMeans(n_clusters=K)
```

But how do we know the correct K?

Use the **Elbow Method**.

Test:

```text
K = 1
K = 2
K = 3
K = 4
K = 5
...
```

For every K:

```text
Train K-Means
      ↓
Calculate Inertia
```

Example:

```text
K = 1 → Inertia = 1000
K = 2 → Inertia = 600
K = 3 → Inertia = 350
K = 4 → Inertia = 300
K = 5 → Inertia = 280
K = 6 → Inertia = 270
```

Plot:

```text
Inertia
  |
1000 ●
     |
 600 |    ●
     |       \
 350 |         ●
     |           \
 300 |             ●
     |               ●
 270 |                 ●
     +--------------------------→ K
        1   2   3   4   5   6
```

Look for the point where the decrease changes from large to relatively small.

That point is the **elbow**.

# 25. Other Clustering Evaluation Metrics

## 1. Inertia / WCSS

Measures cluster compactness.

```text
Lower → Better
```

---

## 2. Silhouette Score

Measures how well a point fits within its cluster compared with other clusters.

Range:

```text
-1 to +1
```

Generally:

```text
Higher → Better
```

---

## 3. Davies-Bouldin Index

Measures similarity between clusters.

```text
Lower → Better
```

---

## 4. Calinski-Harabasz Index

Measures the relationship between:

```text
Between-cluster separation
```

and:

```text
Within-cluster compactness
```

Generally:

```text
Higher → Better
```

# 26. What Happens When New Data Arrives?

This is the most important part for understanding how a trained K-Means model is used.

Suppose we have finished training.

The model learned:

```text
Centroid 0 = [8.3, 88]
Centroid 1 = [5.4, 48]
```

These are now the learned parameters.

A new student arrives:

```text
CGPA = 8.0
Aptitude = 85
```

The model calculates:

```text
Distance(New Student, Centroid 0)

and

Distance(New Student, Centroid 1)
```

Suppose:

```text
Distance to Centroid 0 = 3.02

Distance to Centroid 1 = 37.4
```

The smaller distance is:

```text
3.02
```

Therefore:

```text
New Student
     ↓
Cluster 0
```

# 27. K-Means Prediction

In scikit-learn:

```python
new_student = [[8.0, 85]]

prediction = kmeans.predict(new_student)

print(prediction)
```

Output:

```text
[0]
```

This means:

```text
New Student → Cluster 0
```

It does NOT automatically mean:

```text
New Student → Placed
```

The direct output of K-Means is:

```text
Cluster ID
```

---

## Does Prediction Retrain the Model?

No.

After:

```python
kmeans.fit(X_train)
```

the model has learned its centroids.

For new data:

```python
kmeans.predict(X_new)
```

uses those existing centroids.

We do NOT do:

```python
kmeans.fit(X_new)
```

for every new sample.

Otherwise, we would be retraining/relearning the clusters.

```text
    ↓
```

Then:

```text
Cluster 0 → Strong placement group
Cluster 1 → Weak placement group
```

```text
     ↓
K-Means
     ↓
Cluster 2
```

```text
Cluster 2

Historically 55% Placed

Moderate / uncertain placement pattern
```

Again:

# 31. Important Limitation

K-Means itself does NOT learn:

```text
CGPA + Aptitude → Placement
```

It learns:

```text
CGPA + Aptitude → Cluster
```

If we later discover:

```text
Cluster 0 → 90% Placed
Cluster 1 → 85% Not Placed
```

then we can use the clusters as an indirect proxy for placement.

But this is different from a supervised classification model.

If the actual goal is:

> "Predict whether a student will be placed."

then supervised classification is usually the more direct formulation:

```text
X = CGPA + Aptitude
y = Placement

X → Classification Model → Placement
```

K-Means instead asks:

```text
X = CGPA + Aptitude

X → K-Means → Natural Groups
```

# 32. Complete Python Example

```python
import pandas as pd
from sklearn.cluster import KMeans

# ---------------------------------
# 1. Feature Matrix
# ---------------------------------

X = df[['CGPA', 'Aptitude']]

# ---------------------------------
# 2. Actual Labels
# ---------------------------------

# Used ONLY for evaluation/interpretation
y = df['Placement']

# ---------------------------------
# 3. Train K-Means
# ---------------------------------

kmeans = KMeans(
    n_clusters=3,
    random_state=42
)

kmeans.fit(X)

# ---------------------------------
# 4. Cluster IDs for training data
# ---------------------------------

clusters = kmeans.labels_

print(clusters)

# ---------------------------------
# 5. Learned Centroids
# ---------------------------------

print(kmeans.cluster_centers_)

# ---------------------------------
# 6. Inertia
# ---------------------------------

print(kmeans.inertia_)

# ---------------------------------
# 7. Cross Tabulation
# ---------------------------------

print(
    pd.crosstab(
        y,
        clusters
    )
)

# ---------------------------------
# 8. New Student
# ---------------------------------

new_student = [[8.0, 85]]

cluster = kmeans.predict(new_student)

print(cluster)
```

With:

```python
n_clusters=3
```

the output for a new student can be:

```text
[0]
```

or:

```text
[1]
```

or:

```text
[2]
```

because there are three possible clusters.

# 35. Key Takeaways

## K-Means Training

* K-Means is an **unsupervised learning algorithm**.
* It uses feature matrix `X`.
* It does not use target labels `y` during training.
* It creates `K` clusters.
* Each cluster has a centroid.
* Points are assigned to their nearest centroid.
* Centroids are recalculated from the assigned points.
* K-Means tries to minimize **Inertia / WCSS**.
* Training continues until the algorithm converges.

---

## Inertia

```text
Inertia = Within-Cluster Sum of Squares
```

It measures cluster compactness.

```text
Lower Inertia
      ↓
More compact clusters
```

However:

```text
K ↑
↓
Inertia ↓
```

Therefore, inertia alone cannot determine the optimal K.

Use the **Elbow Method** to help select K.

---

## Cross-Tabulation

Cross-tabulation:

* Happens after training.
* Is NOT part of K-Means training.
* Does NOT update centroids.
* Does NOT affect inertia.
* Requires actual labels.
* Compares actual classes with cluster IDs.
* Helps understand what the clusters represent.

---

## Cluster IDs

Remember:

```text
Cluster 0 ≠ Class 0
Cluster 1 ≠ Class 1
```

Cluster numbers are arbitrary names.

---

## K and Number of Classes

There is no requirement that:

```text
K = Number of Classes
```

For example:

```text
Actual classes = 2

Placed
Not Placed

K = 3

Cluster 0
Cluster 1
Cluster 2
```

is completely valid.

Two clusters can even correspond mostly to the same actual class.

---

## New Data

After training:

```text
New Point
    ↓
Calculate distance to every learned centroid
    ↓
Choose minimum distance
    ↓
Assign cluster
```

For:

```text
K = 3
```

the new point has:

```text
Cluster 0
Cluster 1
Cluster 2
```

as its possible assignments.

---

## Most Important Difference

```text
K-Means:

X → Cluster
```

not:

```text
X → Actual Class
```

If we have actual labels, we can use them afterward to interpret the clusters.

Therefore:

> **K-Means predicts the cluster. Cross-tabulation helps us understand the relationship between that cluster and known classes.**

And:

> **The learned centroids are the main parameters used when assigning new data.**

---

```text
Training:
Learn Centroids by Minimizing Inertia

Evaluation:
```
