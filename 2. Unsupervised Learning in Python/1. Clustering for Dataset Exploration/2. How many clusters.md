# Exercise

## How many clusters?

You are given an array `points` of size 300x2, where each row gives the (x, y) co-ordinates of a point on a map. Make a scatter plot of these points, and use the scatter plot to guess how many clusters there are.

`matplotlib.pyplot` has already been imported as `plt`.

### Instructions

* Create an array called `xs` that contains the values of `points[:,0]` - that is, column `0` of `points`.
* Create an array called `ys` that contains the values of `points[:,1]` - that is, column `1` of `points`.
* Make a scatter plot by passing `xs` and `ys` to the `plt.scatter()` function.
* Call the `plt.show()` function to show your plot.
* How many clusters do you see? (2 or 3)

---

### Starter Code

```python
# Create an array xs containing column 0 of points
xs = ____[:,____]

# Create an array ys containing column 1 of points
ys = ____[:,____]

# Make a scatter plot of xs and ys
plt.____(____, ____)

# Show the plot
____.____()
```

---

### Solution

```python
# Create an array xs containing column 0 of points
xs = points[:,0]

# Create an array ys containing column 1 of points
ys = points[:,1]

# Make a scatter plot of xs and ys
plt.scatter(xs, ys)

# Show the plot
plt.show()
```

### Multiple Choice Answer
**3** (You can visually identify 3 distinct clusters of points on the scatter plot generated by the code).
